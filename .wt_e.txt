+## ⑧ 任务 T-A0-4 · 固化测试配置
+
+**新建 `pytest.ini`（仓库根）**：
+
+```ini
+[pytest]
+testpaths =
+    packages/rag-contracts/tests
+    packages/cg-observability/tests
+    packages/rag-core/tests
+    packages/ai-engine/tests
+    packages/doc-processor/tests
+    apps/api-gateway/app/api/v1/tests
+pythonpath =
+    packages/rag-contracts
+    packages/cg-observability
+    packages/rag-core
+    packages/ai-engine
+    packages/doc-processor
+    apps/api-gateway
+addopts = -q
+```
+
+> ⚠️ `ai-engine/tests` 与 `doc-processor/tests` **当前不存在**。
+> `testpaths` 里的不存在路径 pytest 会自动忽略，但**这两个包目前零测试**——
+> 建议在本任务内**同时建目录并各放一个冒烟用例**，作为 `0.§0.9` DoD「单测已加」的落脚点。
+
+**修改根 `pyproject.toml`**，把工具链登记补齐到全部 workspace 包：
+
+```toml
+[tool.ruff.lint.isort]
+known-first-party = [
+    "rag_core", "rag_contracts", "cg_observability",
+    "ai_engine", "doc_processor", "app", "worker",
+]
+
+[tool.mypy]
+mypy_path = [
+    "packages/rag-contracts", "packages/cg-observability", "packages/rag-core",
+    "packages/ai-engine", "packages/doc-processor",
+    "apps/api-gateway", "apps/async-worker",
+]
+```
+
+**验收标准**
+
+| # | 断言 |
+|---|---|
+| 1 | 仓库根执行 `pytest`（**不预设任何 `PYTHONPATH`**）→ `140 passed` 或更多，0 error |
+| 2 | `ruff check .` 无新增错误 |
+| 3 | `mypy packages/rag-core` 不再出现成片 `import-not-found` |
+
+**避坑**
+
+- ⚠️ `pythonpath` 用相对路径，不要写 `E:\...` 绝对路径（换机器即失效）
+- ⚠️ `pytest.ini` 优先级高于 `pyproject.toml` 的 `[tool.pytest.ini_options]`。
+  若将来想合并回 `pyproject.toml`，**必须删掉 `pytest.ini`**，否则后者被静默忽略
+- 本机 `.venv` 解释器可能无法启动（见 `0.§0.6.3`），此时用系统 Python + `PYTHONPATH` 前置 `.venv\Lib\site-packages` 验证
