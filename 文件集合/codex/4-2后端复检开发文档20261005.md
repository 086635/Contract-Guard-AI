## ⑤ 接口规格

无新增 API 与配置。ResultService.parse_status 的签名、TaskProgress 响应形状与访问权限保持；最新任务 ID 来自 TaskRepository，最新快照来自 TaskService.get，返回 result 继续只保留合同 ID 与错误提示。CeleryTaskDispatcher.get_status 成功快照没有进度时默认 1.0，显式运行进度保持。LocalOcrEngine._read_image 返回 BGR ndarray，无效/缺失/空图片继续抛 RenderFailedError。

## ⑥ 实现规范

遵循 `0.施工标准与定义归属.md` §0.2/§0.6/§0.8/§0.9。只修改 §④ 文件；不手改生成物、不放宽断言；logger 的生产 propagate=False 保留，仅在测试中临时启用捕获并自动恢复。测试临时文件使用唯一目录。AI/向量外部服务保持离线；最终全量使用独立 PG 测试数据库，保留用户合同和现有服务。Windows 子进程使用 PYTHONUTF8=1 避免默认 GBK 解码错误，此项仅设置在本地运行脚本。
