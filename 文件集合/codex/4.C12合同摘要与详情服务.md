## ⑤ 接口规格

```python
class ContractService:
    async def list(self, page: int, page_size: int, *, contract_type=None, status=None) -> tuple[list[ContractSummary], int]: ...
    async def get(self, contract_id: UUID) -> Contract: ...
```

## ⑥ 实现规范

1. `healthScore.dimensions` 只由风险/矛盾数据计算，禁止随机值。
2. `reportId` 从最新 `AuditReport` 读取；无报告为 `None`。
3. list 的 `hasMore = page * pageSize < total`。
4. 筛选使用生成枚举 `ContractType` / `ContractStatus`。
5. 找不到合同由 Service 返回 `None`，路由负责 404。
