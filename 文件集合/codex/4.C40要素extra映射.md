## ② 范围

### ✅ 做

- `IngestionService.finalize_parse()` 除 clauses 外，继续读取解析结果顶层 `elements`。
- 将每个 `ContractElement` 形状的 element 投影为 `ContractChunk`：
  - `section_id = element.key`
  - `title = element.label`
  - `text = element.value`；空 value 保留真实空值，文本占位只用于检索兼容
  - `extra["value"]` 保存原始 value（允许 null）
  - `extra["confidence"]` 保存 confidence
  - `extra["isCustom"]` 保存 isCustom
  - `bbox` 保存真实几何（没有则为 null）
  - `category = CONTRACT_ELEMENT`
- `ContractProjector.elements()` 遇到 `category == CONTRACT_ELEMENT` 时从 `extra` 还原 `ContractElement`。
- 保留 C22 的 clause → chunk 路径，不改变条款索引语义。

### ❌ 不做

- ❌ 不新增独立 contract_elements 表，不改变 `ContractChunk` 28 字段。
- ❌ 不把 label 写入 value 后从文本反推真实值。
- ❌ 不乱改 `source_type` / `chunk_type` 枚举，不新增枚举值。
- ❌ 不改前端 `ContractElement` DTO。

## ⑥ 实现规范

1. 只信任解析结果顶层 `elements` 的 dict；缺 key、非 dict 或字段非法时记录 warning 并跳过单条，不阻断 clause 入库。
2. `chunk_id` 使用 `ContractChunk.make_chunk_id(contract_id, key, 0)`，重复执行必须 upsert 幂等。
3. `text` 只保存 element value 的可检索兼容值；value 为空时可以使用 label 作为文本占位，但 `extra.value` 必须保持 null。
4. `ContractProjector.elements()` 必须优先读取 `extra`，缺失时才走旧字段兼容回退；不得返回假 confidence 或假 isCustom。
5. 不改变条款 `category=CLAUSE` 的现有行为；查询排序沿用 `seq_in_doc`。
6. 新逻辑必须与 C22 的 seal、audit 入库幂等和 warning 语义对齐。
