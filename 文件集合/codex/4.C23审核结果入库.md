## ⑤ 接口规格

```python
class IngestionService:
    async def finalize_audit(self, contract_id: UUID) -> bool: ...
```

- 读取最新 `RUN_AUDIT` 任务的 `celery_task_id` → `TaskDispatcherPort.get_status`。
- 仅 DONE 且快照 `result` 顶层含 `risks` / `conflicts` 时：`EnhancedRiskItem.model_validate` / `CrossClauseConflict.model_validate` 后 `RiskRepository.bulk_upsert(contract_id, [*risks, *conflicts])`。

## ⑥ 实现规范

1. 先 `TaskRepository.get_latest_by_contract(contract_id, TaskKind.RUN_AUDIT.name)`；无任务行或 `celery_task_id` 为空则返回 `False`。
2. 非 DONE（RUNNING/FAILED/无快照）不入库、不误报。
3. 只信任快照 `result` 顶层的 `risks` / `conflicts`，缺失按空列表处理。
4. `bulk_upsert` 幂等（主键冲突更新），重复 `finalize_audit` 不重复建行。
5. 埋点 `log_event`（含 `trace_id` 与 `contract_id`）；异常收敛为「不入库 + warning」。
