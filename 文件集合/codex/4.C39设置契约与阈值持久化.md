## ⑤ 接口规格

```ts
type ReviewThresholds = {
  high: number;   // 0..1
  medium: number; // 0..1
  low: number;    // 0..1
};

type SystemAuditConfiguration = {
  // 既有字段保持不变
  enabled: boolean;
  reviewThresholds: ReviewThresholds;
};
```

- `enabled` 缺省按 `false`/现有记录 `is_enabled` 处理；
- `reviewThresholds` 缺省迁移为 `{high:0.85, medium:0.65, low:0.40}`；
- PUT 成功返回服务端最终 DTO。

## ⑥ 实现规范

1. 先改 OpenAPI，再运行生成；不在 UI 或服务层手写 `enabled`/阈值类型。
2. Alembic 迁移必须为已有行写入默认 JSON，不允许 `NULL` 进入查询。
3. `RuleService._to_dto()` 同时映射 `enabled` 和 `reviewThresholds`；`enabledRules` 继续从既有规则名兼容生成。
4. `RuleService.update()` 解析 `enabled` 和 `reviewThresholds`，完成 0~1、顺序和有限数校验后再写库。
5. `RuleRepository.upsert()` 增加 `review_thresholds` 列；不改变版本冲突语义。
6. API route 的 body 类型使用生成 DTO，禁止 `dict` 直通。
7. 失败返回稳定 4xx/422，不返回部分保存。
