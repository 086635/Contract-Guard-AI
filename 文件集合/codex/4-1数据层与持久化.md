## ⑤ 接口规格

**9 表对齐列**（完整列以 `ContractChunk`/openapi 为唯一依据）：

| 表 | 关键列 |
|---|---|
| `contracts` | `id/filename/file_size/file_hash(UQ)/storage_path/status/contract_type/created_at/updated_at` |
| `contract_commits` | `id/contract_id/request_id/item_id/accepted/version/created_at` |
| `contract_elements` | `ContractChunk` 28 字段投影 + `contract_id(FK)` + `vector_id(=chunk_id)` |
| `audit_tasks` | `id(=task_id)/contract_id(FK)/task_type/stage/progress(0..1)/status/celery_task_id/error_message/created_at/updated_at` |
| `audit_risks` | `EnhancedRiskItem`/`CrossClauseConflict` 投影（`level` 用 `RiskLevel`） |
| `seal_detections` | `SealSignatureDetection` 投影（type/status/bbox/page/confidence） |
| `settings_rules` | `id/rule_name/category/prompt_template/threshold/is_enabled` |
| `audit_reports` | `id(=reportId)/contract_id(FK)/format/storage_path/download_count/generated_at/status` |
| `user_feedbacks` | `id/target_type/target_id/verdict/user_comment/created_at` |

DAL 统一为 async 方法，返回 Pydantic DTO（由 openapi 生成物映射），示例：

```python
class ContractRepository:
    async def list(self, page: int, page_size: int) -> tuple[list[ContractSummary], int]: ...
    async def get(self, contract_id: UUID) -> ContractDetail | None: ...
    async def create(self, meta: ContractCreate) -> ContractDetail: ...
    async def update_status(self, contract_id: UUID, status: ContractStatus) -> None: ...
```

## ⑥ 实现规范

1. 枚举列一律映射 openapi/`rag_contracts` 枚举，**禁止魔法字符串**。
2. `audit_tasks.progress` 用 **0..1**（与 `TaskProgress.percent` 一致），`status` 用 `RUNNING/DONE/FAILED`。
3. `user_feedbacks` 用 `target_type + target_id` 多态关联（`Feedback.targetType` 四值）。
4. 报告只记 `format=DOCX` 起步，`downloadUrl` 不在 DB 存（运行时由 MinIO 预签名生成）。
5. 迁移只通过 Alembic；本机 `pytest` 用 §4.1 的 `PYTHONPATH`。
