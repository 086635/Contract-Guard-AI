## ② 范围

### ✅ 做

- 生产 nginx 监听 443，HTTP 跳转 HTTPS。
- 设置 HSTS、CSP、X-Content-Type-Options、Referrer-Policy、frame-ancestors。
- 对 /api 登录/上传等路径限流并设置请求体上限。
- 代理头和 WebSocket/SSE buffering 配置正确。

### ❌ 不做

- 不在 nginx 写业务权限。
- 不关闭 TLS 校验。
- 不让 SSE 被缓冲。

## ⑤ 接口规格

```text
listen 443 ssl http2
location /api/ { proxy_pass http://api:8000; ... }
HSTS/CSP/rate_limit
```

## ⑥ 实现规范

1. 证书文件不提交仓库。
2. SSE 设置 proxy_buffering off。
3. 错误页不返回内部版本。
4. 请求体限制与上传上限一致。
