## ② 范围

### ✅ 做

- **新建** `doc_processor/ocr/seal.py`，实现三段式印章检测（**全程不依赖深度学习模型**）：
  1. **区域检测**：HSV 红色掩膜（**红色跨 0/180 两段，必须取并集**）→ 形态学闭运算 → 轮廓筛选（面积 / 长宽比 / 圆度）
  2. **文字识别**：极坐标展开（`cv2.warpPolar`）把圆环文字拉成水平文本条 → 送通用 OCR
  3. **主体比对**：`difflib.SequenceMatcher` 与甲乙方名称模糊匹配 → "印章与签约主体是否一致"
- 产出 **`SealAnalysis`**（冻结的 `SealDetection` + `seal_type` / `status` / `is_matched_with_parties` / `compliance_note`）
- 提供 `to_detection_payload()`：转成 openapi `SealSignatureDetection` 形状（供 3-6 放进信封）
- 提供**两个离线可测的纯/半纯入口**：`red_mask()`、`find_seal_regions()`、`expand_ring()`、`match_parties()`、`classify_seal_type()`、`judge_status()`
- 引擎缺失时**降级**：区域检测照常产出，`extracted_text=None`、`status="BLURRY_UNRECOGNIZABLE"`，不抛异常

### ❌ 不做

- ❌ **不改 `SealDetection` 字段**（冻结）；**不新增第二个坐标体系**（结果必须经 `to_pdf_points(src_dpi)` 归一）
- ❌ **不定义 `SealType` / `SealStatus` 的第二个枚举**：取值 SSOT 是 `packages/schema/openapi.yaml`（§5.5 用测试守住）
- ❌ 不判 **`MISSING`（应有未盖）**：那是**合同级**判断（要有甲乙方、签署栏位置、条款约定"盖章生效"等信息），属审核侧任务 → 登记为待建（§⑨-9）
- ❌ 不做**手写签名识别**（D3-d 建议本次只做"存在性检测"）；不做印章**防伪/PS 检测**
- ❌ 不做印章文字的**结构化解析**（税号 / 社会信用代码抽取）——`extracted_text` 只存原文串
- ❌ 不写红色之外的颜色掩膜（蓝章 / 骑缝章按 `hints` 区域做存在性检测，不识别文字）→ 登记为增强项
- ❌ 不重复声明依赖（`opencv-python-headless` / `numpy` / `pypdfium2` 以 **3-1** 的 `pyproject.toml` 区间清单为准）

### 5.1 模块接口

```python
# doc_processor/ocr/seal.py
from __future__ import annotations

from dataclasses import dataclass
from typing import Sequence

import numpy as np

from doc_processor.ocr import OcrEngine, SealDetection

HSV_RED_LOW = ((0, 70, 50), (10, 255, 255))      # 红色下段
HSV_RED_HIGH = ((170, 70, 50), (180, 255, 255))  # 红色上段（跨 0/180，必须并集）
MORPH_KERNEL_SIZE = 15        # 闭运算核（连接被签名/正文遮挡的笔画）
ASPECT_RANGE = (0.6, 1.7)     # 外接矩形长宽比可接受区间（印章近似方形）
MIN_CIRCULARITY = 0.35        # 圆度下限 4πA / P²
PADDING_RATIO = 0.10          # 候选框外扩比例
PARTY_MATCH_THRESHOLD = 0.60  # 主体模糊匹配阈值
REGION_SCORE_WEIGHT = 0.6     # confidence 合成权重（区域）
OCR_SCORE_WEIGHT = 0.4        # confidence 合成权重（文字）
MAX_SEALS_PER_PAGE = 8        # 单页候选上限（防极端图片刷爆）


@dataclass(frozen=True, slots=True)
class SealAnalysis:
    """印章判定结果（本模块内部载体，见 §③ 说明）。"""

    detection: SealDetection      # 冻结契约：page/x/y/width/height/extracted_text/confidence
    seal_type: str                # ∈ openapi SealType（字面量）
    status: str                   # ∈ openapi SealStatus（字面量）
    is_matched_with_parties: bool
    party_ratio: float            # 与甲乙方名称的最高相似度（0~1）
    compliance_note: str          # 中文一句话（进报告）


def red_mask(image: "np.ndarray") -> "np.ndarray":
    """红色掩膜（**双段并集，唯一处**）：`inRange(HSV_RED_LOW) | inRange(HSV_RED_HIGH)`。

    Args:
        image: BGR 图像。

    Returns:
        单通道 `uint8` 掩膜（0 / 255）。
    """


def find_seal_regions(
    image: "np.ndarray", *, min_area_ratio: float
) -> "list[tuple[int, int, int, int]]":
    """红色候选区域（像素坐标 `(x, y, w, h)`，已外扩 `PADDING_RATIO`）。

    流程：`red_mask` → 闭运算 → 轮廓 → 面积 ≥ 页面面积 × `min_area_ratio` →
          长宽比 ∈ `ASPECT_RANGE` → 圆度 ≥ `MIN_CIRCULARITY` → 按面积降序取前 `MAX_SEALS_PER_PAGE`。
    """


def expand_ring(image: "np.ndarray", box: "tuple[int, int, int, int]", *, steps: int) -> "np.ndarray":
    """把候选框内的圆环展开为水平文本条（**唯一处**）。

    实现固定为 `cv2.warpPolar(..., dsize=(半径, steps), WARP_POLAR_LINEAR)`：
    输出形状 `(steps, 半径, 3)`，**行 = 角度、列 = 半径** —— 环形文字因此变成横向文本条。

    Returns:
        BGR 图像；候选框退化（宽或高为 0）时返回空数组。
    """


def match_parties(text: str | None, party_names: Sequence[str]) -> "tuple[bool, float]":
    """印章文字与甲乙方名称的模糊比对（**唯一处**）。

    规则：
      1. 归一化：去空白与中英文标点、全角 → 半角；**保留"有限公司"等后缀**；
      2. 对每个主体名算 `difflib.SequenceMatcher(None, text, name).ratio()`；
      3. 命中条件（满足其一）：`name` 是归一化文本的**子串** 或 最高 ratio ≥ `PARTY_MATCH_THRESHOLD`。

    Returns:
        `(是否命中, 最高相似度)`；`text` 为空或 `party_names` 为空 → `(False, 0.0)`。
    """


def classify_seal_type(text: str | None) -> str:
    """按关键词判印章类型（规则表见 §5.4）。"""


def judge_status(*, region_score: float, extracted_text: str | None, matched: bool,
                 overlap: bool) -> str:
    """判定印章状态（规则表见 §5.4）。**不产出 `MISSING`**（属审核侧）。"""


def to_detection_payload(analysis: SealAnalysis, *, seq: int) -> dict:
    """转 openapi `SealSignatureDetection` 形状（camelCase + `BBox`，唯一映射处）。"""


class LocalSealDetector:
    """三段式印章检测器（区域 → 展开 → 比对）。"""

    def __init__(self, settings=None, ocr: OcrEngine | None = None) -> None: ...

    def detect(
        self,
        image: "np.ndarray",
        *,
        page: int,
        src_dpi: int,
        party_names: Sequence[str] = (),
        hints: Sequence[tuple[float, float, float, float]] = (),
    ) -> list[SealAnalysis]:
        """对单页图像做印章检测。

        Args:
            image: BGR 图像。
            page: 页码（1-based）。
            src_dpi: 图像 DPI（归一化坐标**必须**用它，`render_dpi` 或 `image_dpi`）。
            party_names: 甲乙方名称（来自 3-4 的 `ParsedElement`；空 → 不做主体比对）。
            hints: 区域提示框（**PDF_POINTS**，来自 3-7 的 `SEAL` 块）：优先只在提示区找红色；
                   提示区无命中 → 回落全页扫描。空 → 全页扫描。

        Returns:
            `SealAnalysis` 列表（按面积降序）。
        """


def detect_seals_in_image(
    image: "np.ndarray", *, page: int, src_dpi: int, settings=None,
    party_names: Sequence[str] = (), hints: Sequence[tuple[float, float, float, float]] = (),
    ocr: OcrEngine | None = None,
) -> list[SealAnalysis]:
    """模块级入口（**3-6 与 3-3 的共同调用点**）。"""
```

### 5.2 三段式流程（**唯一处**）

```text
① 区域检测（无模型）
   BGR → HSV → red_mask()（双段并集）→ morphologyEx(MORPH_CLOSE, 椭圆核 MORPH_KERNEL_SIZE)
   → findContours(RETR_EXTERNAL) → 面积 / 长宽比 / 圆度筛选 → 外扩 PADDING_RATIO
   hints 非空时：先只在 hints 框内做同样的筛选；无命中 → 回落全页（并记一条 warning）

② 文字识别（复用通用 OCR）
   对每个候选框：
     · 正方形化（边长 = max(w, h)）→ 中心 = 框中心 → 半径 = 边长 / 2
     · expand_ring() → 水平文本条
     · 对文本条做 0° / 90° / 180° / 270° 四个方向的 OCR（`ocr.ocr_image`，`src_dpi` 透传，
       **超过 4 次调用就是浪费**），取置信度最高者
     · 文本置信度 < OcrSettings.min_confidence → 视为未识别（extracted_text = None）
     · 引擎不可用 / 未注入 → 跳过本段（extracted_text = None + 一条 warning，**不抛异常**）

③ 主体比对（零依赖）
   match_parties(extracted_text, party_names) → (matched, ratio)
   · party_names 为空 → matched=False、ratio=0.0，且 compliance_note 写明"未提供主体名称，未做比对"

confidence 合成（**唯一公式**）：
   region_score = clamp(圆度 / 0.6, 0, 1)          # 越接近圆越像印章
   ocr_score    = 该区域的最高文本置信度（无文本 → 0.0）
   confidence   = REGION_SCORE_WEIGHT × region_score + OCR_SCORE_WEIGHT × ocr_score
   引擎不可用时 confidence = REGION_SCORE_WEIGHT × region_score（降级口径，写进 compliance_note）
   最终结果 round(…, 2)，并 clamp 到 [0, 1]
```

## ⑥ 实现规范

1. 🔴 **红色必须双段并集**：HSV 的红色跨越 `0` 与 `180` 两端，只写一段会漏掉一半红章（§⑦ 断言 1 会抓）。两段的阈值只能出现在 `HSV_RED_LOW` / `HSV_RED_HIGH` 两处常量里。
2. 🔴 **闭运算不可省**：印章常被签名、正文、折痕遮挡，笔画会断裂；不闭运算会导致圆度骤降、整枚漏检。
3. 🔴 **坐标零例外**：`find_seal_regions()` 产出的是**像素**框，出模块前必须 `to_pdf_points(..., src_dpi=src_dpi)`（`src_dpi` = 渲染 DPI 或图片 DPI，**由调用方传入，不在本模块猜**）。
4. 🔴 **展开方向四选一**：圆环文字在展开图上会呈现为横向或倒向，**只试 0° 一定漏**；四方向各一次 OCR，取最高置信度。**最多 4 次**，不做网格搜索。
5. 🔴 **不注入引擎也要能用**：`ocr=None` 或引擎不可用时，区域检测与状态判定照常完成（`BLURRY_UNRECOGNIZABLE` + 说明），**不得抛异常**——印章检测是 3-6 的**软依赖**，不能把整条解析链路打挂（3-6 §6.9）。
6. 🔴 **不产出 `MISSING`**：见 §5.4 末的红线。
7. ⚠️ **`MAX_SEALS_PER_PAGE` 是护城河**：红色商标、红色表头、红色批注会造出大量候选；按面积降序截断（不是随机丢），并记一条 warning。
8. ⚠️ **`hints` 是提示不是约束**：提示区无红色时必须回落全页扫描（合同可能有多枚章，`SEAL` 块只覆盖文字附近）。
9. ⚠️ **重叠判定是自比对**：候选框两两算 IoU，≥ 0.5 才置 `overlap=True`（骑缝章、重叠盖章是真实的合规风险场景）。
10. ⚠️ **打点**：命名空间 `get_logger("doc_processor.ocr.seal")`；`log_event("seal.detect", page=..., regions=..., analyzed=..., matched=..., latency_ms=...)`。
11. ⚠️ **性能**：单页 ≤ 8 枚、每枚 ≤ 4 次 OCR —— 30 页扫描件的印章段应在个位数秒内完成；超时说明候选筛选失效，先查阈值不要加超时。

## ⑨ 避坑清单

| # | 坑 | 说明 |
|---|---|---|
| 1 | 红色掩膜只写 `H ∈ [0,10]` | 另一半红章（`H ∈ [170,180]`）**整枚漏检**；必须两段取并集 |
| 2 | 跳过闭运算直接找轮廓 | 被签名/正文压过的印章轮廓会碎成十几块，圆度全灭 |
| 3 | 拿像素坐标直接进信封 | 前端整体错位；必须 `to_pdf_points(..., src_dpi)` |
| 4 | 只对一个角度 OCR 展开条 | 环形文字方向不定；**四个方向取最高置信度**（最多 4 次） |
| 5 | 引擎不可用时抛异常 | 印章是 3-6 的软依赖，抛异常会把整条解析链路打成 `FAILED` |
| 6 | 产出 `MISSING` 状态 | 那是合同级判断（要有"应当盖章"的依据）；越界会与模块 2 的结论打架 |
| 7 | 为 `SealType` / `SealStatus` 另立枚举类 | 与 `packages/schema/openapi.yaml` 形成两处定义，前端映射会漂移 |
| 8 | 用 `extracted_text` 去匹配"任意一方"就算一致 | 必须与**甲乙方名称**比对；相似度与命中判定都要落进 `compliance_note` 便于复核 |
| 9 | 把"应有未盖"写进本模块 | 见第 6 条；登记为待建任务（合同级审核侧） |
| 10 | 红色商标/表头被当成印章 | 面积 + 长宽比 + 圆度三道筛选；并保留 `MAX_SEALS_PER_PAGE` 截断 |
| 11 | 忽略 `hints`（3-7 的 `SEAL` 块） | 提示能显著降低误检；但**提示区无命中时一定要回落全页** |
| 12 | 把 `src_dpi` 写死 72 | 扫描件是 200dpi 渲染的，写死 72 会让所有框缩小到 1/2.8 |
