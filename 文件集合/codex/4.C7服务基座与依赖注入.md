## ⑤ 接口规格

```python
class ObjectStoragePort(Protocol):
    def presign_put(self, file_key: str, expires_s: int = 600) -> str: ...
    def presign_get(self, file_key: str, expires_s: int = 900) -> str: ...
    def stat_object(self, file_key: str) -> StoredObjectInfo: ...

class TaskDispatcherPort(Protocol):
    def send(self, task_name: str, *, args: tuple[object, ...] = ()) -> str: ...
    def get_status(self, task_id: str) -> TaskStatusSnapshot | None: ...

class ProgressBrokerPort(Protocol):
    def subscribe(self, task_id: str) -> AsyncIterator[dict[str, object]]: ...

@dataclass(frozen=True, slots=True)
class ServiceContext:
    session: AsyncSession
    object_storage: ObjectStoragePort
    task_dispatcher: TaskDispatcherPort
    progress_broker: ProgressBrokerPort
```

FastAPI 依赖：

```python
async def get_db() -> AsyncIterator[AsyncSession]: ...
async def get_service_context(
    db: AsyncSession = Depends(get_db),
) -> ServiceContext: ...
```

## ⑥ 实现规范

1. 所有路由只依赖 `get_service_context()`，不直接构造 engine、Minio 或 Celery。
2. `ServiceContext` 使用 `dataclass(frozen=True, slots=True)`，避免请求内被替换。
3. Protocol 方法只表达网关需求，不暴露 worker 内部类。
4. 测试通过 FastAPI `dependency_overrides` 注入 Fake 端口。
5. 不吞依赖构造异常；客户端真实不可用时由 C8 的适配器决定降级语义。
