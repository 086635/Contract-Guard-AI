## ⑤ 接口规格

```ts
export const taskApi = {
  get(taskId: string): Promise<TaskProgress>;
  subscribe(
    taskId: string,
    onProgress: (progress: TaskProgress) => void,
    onError?: (event: Event) => void
  ): () => void;
};
```

约定：

- `event: progress` 的 `data` 是裸 `TaskProgress`。
- 终态集合固定为 `DONE`、`FAILED`。
- `onerror` 只触发轮询兜底，不把任务直接标记为成功。
- `unsubscribe()` 必须同时关闭 EventSource 并停止定时器。

## ⑥ 实现规范

1. 使用 `source.addEventListener("progress", handler)`；不得只依赖 `onmessage`。
2. 事件 JSON 先按 `TaskProgress` 形态解析；解析失败只告警，不中断轮询兜底。
3. 轮询间隔固定 2 秒，调用 `taskApi.get()`；在 `DONE/FAILED` 时停止并清理。
4. 终态关闭后必须幂等，重复调用 unsubscribe 不产生额外请求。
5. 请求错误继续通过 C29 的错误对象传播，页面负责展示。
6. 不在本卡改变 `taskApi.get()` 的成功包络解包方式。
