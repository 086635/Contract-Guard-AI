## ⑤ 接口规格

```python
class ContractRepository:
    def __init__(self, session: AsyncSession) -> None: ...
    async def list(self, page: int, page_size: int, *, contract_type=None, status=None) -> tuple[list[ContractSummary], int]: ...
    async def get(self, contract_id: UUID) -> ContractDetail | None: ...
    async def create(self, meta: ContractCreate) -> ContractDetail: ...
    async def update_status(self, contract_id: UUID, status: ContractStatus) -> None: ...
    async def increment_version(self, contract_id: UUID) -> int: ...

class CommitRepository:
    async def list_by_request(self, request_id: str) -> list[CommitItemRecord]: ...
    async def create_items(self, contract_id, request_id, version, items) -> None: ...

class TaskRepository:
    async def get(self, task_id) -> TaskRecord | None: ...
    async def create(self, contract_id, task_type, celery_task_id) -> TaskRecord: ...
    async def update_status(self, task_id, status, error_message=None) -> None: ...
    async def update_progress(self, task_id, stage, progress) -> None: ...
```

## ⑥ 实现规范

1. 返回 Pydantic DTO（openapi 生成物），不泄漏 ORM 对象到路由层。
2. `update_status` 同时刷 `updated_at`。

## ⑦ 验收标准（**卡内可自证**）

| 2 | `update_status` 后状态变更且 `updated_at` 更新 |
