## ⑤ 接口规格

不新增生产接口。测试边界（离线，Fake `ProgressBrokerPort`）：

```python
class FakeProgressBroker:
    def __init__(self, events: list[dict] | None = None) -> None: ...
    async def subscribe(self, task_id: str) -> AsyncIterator[dict]: ...
    def unsubscribed(self, task_id: str) -> bool: ...
```

## ⑥ 实现规范

1. 用 Fake broker 推送 `RUNNING`（`stage` 非终态）与 `DONE` 两类事件，断言流内先后出现。
2. `DONE` / `FAILED` 后 `TaskService.stream` 主动 `break`，Fake broker 观察 `unsubscribe`。
3. 客户端断开（`aclose`）后订阅被取消（`unsubscribed()` 为真）。
4. 非法事件（缺字段）只 `log_event` warning，`continue` 不中断。
5. 不依赖真实 redis / Celery，离线可跑；生产代码无 `MockDataFactory`。
