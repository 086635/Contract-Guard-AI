## ⑥ 实现规范

1. 指标定义：
   - 分类准确率 = 分类正确份数 / 有效样本数
   - 要素 micro-F1 = 以 `(key, normalized_value)` 为元素的 P/R 后取 F1（值做去空白/大小写归一）
   - 风险召回/精准 = 以 `category` 为元素，`recall = 命中gold / gold总数`、`precision = 命中gold / 系统输出总数`
2. **必须真实端到端**：真实解析 → 真实 RAG → 真实 LLM；`--cache` 只用于重复评分，首次必须真跑。
3. 外部依赖不可用时**skip 该分项**并在输出中标注 `skipped`，不得用假数据凑数。
4. 报告必须写明**样本量**，不得暗示统计显著性。
5. 不打印合同原文/密钥；输出只含 id、指标与安全摘要。
