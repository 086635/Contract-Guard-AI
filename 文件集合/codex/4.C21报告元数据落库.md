## ② 范围

### ✅ 做

- `generate` 从 DAL 聚合 `risks/conflicts/elements`，按 `4-3 §⑤.1` 组装 `gen_report` 载荷。
- `generate` 派发 `gen_report` 后继续写 `audit_tasks`，返回 `TaskProgress`。

- 仅任务成功且返回 `storagePath` 时落库；落库后运行时签发 `downloadUrl`。
- 更新 C16 测试夹具，使其能模拟 Celery DONE/RUNNING/FAILED 快照。

- ❌ 不让 worker 直连 PostgreSQL。
- ❌ 不把 `downloadUrl` 写入数据库。
- ❌ 不在任务未完成时返回空 `downloadUrl` 的假 `ReportData`。
- ❌ 不伪造未持久化的健康分或风险内容。

## ⑤ 接口规格

```python
class ReportService:
    async def generate(self, contract_id: UUID) -> TaskProgress: ...
    async def get(self, contract_id: UUID) -> ReportData: ...
```

`generate` 组装的载荷必须与 `4-3 §⑤.1` 对齐：

```python
{
    "contractId": str(contract_id),
    "generatedAt": datetime.now(UTC).isoformat(),
    "risks": [risk.model_dump(mode="json", by_alias=True) for risk in risks],
    "conflicts": [conflict.model_dump(mode="json", by_alias=True) for conflict in conflicts],
    "elements": [element.model_dump(mode="json", by_alias=True) for element in elements],
}
```

## ⑥ 实现规范

1. `generate` 先检查合同存在；再调用 `ResultService.risks/conflicts/elements` 组装载荷。
2. `generate` 派发参数必须是 `(str(contract_id), payload)`，并继续用 `TaskRepository.create` 创建 `GEN_REPORT` 任务行。
3. `get` 先查 `ReportRepository`；有报告则 presign 并返回 `DONE`。
4. 无报告时读取最新 `GEN_REPORT` 任务，用 `task.celery_task_id or str(task.id)` 读取 Celery 快照：
   - `DONE` 且 `storagePath` 非空：`ReportRepository.create`，commit，再 presign。
   - `FAILED`：抛 `ReportUnavailableError`，由路由映射 502。
   - `RUNNING` 或无快照：抛 `ReportNotFoundError`，由路由映射 404，进度走 `/tasks/{taskId}`。
5. `downloadUrl` 每次 `GET` 运行时签发，不落库。
6. 任务结果优先取顶层 `storagePath`；不得信任 result 之外的任意字段。
