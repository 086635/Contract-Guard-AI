# AGENTS.md · 施工文档区执行守则（`文件集合/codex/`）

> **读者**：在本目录树工作的 AI 代理，以及**把本目录的施工文档落地为代码**的 AI 代理。
> **定位**：本文件只解决两件事 ——
> ① 在本目录**写 / 改文档**时必须遵守的规则；
> ② 把一份子任务文档**落地为代码**时的执行流程（模式选择 / 前置核销 / 回填 / 汇报 / 交接 / 停手条件）。
>
> **本文件不是定义源，也不定义任何契约与任务。** 它与下列文件是**单向引用**关系：
>
> | 你要找的东西 | 去这里（唯一处） |
> |---|---|
> | 契约字段、接口签名、枚举取值 | **L1** `文件集合/report/RAG_MODULE_DESIGN.md` |

> | 环境、测试命令、仓库级红线、本机坑 | **仓库根 `AGENTS.md`** |
>
> 🔴 **冲突处理**：本文件与 `0.施工标准与定义归属.md` 或仓库根 `AGENTS.md` 冲突时，**一律以它们为准**，

## 2. 写 / 改文档的规则

### 2.1 新增一篇 `N-M` 文档 = 6 处同步（缺一处就是没写完）

| # | 去处 | 改什么 |
|---|---|---|
| 1 | 模块总纲 `§X.5` | 该行状态由 `⏳ 待落盘` → `✅ 已落盘`（带日期） |
| 2 | `0.§0.1.2` 模块登记表 | 该模块状态列（该模块子任务全部补齐时） |
| 3 | `0.§0.1.3` 末尾「对照情况」 | 补一句：`N-M`~`N-M'` 标题逐字一致 / 或已附「九项对照」表 |
| 4 | `0.§0.10` 引用表 | 新增一行：该文档 → 它引用了本标准的哪些节 |
| 5 | `0.§0.7.2 / §0.7.4` 定义归属表 | 该文档**新增了唯一处定义**时登记；仅引用则不登记 |
| 6 | 模块总纲 `§X.8` 模块边界 | 该文档改变了模块边界或依赖关系时 |

🔴 **只写正文、不做这 6 处同步 = 文档立刻落后于代码** —— 这正是本项目上一轮花大力气消除的问题。

### 2.2 正文硬规则

1. **9 节必须齐**（`0.§0.1.3`）：标题逐字一致 → 免「九项对照」表；不一致 → 必须补表，不适用项写 `不适用（原因）`，**不得静默省略**。
2. **不复述公共约定**：代码风格 / 配置规范 / 测试写法 / 落点 / DoD 一律写「见 `0.§X`」，**禁止复制粘贴**（否则产生第二处定义）。
3. **新术语先登记再使用**：任何要当契约名或唯一处使用的符号，必须先进 `0.§0.7` 定义归属表；未登记的一律只能写成「建议」。
4. **数字必须带证据**：写「实测」就要给命令与版本/日期（例：2026-09-21 实测、ruff 0.16.4 → 53 项）。**不得跨版本比较 ruff 数字。**
5. **状态标记语义固定**（不得自创）：
   - `✅ 已落盘`：文件存在、9 节完整、通过 §2.4 自检
   - `⏳ 待落盘`：仅总纲提到，文件不存在
   - `🟡 有但未验证`：代码存在但无测试/无实测证据
6. **只增不删**：已被别处引用的段落不删；确需推翻时**追加** `⚠️ 文档纠偏声明`（`0.§0.11.2` 规则 3）。
7. **不写未来时**：「将会支持」「后续会加」一律删掉 —— 改成明确的「不做（原因）」或写进 `§X.5` 的待办行。

### 2.3 引用格式（统一，便于 `rg` 校验）

```text
任务：T-A0 · 1-1 前置修复与契约补丁
引用：0.§0.8 落点表 · 0.§0.9 通用 DoD · 仓库根 AGENTS.md §4.1 测试命令
```

- 一律写「文件名 + 节号」，**不写**「前面那节」「如图」这类不可检索的描述
- 校验方式：`rg -n "0\.§0\.8" 文件集合/codex`

### 2.4 落盘技术规范（Windows 本机）

| 项 | 要求 |
|---|---|
| 编码 | **UTF-8 无 BOM** |
| 换行 | **LF**（不要 CRLF） |
| 乱码 | 文件里**不得出现 `\ufffd`**（替换字符） |
| 表格 | 每行以 `|` 结尾；表头下必须有分隔行 |
| 代码块 | 围栏必须成对 |
| 写文件 | Python `io.open(..., encoding="utf-8")`，或 PowerShell 单引号 here-string + `[IO.File]::WriteAllText($p, $t, (New-Object System.Text.UTF8Encoding($false)))` |
| 读文件 | **不要用 PowerShell 读含中文的文件**（GBK 乱码）→ 用 Python；或先 `[Console]::OutputEncoding=[Text.Encoding]::UTF8` |

**落盘后自检脚本**（全部计数正常才算干净）：

```python
import io
import os

FENCE = chr(96) * 3
FOLDER = "文件集合/codex"


def audit(path):
    raw = open(path, "rb").read()
    text = io.open(path, encoding="utf-8").read()
    lines = text.split("\n")
    fences = sum(1 for line in lines if line.startswith(FENCE))
    rows = [line for line in lines if line.startswith("|")]
    broken = [line for line in rows if not line.rstrip().endswith("|")]
    return dict(bytes=len(raw), fffd=text.count("\ufffd"), fences_even=fences % 2 == 0,
                rows=len(rows), broken=len(broken), crlf=raw.count(b"\r\n"))


for name in sorted(os.listdir(FOLDER)):
    if name.endswith(".md"):
        print(name, audit(os.path.join(FOLDER, name)))
```

> 中文 / emoji **不要在控制台直接 print**（会 `UnicodeEncodeError`，只是显示问题，文件内容通常是对的）；要核对就打印码点十六进制。

## 6. 反模式清单（做过一次就别再做）

| 反模式 | 后果 | 正确做法 |
|---|---|---|
| 照历史档案（`RAG_IMPLEMENTATION_GUIDE.md` 等）干活 | 建出废弃目录 `packages/rag-etl/` | 只读 L0~L2（`0.§0.11`） |
| 在同一份代码里实现第二个「唯一处」 | 两处定义漂移，解析层与检索层口径不一致 | 先查 `0.§0.7`，其它文件只 import |
| 文档没写就自己发明字段名 / 文件名 | 与契约层对不上，返工 | 停手问（§3.4-1） |
| 为了让断言过去而放宽阈值 | 指标失真，评测白做 | 停手汇报（§3.4-6） |
| 一个 goal 塞多个任务 | 失败时无法定位是哪一步坏的 | 一 goal 一任务（§3.1） |
| 只写正文、不做 6 处同步 | 下一轮又出现「文档落后于代码」 | 照 §2.1 清单走 |
| 声称「ruff 全绿」 | 与实测数字矛盾 | 报数字必带版本与日期（§2.2-4） |
