## ② 范围

### ✅ 做

- 校验 `AgentRewriteRequest`。
- 向 Celery 任务名 `rewrite` 发送请求负载。
- 等待 Celery backend 返回结构化结果，并返回 OpenAPI `RewriteResponse`。
- 对 `xRequestId` 做进程内有界幂等缓存。

### ❌ 不做

- 不在网关执行 LLM 或图。
- 不 import `ai_engine.graphs.rewrite_graph` 或 prompt 内部。
- 不修改 `ScopedClauseMemory` / `RagRuleContext`。

## ⑤ 接口规格

```python
class AgentService:
    async def rewrite(self, body: AgentRewriteRequest) -> RewriteData: ...
```

派发参数必须包含：

```text
contractId, clauseId, instruction, scopedMemory, ragContext, xRequestId
```

## ⑥ 实现规范

1. 网关只做请求校验、任务建行、Celery 派发与状态映射。
2. `xRequestId` 继续由幂等中间件消费，payload 保留原值。
3. LLM 超时映射为 504，不能吞掉错误。
4. 任务未注册或 broker 不可用时返回可诊断错误，不伪造改写结果。

## ⑦ 验收标准

| # | 断言 |
|---|---|
| 1 | 路由不再调用 MockDataFactory |
| 2 | Fake dispatcher 收到 `rewrite` 与完整 payload |
| 3 | 幂等重复请求不产生第二个任务 |
| 4 | broker 失败返回 5xx 且不返回假 Diff |
