## ② 范围

### ✅ 做

- 生成报告时检查合同存在并派发 `gen_report`。
- 返回 `ReportGenerateResponse` 的 `TaskProgress`。
- 获取报告时读取 `audit_reports`，运行时生成 GET 预签名 URL。
- 返回 `ReportData`，不把 `downloadUrl` 写入数据库。

### ❌ 不做

- 不实现 DOCX 生成，属 T-D3。
- 不把报告文件传给前端，MinIO 预签名负责下载。
- 不手改生成 DTO。

## ⑤ 接口规格

```python
class ReportService:
    async def generate(self, contract_id: UUID) -> TaskProgress: ...
    async def get(self, contract_id: UUID) -> ReportData: ...
```

## ⑥ 实现规范

1. 生成接口只派发 `gen_report`，不阻塞等待 DOCX。
2. `downloadUrl` 每次 GET 运行时生成，15 分钟有效。
3. 无报告返回 404；生成中仍 404，进度走 `/tasks/{taskId}`（T-D3 后由 C21 补写报告行）。
4. 对象不存在或 MinIO 异常返回可诊断 5xx，不返回假 URL。
5. `ReportData.status` 必须来自 `AuditReport` 或任务状态，不硬编码 DONE。
