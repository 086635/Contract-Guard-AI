## ⑤ 接口规格

不新增 HTTP 接口。字段和签名见生成类型与 `src/api/services.ts`：

| 既有入口 | 本轮消费方式 |
|---|---|
| `httpClient` 错误拦截器 | 具体 message 优先，缺失时 detail 回退；通用 409“数据冲突”保留详情提示 |
| `contractApi.list({page, pageSize})` | 按返回 total/pageSize 读取分页，不把第一页条数当成全部 |
| `contractApi.parseStatus(contractId)` | 仅对解析中的合同读取 RUNNING/DONE/FAILED；终态后重读摘要 |
| `taskApi.get(taskId)` | parse-status 的数据库快照为 RUNNING 时读取实际任务快照；结果信封 FAILED 同样显示失败，不当作成功 |
| `buildNavItems(contractId, isAdmin)` | 保持现有链接目标与角色过滤；无合同的审核/报告入口不标为当前页 |
