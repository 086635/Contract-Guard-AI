## ⑤ 接口规格

```text
Route contract:
  /contracts
  /contracts/:contractId/audit
  /contracts/:contractId/report
  /settings/rules
  /feedback

Audit data contract:
  ContractDetail + ContractElement[] + EnhancedRiskItem[]
  + CrossClauseConflict[] + SealSignatureDetection[] + TaskProgress
```

页面只接受路由 `contractId`；没有有效 ID 时返回合同中心或显示明确空态。

## ⑥ 实现规范

1. `AppShell` 的“审核工作台”“审核报告”必须根据当前选中合同或最近打开合同生成路径；没有选中合同时指向 `/contracts`。
2. `Audit` 使用 `useParams()` 的真实 ID；禁止 `DEFAULT_CONTRACT_ID` 常量保留在生产路径。
3. 六路请求并行加载；任一请求失败要保留已有数据并展示可重试错误，不能静默替换为固定 Mock。
4. Loading、Empty、Error 三态必须有明确文案；空结果不得触发报告或提交操作。
5. 路由深链刷新依赖 C36 的 SPA fallback，本卡只负责路由正确性。
6. 不改变 `Audit.tsx` 的 C33 报告处理函数所有权。
