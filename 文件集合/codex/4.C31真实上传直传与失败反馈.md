## ⑤ 接口规格

```ts
export const uploadApi = {
  presign(fileName: string, fileType: FileType): Promise<PresignData>;
  directUpload(presignedUrl: string, file: File): Promise<void>;
  submit(body: UploadBody): Promise<TaskProgress>;
};
```

交互状态：

```text
idle -> uploading -> parsing -> done
                    \-> failed -> retry
```

## ⑥ 实现规范

1. `directUpload()` 使用原始 `presignedUrl` 发起 PUT；不得修改 host、不得根据 `.local` 跳过。
2. PUT 失败、非 2xx、CORS、超时都抛出可读错误；`UploadPanel` 展示具体失败信息。
3. 上传成功后调用 `uploadApi.submit()`，再交给 C30 订阅任务进度。
4. `DONE` 才启用“进入审核”；`FAILED` 禁用进入并显示重试；重试不得复用失效的 presign。
5. 关闭弹窗时清理 subscription、timer 和未完成任务状态；不改变全局合同列表。
6. 不写死示例合同 ID；审核跳转只使用服务返回的真实 `contractId`。
