## ② 范围

### ✅ 做

- **新建** `doc_processor/layout/analyzer.py`：`LocalLayoutAnalyzer`（`LayoutAnalyzer` 的实现类）+ `build_layout_analyzer()`
- **规则优先**（数字版 PDF）：用 `pdfplumber` 的 `extract_text_lines()`（含 `chars`）取行的**字号 / 加粗**，用 `find_tables()` 取表格框，按 §5.4 的规则表判 `BlockType` 并**归并成块**
- 暴露两个**纯函数**供离线单测：`classify_line()` 与 `merge_blocks()`
- 扫描件 / 图片的**兜底**：无字号信息 → 全部 `UNKNOWN`（保底整页 `PARAGRAPH`）+ 一条 warning；若引擎提供版面能力（可选）→ 映射其区域类型
- 埋点：块数 / 各类别计数 / 耗时

### ❌ 不做

- ❌ **不改 `BlockType` / `LayoutBlock` 字段**（冻结；需要新字段时按标准 §0.11.2-3 走"追加纠偏声明"，不是本任务）
- ❌ **不写行聚类**：行切分一律用 `pdfplumber.extract_text_lines()`（与 3-6 同一原语）；本模块只在**行之上**做块归并

- ❌ 不做印章的**红色掩膜/文字识别**（属 3-8）；本模块只负责"哪里可能是印章区"
- ❌ 不做条款切分与要素抽取（属 3-4）；**不用** `CLAUSE_HEAD_RE` 判标题（条款编号 ≠ 标题）

- ❌ 不新增 `OcrSettings` 字段（3-2 是唯一处）；阈值一律用 §5.4 的**常量**（有消费方、可回归）

## ⑤ 接口规格

### 5.1 分析器

```python
# doc_processor/layout/analyzer.py
from __future__ import annotations

from dataclasses import dataclass
from pathlib import Path
from typing import Sequence

from doc_processor.layout import BlockType, LayoutBlock

BODY_SIZE_FALLBACK = 10.5      # 拿不到字号时的默认正文字号（pt）
TITLE_SIZE_RATIO = 1.2         # 字号 ≥ 正文中位数 × 该值 → TITLE
TITLE_MAX_CHARS = 40           # TITLE 的最长字符数（长行一定是正文）
MERGE_GAP_RATIO = 1.8          # 纵向间距 ≤ 行高 × 该值 → 视为同一段
FOOTER_ZONE_RATIO = 0.667      # 页面高度的下 1/3（签名区判定用，按"页高中位数"计算）


@dataclass(frozen=True, slots=True)
class StyledLine:
    """版面层的行载体（**局部类型，不进任何对外接口**）。

    前 6 个字段与 `TextLine` 同义（PDF_POINTS / 左上原点），后 3 个是版面专用。
    """

    page: int
    text: str
    x: float
    y: float
    width: float
    height: float
    size: float = BODY_SIZE_FALLBACK       # 行内字符的字号中位数
    bold: bool = False                     # 行内任一字符的字体名含 "Bold"
    in_table: bool = False                 # 行框与表格框相交


def classify_line(
    line: StyledLine,
    *,
    body_size: float,
    table_boxes: Sequence[tuple[float, float, float, float]] = (),
    page_height: float | None = None,
) -> BlockType:
    """判定单行的块类型（**规则表唯一处**，见 §5.4）。

    Args:
        line: 待判定行。
        body_size: 本页正文字号（行字号的中位数）。
        table_boxes: 本页表格框 `(x0, top, x1, bottom)` 列表（`pdfplumber.find_tables()` 产出）。
        page_height: 本页高度（判定"下 1/3 签名区"；为 `None` 时跳过该条规则）。

    Returns:
        `BlockType` 之一；空行返回 `BlockType.UNKNOWN`（由 `merge_blocks()` 丢弃）。
    """


def merge_blocks(lines: Sequence[StyledLine], *, page: int) -> list[LayoutBlock]:
    """把同页相邻同类行归并为块（**归并规则唯一处**，见 §5.4）。

    Args:
        lines: 同一页的行（按阅读顺序）。
        page: 页码（1-based）。

    Returns:
        `LayoutBlock` 列表（顺序 = 阅读顺序）。
    """


class LocalLayoutAnalyzer(LayoutAnalyzer):
    """规则优先的版面分析实现。

    设计要点：
    1. 规则优先：数字版 PDF 的字号 / 加粗 / 表格线**本来就在文件里**，不需要模型；
    2. 只做块归并，不做行聚类（行的切分交给 pdfplumber，与 3-6 同源）；
    3. 扫描件兜底：无字号信息时退化为 UNKNOWN，**不静默返回空**（前端需要占位块）。
    """

    def __init__(self, settings: OcrSettings | None = None, router: DocRouter | None = None) -> None: ...

    def analyze(self, pdf_path: str) -> list[LayoutBlock]:
        """对 PDF 做版面分析（契约方法）。

        Raises:
            DocProcessorError: 文件不可读（沿用 3-2 的错误家族，**不新造异常**）。
        """

    def analyze_lines(self, lines: Sequence[StyledLine], *, page: int, page_height: float | None = None,
                      table_boxes: Sequence[tuple[float, float, float, float]] = ()) -> list[LayoutBlock]:
        """纯函数入口：由已构造好的行做单页版面分析（便于单测，不碰文件系统）。"""


def build_layout_analyzer(settings: OcrSettings | None = None) -> LayoutAnalyzer:
    """工厂：返回本机实现（与 3-6 的接线约定）。"""
```

### 5.2 行来源（**唯一处**：与 3-6 同源）

```text
每页的行与样式均来自 pdfplumber：
  page.extract_text_lines()   → 行文本 + 行框（x0/top/x1/bottom）+ chars
  line["chars"]  → size = median(c["size"]) ；bold = any("Bold" in c["fontname"])
  page.find_tables()          → 表格框 (bbox)；行框与其相交 → in_table=True
坐标**已是 PDF_POINTS**（pdfplumber 原生 72dpi、左上原点）→ 本模块**零换算**。
```

### 5.3 常量表（**唯一处**）

| 常量 | 值 | 消费方 |
|---|---|---|
| `BODY_SIZE_FALLBACK` | `10.5` | 字号缺失时的正文基准 |
| `TITLE_SIZE_RATIO` | `1.2` | 规则 4（TITLE 判定） |
| `TITLE_MAX_CHARS` | `40` | 规则 4（长行不可能是标题） |
| `MERGE_GAP_RATIO` | `1.8` | 归并规则（同段判定） |
| `FOOTER_ZONE_RATIO` | `0.667` | 规则 2（签名区判定） |

> 这 5 个常量**不进** `OcrSettings`：它们不是可调业务参数，而是**规则阈值**（改动会影响回归基线）。
> 真要调 → 改本表 + 跑 §⑧ 的 `test_rule_table_*` 全量回归。

### 5.4 规则表（**唯一处**：类型判定与块归并）

**判定优先级（命中即停）**：

| # | 条件 | 结果 |
|---|---|---|
| 0 | `text.strip() == ""` | `UNKNOWN`（由归并阶段丢弃，**不产出空块**） |
| 1 | `in_table` 或与 `table_boxes` 相交 | `TABLE` |
| 2 | 含签名关键词（`甲方`/`乙方`/`签字`/`盖章`/`签署` **且** 含 `日期`/`年`月`日` 之一 或 行内容长度 ≤ 20）**且** 行位于页面下 1/3 | `SIGNATURE` |
| 3 | 含印章关键词（`印章`/`（章）`/`加盖`） | `SEAL` |
| 4 | `size ≥ body_size × TITLE_SIZE_RATIO` **或** `bold`，且 `len(text.strip()) ≤ TITLE_MAX_CHARS` | `TITLE` |
| 5 | 其余非空行 | `PARAGRAPH` |

> `body_size` = **本页所有非空行字号的中位数**；取不到时用 `BODY_SIZE_FALLBACK`。
> `SIGNATURE` 的"下 1/3"按 `page_height × FOOTER_ZONE_RATIO` 判定；`page_height` 未知时**跳过规则 2**
> （宁可不判签名区，也不误判正文中的"甲方"引用）。

**归并规则**：

```text
顺序扫描本页行：
  1. 计算行的判定类型；UNKNOWN（空行）→ 结束当前块（空行是天然的段落边界）；
  2. 与当前块**同类型** 且 纵向间距（本行 y - 上一行 y - 上一行 height）≤ 行高 × MERGE_GAP_RATIO
     → 并入当前块：bbox = 并集；text = 各行文本以 "\n" 拼接（与 3-6 的全文分隔符一致）；
  3. 否则 → 收尾当前块，开新块；
  4. 类型为 TITLE / SEAL / SIGNATURE 的行**一律独立成块**（不与相邻块合并）。
块坐标 = 各行框并集；`LayoutBlock.page` = 入参 page；`text` 保留原文（不 strip 内部空白）。
```

## ⑥ 实现规范

1. 🔴 **规则优先，模型兜底**：`RouteKind.PDF_NATIVE` → 纯规则；`PDF_SCANNED` / `IMAGE` → 无字号信息，全部行判 `UNKNOWN` 并保底产出**一个整页 `PARAGRAPH` 块**（前端要有东西可画）+ 一条 warning。**禁止**在规则法可用时去加载重模型。
2. 🔴 **不写行聚类**：行只能来自 `extract_text_lines()`（与 3-6 同一原语）。自定义 y 聚类会产生"两种行边界"，是 3-6 §⑨-2 已明令禁止的事。
3. 🔴 **坐标零换算**：源坐标已是 PDF_POINTS，本模块**不得**出现 `72 /`、`src_dpi` 等缩放（§⑦ 断言 5）。
4. 🔴 **块不重叠、不空洞化**：块的 `text` 只能是其包含行的原文拼接；**不得**为了"好看"把不相邻的行塞进同一块。
5. 🔴 **不确定就不判**：`page_height` 未知 → 跳过 SIGNATURE 规则；字号全缺 → 用 `BODY_SIZE_FALLBACK` 并记 warning。**禁止**用"猜测的版面"覆盖可确定的文本。
6. ⚠️ **空行是边界不是内容**：空行结束当前块，但**不产出** `UNKNOWN` 块（前端会出现空白框）。
7. ⚠️ **表格取整块**：`TABLE` 块的行按表格框归并（同一表格内的多行合成**一个**块），与相邻段落不合并。
8. ⚠️ **扫描件兜底不算失败**：本模块是 P1 增强项，兜底结果照常返回，不置 `DEGRADED`（与 3-6 的状态判定表互不影响）。
9. ⚠️ **打点**：命名空间 `get_logger("doc_processor.layout.analyzer")`；`log_event("layout.analyze", page=..., blocks=..., titles=..., tables=..., latency_ms=...)`。
10. ⚠️ **性能**：`find_tables()` 是页级重活，**每页只调一次**；块归并是线性扫描（`O(n)`），不得对每行重复调用 `find_tables()`。

## ⑨ 避坑清单

| # | 坑 | 说明 |
|---|---|---|
| 1 | 给所有 PDF 都上 PP-Structure | 数字版 PDF 的字号/表格线本来就在文件里；上模型只是更慢、更不可复现（模块总纲 §3.3 的"规则优先"） |
| 2 | 自己写 y 聚类切行 | 与 3-6 的 `extract_text_lines()` 产生**两套行边界**；块与行会对不上 |
| 3 | 用 `CLAUSE_HEAD_RE` 判标题 | 条款编号 ≠ 标题；层级规则属 3-4，重复实现会让"第几条"两处不一致 |
| 4 | 把 `StyledLine` 导出到包出口 | 会变成事实上的第二套行契约，后续一定有人拿它当接口用 |
| 5 | 空行产出 `UNKNOWN` 块 | 前端会画出空白框；空行只做**边界** |
| 6 | 在 `page_height` 未知时硬判签名区 | 正文里"甲方"引用会被误判成签名区 |
| 7 | 每行都调 `find_tables()` | 页级重活；每页一次，行与表格框的相交判定在内存里做 |
| 8 | 块 `text` 用 `" "` 拼接 | 与 3-6 全文的 `"\n"` 不一致，前端按块取文本时行号会错位 |
| 9 | 扫描件兜底返回 `[]` | 前端拿不到任何块会显示空白页；必须保底一个整页块 |
| 10 | 把阈值塞进 `OcrSettings` | 规则阈值不是业务配置；进配置就会有人在不同环境调到不同值，基线无法复现 |
| 11 | 顺手改 `LayoutBlock` 加 `confidence` | 契约冻结；需要新字段时按标准 §0.11.2-3 走追加声明，并在 §0.7 登记 |
