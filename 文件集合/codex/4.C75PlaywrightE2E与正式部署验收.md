> **本轮修复的验收阻塞项**（3 项真实产品缺陷 + 1 项测试自身）：
> 1. `docker/docker-compose.c75.yml`：minio/minio-init 未接同套 secrets → 与 api 密钥不一致 → 预签名 PUT 恒 403；已接线修复。
> 2. `apps/web-ui/src/api/services.ts`：`rewriteClause` 走全局 axios 30s 超时 < 真实 LLM 改写 ~46s → 前端先超时、`采用这版修改` 永不出现；已显式放宽到 `timeout: 180_000`。
> 3. `apps/web-ui/src/index.css`：`.modal` 无 `max-height`/`overflow`，改写结果（diff + 引用）撑高后底部按钮溢出视口不可点（真实用户同样点不到）；已加 `max-height: calc(100vh - 48px); overflow-y: auto;`。
> 4. `apps/web-ui/e2e/audit_rewrite_commit.spec.ts`（链路 6）：原等待信号「按钮变『处理中…』」早于 presign/PUT，随后 `reload` 打断三步上传；改为等 `/api/v1/contracts/upload` 响应再 reload。
