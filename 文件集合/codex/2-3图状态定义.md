> **禁止**把 `ClauseInput` 反向塞回 `doc_processor`。

## ⑤ 接口规格

```python
# ai_engine/graphs/state.py
from __future__ import annotations

import operator
from typing import Annotated, Literal, TypedDict

from ai_engine.agents.auditor import EnhancedRiskItem
from ai_engine.agents.conflict import CrossClauseConflict
from rag_contracts.enums import ContractType

# 6 阶段（与 2.AGENT模块.md §2.1.3 拓扑逐字一致；SSE stage / 埋点名共用此常量）
AUDIT_STAGES: tuple[str, ...] = (
    "classify",
    "extract",
    "risk",
    "conflict",
    "standard_compare",
    "report_draft",
)


class ClauseInput(TypedDict):
    """审核图的最小条款输入面（由 worker 从 ParsedClause 适配而来）。"""

    clause_id: str
    label: str                  # 形如「第三条」/「6.2.1」，原文标题
    text: str                   # 条款正文
    level: int                  # AST 层级，0=顶层
    parent_id: str | None
    page_no: int | None
    bbox: dict | None           # PDF_POINTS（缺坐标时为 None，不得伪造）


class StageLog(TypedDict):
    """单阶段执行记录（埋点与 SSE 共用）。"""

    stage: str                  # ∈ AUDIT_STAGES
    status: str                 # OK | DEGRADED | SKIPPED
    latency_ms: int
    detail: str                 # 一句中文说明（失败原因 / 跳过原因）


class AuditState(TypedDict, total=False):
    """审核图状态。

    🔴 只放**可序列化数据**：str / int / float / bool / list / dict / Pydantic 模型。
    禁止放模型实例、客户端、连接对象、Settings —— 那些走 `GraphDeps` 闭包（见 2-4）。
    """

    # —— 入口注入（只读）——
    contract_id: str
    trace_id: str               # 必填：无 trace_id 不允许进图
    tolerance: str              # STRICT | BALANCED | LOOSE
    clauses: list[ClauseInput]

    # —— 各节点产出 ——
    contract_type: ContractType | None
    elements: list[dict]                                        # 要素（含 bbox/confidence）
    risks: Annotated[list[EnhancedRiskItem], operator.add]
    conflicts: Annotated[list[CrossClauseConflict], operator.add]
    missing_clauses: Annotated[list[dict], operator.add]        # 对齐 openapi MissingClause
    report_draft: dict
    health_score: int

    # —— 观测与降级 ——
    warnings: Annotated[list[str], operator.add]
    stage_log: Annotated[list[StageLog], operator.add]
    llm_calls: Annotated[int, operator.add]
    rag_calls: Annotated[int, operator.add]


class RewriteState(TypedDict, total=False):
    """改写图状态（`thread_id = f"{contract_id}:{clause_id}"`，见 2-7）。"""

    contract_id: str
    clause_id: str
    trace_id: str
    instruction: str
    before: str
    after: str
    diff: dict
    reasoning_steps: list[dict]
    citations: list[dict]
    rag_context: dict | None
    warnings: Annotated[list[str], operator.add]
    stage_log: Annotated[list[StageLog], operator.add]


def new_audit_state(
    contract_id: str,
    clauses: list[ClauseInput],
    *,
    trace_id: str,
    tolerance: str = "BALANCED",
) -> AuditState:
    """构造审核图初始状态。

    Args:
        contract_id: 合同 ID。
        clauses: 条款输入列表（空列表合法，图会走"无条款"降级路径）。
        trace_id: 全链路追踪 ID（必填）。
        tolerance: 风险容忍度，默认 BALANCED。

    Returns:
        已注入 `trace_id` / `warnings=[]` / `stage_log=[]` / 计数器的初始状态。
    """
```

## ⑥ 实现规范

1. 🔴 **reducer 只加在"多节点追加"的字段上**：`risks` / `conflicts` / `missing_clauses` / `warnings` / `stage_log` / `llm_calls` / `rag_calls`。
   其余字段（`contract_type` / `elements` / `report_draft` / `health_score`）是**覆盖型**——加 `operator.add` 会让"重跑某阶段"变成数据重复。
2. 🔴 **`total=False` 是刻意的**：每个节点只返回自己产出的增量 dict（`return {"risks": [...]} `），不必回填全部字段。
   ⚠️ 因此**节点不得**假设其它键存在，读之前一律 `.get()` 或 `state.get("clauses", [])`。
3. 🔴 **`trace_id` 必填**：`new_audit_state` 的 `trace_id` 是关键字必传参数（不设默认值），防止"忘了传导致埋点断链"。
4. 🔴 **时间戳统一 `from datetime import UTC, datetime` + `datetime.now(UTC).isoformat()`**（**不要**用 `timezone.utc`，会新增 ruff `UP017`）。
5. 🔴 **`ClauseInput.bbox` 为 `dict` 而非 `BBox`**：审核图只做转发，不解析坐标；`BBox` 的唯一定义处是 `rag_contracts/chunk.py`，需要强类型时在那里转。
6. ⚠️ **`AUDIT_STAGES` 是阶段名的唯一处**：SSE 的 `stage`、`stage_log[].stage`、埋点事件名后缀（`audit.classify` 等）全部由它派生，**禁止**在节点里写字符串字面量。
7. ⚠️ **`llm_calls` / `rag_calls` 用 `Annotated[int, operator.add]`**：节点返回 `{"llm_calls": 1}` 即自动累加——这让 `2-4` 的"调用预算"断言可测。
8. ⚠️ 所有公开符号进 `graphs/__init__.py` 的 `__all__`（标准 §0.9 DoD）。

## ⑨ 避坑清单

| # | 坑 | 说明 |
|---|---|---|
| 1 | 把 `GraphDeps` / `RagSettings` / 模型实例放进 state | 检查点无法序列化，`graph.invoke` 直接报错。依赖走闭包（`2-4` §⑤） |
| 2 | 给 `elements` / `report_draft` 也加 `operator.add` | 重跑阶段会叠加脏数据；追加型字段**只有 7 个** |
| 3 | 节点里写 `state["clauses"]` | `total=False` 下该键可能不存在 → `KeyError`。统一 `.get(..., [])` |
| 4 | 自定义 `RiskTolerance` 枚举 | 与 `openapi.yaml` 形成第二处定义（标准 §0.7 禁令）。用 `str` + 取值表 |
| 5 | 复制 `ScopedClauseMemory` 到 `graphs/state.py` | 这正是 L3 **F7**（两份定义）的成因；本文件只 import |
| 6 | 用 `timezone.utc` 打时间戳 | 触发 ruff `UP017`（本仓已有 3 处历史遗留，不新增） |
| 7 | 把 `ParsedClause` 直接搬成 `ClauseInput` | 会把解析层契约拖进 Agent 包；两者字段与语义不同（§③） |
| 8 | 阶段名写成字符串字面量 | 与 `AUDIT_STAGES` 漂移后，SSE 前端映射会静默失配 |
