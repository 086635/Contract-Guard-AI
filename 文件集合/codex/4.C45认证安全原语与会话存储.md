## ⑥ 实现规范

1. JWT 密钥必须来自配置，禁止硬编码。
2. refresh token 只保存哈希，轮换后旧 token 立刻失效。
3. 校验失败统一抛领域异常，不泄露内部原因。
4. 测试使用固定时钟和可注入随机源。

## ⑦ 验收标准

| # | 断言 |
|---|---|

| 2 | 过期/篡改/错误 audience JWT 拒绝 |
| 3 | refresh 只能使用一次 |
| 4 | 登出后旧 refresh 不可用 |
