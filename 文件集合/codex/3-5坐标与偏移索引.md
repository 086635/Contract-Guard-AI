## ⑤ 接口规格

```python
# doc_processor/aligner/aligner.py
class LocalBBoxAligner(BBoxAligner):
    """字符偏移 ↔ BBox 索引器。

    设计要点：
    1. **半开区间**：`locate(start, end)` 覆盖 `[start, end)`（与前端 `selection` 语义一致）。
    2. **二分查找**：索引按 `char_start` 升序，定位用 `bisect`，复杂度 `O(log n + k)`。
    3. **永不抛异常**：未索引 / 区间非法 / 越界 → 返回 `[]` 或裁剪后的结果。
    """

    def index_text_offsets(self, lines: Sequence[TextLine]) -> None:
        """建立索引（幂等；重复调用以最后一次为准）。

        Args:
            lines: 行序列（顺序任意，内部按 `char_start` 排序副本）。
        """

    def locate(self, start: int, end: int) -> list[NormalizedBBox]:
        """把字符区间换算为 BBox 列表（按阅读顺序）。

        Args:
            start: 起始偏移（含）。
            end: 结束偏移（**不含**）。

        Returns:
            覆盖区间内所有行的 BBox；无命中返回 `[]`。

        Raises:
            不抛异常（契约：前端高频调用，必须稳定）。
        """

    @property
    def indexed(self) -> bool:
        """是否已建立索引。"""

    @property
    def total_chars(self) -> int:
        """已索引文本的总长度（`max(char_end)`）。"""


def build_bbox_aligner(settings: OcrSettings | None = None) -> BBoxAligner:
    """工厂：返回本机实现。"""
```

### 5.2 区间语义与查找算法（**唯一处**）

```text
索引：_starts = [line.char_start ...]（升序），_lines 与之对齐
查找：i = bisect_right(_starts, start) - 1 ；从 max(i, 0) 起向后扫描，
      当 line.char_start >= end 时停止（因已排序，可安全早停）
命中判定：line.char_end > start 且 line.char_start < end      # 半开区间重叠
裁剪：start = clamp(start, 0, total_chars)；end = clamp(end, 0, total_chars)
      start >= end → 返回 []
去重：相同 (page, x, y, width, height) 只保留一次
构造：NormalizedBBox(page=..., x=..., y=..., width=..., height=..., coordinate_system="PDF_POINTS")
```

> 🔴 **为什么不去"补齐"空洞**：跨页/表格/图片区域可能在字符序列中间形成空洞，
> 那是**真实版面**。补齐会画出覆盖整页的错误高亮框 —— 宁缺毋滥。

## ⑥ 实现规范

1. 🔴 **二分查找**：禁止在 `locate()` 里 `for line in self._lines` 全扫（前端高频调用）。
2. 🔴 **不修改入参**：排序用 `sorted(lines, key=...)` 生成副本；调用方可能复用原列表。
3. 🔴 **`NormalizedBBox` 只在本文件构造**（`to_pdf_points` 内部除外）：其它模块需要 BBox 时一律调 `locate()`。
4. 🔴 **不重写缩放**：本文件**不得**出现 `72 / dpi` 之类换算（坐标已是 PDF_POINTS）；
   §⑦.5 有源码级断言。
5. 🔴 **未索引不抛异常**：`locate()` 在 `indexed is False` 时返回 `[]`，并**只记一次** warning（避免刷屏）。
6. 🔴 **乱序/重叠的容忍**：`char_start` 非单调时按其排序；重叠区间允许（跨页）。
   非法数据（`char_end < char_start`）→ 跳过该行 + warning。
7. 🔴 **线程安全的只读契约**：`index_text_offsets()` 完成后，`locate()` 为纯只读；**不得**在 `locate()` 里惰性重建索引。
8. 🔴 **打点**：`log_event("ocr.align.locate", span=end-start, hits=len(boxes), latency_ms=...)`；
   命名空间 `get_logger("doc_processor.aligner.aligner")`。
9. ⚠️ **精度**：坐标四舍五入到 0.1 pt（前端 Canvas 无需更高精度），并在文档回填里记录该约定。

## ⑨ 避坑清单

| # | 坑 | 说明 |
|---|---|---|
| 1 | 用闭区间语义 | 前端 `selection` 是半开区间；差一位就会高亮多一个字 |
| 2 | 线性扫描 | 前端每次悬停都会调用；必须二分 |
| 3 | 返回整条条款的框冒充"命中句" | 模块总纲 §3.4.2 明确：`ContractChunk.bbox` 是**整条条款**的框，两者不可互换 |
| 4 | 为空洞"补齐"大框 | 会画出覆盖整页的错误高亮；真实版面允许空洞 |
| 5 | 在 `aligner.py` 里再写一份缩放 | 缩放唯一处是 `to_pdf_points()`；断言 5 会抓 |
| 6 | 修改调用方传入的 list | 用 `sorted()` 副本；否则上游分页逻辑会错乱 |
| 7 | 未索引时抛异常 | 前端初始化时序不保证；必须返回 `[]` |
| 8 | 在 `locate()` 里重建索引 | 破坏只读契约，且会让高频调用变成 O(n log n) |
| 9 | 记录超长 span 的完整文本 | 日志只需长度与命中数，避免把合同原文写进日志 |
