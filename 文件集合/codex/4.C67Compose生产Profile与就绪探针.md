## ⑤ 接口规格

```text
GET /health/live -> process alive
GET /health/ready -> DB/Redis/MinIO/Qdrant status
prod ports: 80,443 only
```

## ⑥ 实现规范

1. readiness 失败返回 503 且不泄露连接串。
2. 外部服务不可用标 ready=false。
3. 依赖服务使用 compose healthcheck。
4. 资源限制可配置。

### 实测后回填·断言逐条

| # | 断言 | 实测结果 |
|---|---|---|
| 1 | prod 端口限制通过 | 通过：`test_only_public_ports`（`docker compose config --format json` 合并后**只有 nginx 发布 80/443**；postgres/redis/qdrant/minio/api/web/clamav 均 `ports: !override []`）+ `test_development_compose_kept`（开发 compose 端口仍在，叠加 prod 后被收敛） |
