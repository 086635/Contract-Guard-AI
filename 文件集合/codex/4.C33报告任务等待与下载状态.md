## ⑤ 接口规格

```ts
export const reportApi = {
  get(contractId: string): Promise<ReportData>;
  generate(contractId: string): Promise<TaskProgress>;
};
```

页面状态：

```text
未生成 -> 生成中 -> 可下载
           \-> 失败 -> 重新生成
```

## ⑥ 实现规范

1. `generateReport()` 保存返回的 `taskId`，调用 C30 `taskApi.subscribe()`；不要在响应后立即导航。
2. `DONE` 后调用 `reportApi.get()` 或在报告页重新加载；`FAILED` 展示任务错误并保留合同上下文。
3. `Report.tsx` 初次 GET 404/未生成时显示“报告生成中/尚未生成”，不要和网络失败混为一类。
4. 重新生成期间禁用重复按钮；任务完成后刷新报告元数据。
5. `openDownload()` 只在 `downloadUrl` 非空且可解析时执行；不得因 `.local` 回退到打印。
6. 页面卸载或重新生成前取消旧订阅，避免旧任务覆盖新状态。

## ⑦ 验收标准

| # | 断言 |
|---|---|
| 1 | 生成请求返回后仍停留/等待，只有 DONE 后才加载报告 |
| 2 | RUNNING、未生成、FAILED、DONE 四类状态可见且区分 |
| 3 | 重新生成成功后报告可刷新读取 |
| 4 | 真实 `downloadUrl` 可下载 DOCX；无 URL 时按钮禁用 |
| 5 | 源码无 `.local` 打印回退、无固定合同 UUID |
| 6 | 旧订阅不会覆盖新一轮任务状态 |
