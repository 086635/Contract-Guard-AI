| `rewrite` | `instruction` / `before` / `recent_dialog` / `rag_context` |

## ⑥ 实现规范

1. 模板名等于文件名 stem，统一 ASCII snake_case。
2. 占位符只允许 `{{snake_case}}`，不得出现 Jinja 控制语法。
3. 每个模板按“角色 / 任务 / 输出 / 约束”四段组织。
4. 输出段必须写“严格输出 JSON”和字段名清单，不复制 JSON Schema。
5. 每个模板必须出现 `【缺失标准对照】`，表达不得虚构依据的约束。
6. 文件 UTF-8 无 BOM、LF，正文建议不超过 1200 字符。
7. 模板不得写死具体法条编号、模型名、供应商或真实合同主体。
8. `loader.py` 不改；缺键仍由既有 `render()` 抛 `KeyError`。
