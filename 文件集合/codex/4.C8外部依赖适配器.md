## ⑤ 接口规格

```python
class TaskKind(StrEnum):
    PARSE_DOC = "parse_doc"
    RUN_AUDIT = "run_audit"
    GEN_REPORT = "gen_report"
    REWRITE = "rewrite"

class MinioObjectStorage:
    def presign_put(self, file_key: str, expires_s: int = 600) -> str: ...
    def presign_get(self, file_key: str, expires_s: int = 900) -> str: ...
    def stat_object(self, file_key: str) -> StoredObjectInfo: ...

class CeleryTaskDispatcher:
    def send(self, task_name: str, *, args: tuple[object, ...] = (), task_id: str | None = None) -> str: ...
    def get_status(self, task_id: str) -> TaskStatusSnapshot | None: ...

class RedisProgressBroker:
    def subscribe(self, task_id: str) -> AsyncIterator[dict[str, object]]: ...
```

Redis channel：

```text
task_progress:{task_id}
```

## ⑥ 实现规范

1. MinIO bucket 不存在时按需创建或给出配置错误，不静默生成无效 URL。
2. `send()` 只返回 Celery task id；不在网关等待结果。
3. SSE 订阅超时、Redis 断连、取消订阅时必须退出异步生成器。
4. 事件负载必须是 OpenAPI `TaskProgress` 的 camelCase JSON。
5. 外部 SDK 只在 Adapter 文件中 import。

## ⑦ 验收标准

| # | 断言 |
|---|---|
| 1 | presign PUT 默认 600 秒，GET 默认 900 秒 |
| 2 | dispatcher 只发送四个登记任务名 |
| 3 | Redis 订阅 channel 名固定为 `task_progress:{task_id}` |
| 4 | Redis 断开时生成器退出，不忙循环 |
| 5 | C7/C9~C17 不直接 import MinIO/Celery/Redis SDK |

### 实测后回填

| 项 | 实测值 |
|---|---|
| presign 适配 | ✅ PUT 默认 600 秒、GET 默认 900 秒；自定义 120 秒生效，非法 0 秒抛 `ValueError`（2026-09-27） |
| dispatch 适配 | ✅ `TaskKind` 四任务名可派发；未知任务名抛 `ValueError`；Fake Celery 返回 task id（2026-09-27） |
| Redis 订阅 | ✅ channel 固定为 `task_progress:{task_id}`；RUNNING→DONE 逐条产出，DONE 后退出并清理订阅（2026-09-27） |
| SDK 隔离 | ✅ 只有三个 Adapter 文件 import MinIO/Celery/Redis；C8 测试 **4 passed in 0.89s**（2026-09-27） |
