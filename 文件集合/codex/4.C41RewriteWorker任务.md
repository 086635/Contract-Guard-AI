## ⑤ 接口规格

```python
@celery_app.task(name="rewrite", bind=True)
def rewrite_task(self, payload: dict) -> dict:
    """把 OpenAPI AgentRewriteRequest 转换为 RewriteData JSON。"""
```

成功结果：

```json
{
  "taskId": "<xRequestId>",
  "clauseId": "<clauseId>",
  "before": "...",
  "after": "...",
  "diff": {"type":"DIFF","before":"...","after":"...","clauseId":"..."},
  "reasoningSteps": [],
  "citations": [],
  "updatedAt": "ISO-8601"
}
```

失败：

- 校验失败、模型不可用、graph 异常都必须转为 Celery `FAILED`；
- 不允许把异常栈或内部 Prompt 原样返回给前端；
- 结果字段保持 JSON 可序列化。

## ⑥ 实现规范

1. 使用 `AgentRewriteRequest.model_validate(payload)`；非法 payload 不进入 graph。
2. 调用 `rewrite_clause()`，禁止 worker 内直接运行 graph 或 `RagTool`。
3. 成功结果用 `model_dump(mode="json", by_alias=True)`，必须与 `RewriteData` 字段一致。
4. 失败统一捕获 `RewriteUnavailableError` 与未预期异常，记录 `log_event` 含 `trace_id`，再让 Celery 任务失败；不得返回半成品。
5. `worker/main.py` 的 include 只增加模块名，不改变 Celery serializer/backend 配置。
6. 不与 C15 的 gateway 缓存重复实现；Worker 只负责执行和返回结果。
