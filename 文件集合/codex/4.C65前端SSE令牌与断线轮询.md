## ② 范围

### ✅ 做

- 订阅前请求 stream token，再拼 EventSource URL。
- token 过期/断线时重新取 token 或回退 2 秒轮询。
- 终态关闭订阅，组件卸载清理。
- 权限/任务不存在错误展示安全提示。

### ❌ 不做

- 不把 access token 拼 URL。
- 不断线后无限重连。
- 不忽略 403/404。

## ⑤ 接口规格

```text
taskApi.subscribe(taskId,onProgress,onError)->unsubscribe
内部：POST stream-token -> EventSource(?streamToken=...)
```

## ⑥ 实现规范

1. 每次重连必须请求新 token。
2. 终态立即清理 timer/source。
3. 网络错误保留轮询兜底。
4. 不记录 token。
