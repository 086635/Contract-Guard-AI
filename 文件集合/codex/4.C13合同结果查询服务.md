## ⑤ 接口规格

```python
class ResultService:
    async def parse_status(self, contract_id: UUID) -> TaskProgress: ...
    async def elements(self, contract_id: UUID) -> list[ContractElement]: ...
    async def risks(self, contract_id: UUID, level: RiskLevel | None) -> list[EnhancedRiskItem]: ...
    async def conflicts(self, contract_id: UUID) -> list[CrossClauseConflict]: ...
    async def seals(self, contract_id: UUID) -> list[SealSignatureDetection]: ...
```

投影白名单：

```text
ContractChunk.section_id → ContractElement.key
ContractChunk.title/category → ContractElement.label
ContractChunk.text → ContractElement.value
ContractChunk.bbox → ContractElement.bbox
isCustom = False
```

## ⑥ 实现规范

1. 无数据统一返回空数组，不返回 `None`。
2. `level` 只接受 `HIGH/MEDIUM/LOW`，大小写规范化在 Service 完成。
3. parse-status 无任务时返回 404 或明确的空状态，不能伪造 DONE。
4. 不使用 `MockDataFactory`，不在路由中手拼列表。
5. `ContractChunk` 投影必须在 `projector.py` 保留唯一实现。
