## ⑥ 实现规范

1. 字段默认值兼容旧任务。
2. 重试只对幂等任务开放。
3. 超时和失败写 errorCode。
4. 迁移 downgrade 可回退新增列。

### 实测后回填·断言逐条

| # | 断言 | 实测结果 |
|---|---|---|
| 1 | 旧任务升级后字段可空 | 通过：`test_task_reliability_fields`（7 列齐备；`attempt_count`/`max_attempts` NOT NULL + 默认值，期余 5 列可空）+ `test_task_migration_roundtrip`（升级 SQL 新增列、降级 SQL 完整回退） |
| 2 | acks_late/prefetch/超时配置生效 | 通过：`test_celery_reliability_config` / `test_acks_late_config`（`task_acks_late=True`、`task_reject_on_worker_lost=True`、`worker_prefetch_multiplier=1`）/ `test_soft_time_limit`（软 600 < 硬 900，环境变量可覆写） |
| 3 | 重试次数不超过 max_attempts | 通过：`test_retry_cap`（退避 5/10/20s 指数增长并封顶 300s；到 `max_attempts` 后 `can_retry=False`）、`test_retry_then_success`、`test_retry_exhausted_failed`（1+2=3 次尝试恰好用满，不无限重试） |
| 4 | 外部 Status 不变 | 通过：`test_external_status_enum_unchanged`（`Status` 仍 RUNNING/DONE/FAILED；OpenAPI 内联任务状态枚举不变；`PENDING` 只属于独立的 `PreviewStatus`） |

> 附加：`test_task_type_whitelist_covers_dispatched_tasks`（白名单含 `SCAN_UPLOAD`/`CONVERT_DOC`）、`test_retry_only_for_idempotent_tasks`（只对 3 个可重放任务、只对 `OSError`/`TimeoutError`、上限有限）、`test_reliability_params_are_env_overridable`。
> 本轮同时**修复**：`audit_task_type` CHECK 与 `VARCHAR(10)` 会拒绝/截断 `SCAN_UPLOAD`、`CONVERT_DOC`（C57 扫描档、C59 转换任务原先无法落库）。
