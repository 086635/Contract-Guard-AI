## ⑤ 接口规格

```python
class RuleRepository:
    async def list(self, category=None) -> list[RuleRecord]: ...
    async def get(self, rule_id) -> RuleRecord | None: ...
    async def upsert(self, rule: RuleUpsert) -> RuleRecord: ...

class FeedbackRepository:
    async def create(self, target_type, target_id, verdict, user_comment) -> FeedbackRecord: ...
    async def list(self, target_type=None) -> list[FeedbackRecord]: ...
```

## ⑥ 实现规范

1. `FeedbackRepository.create` 校验 `verdict ∈ FeedbackVerdict`、`target_type ∈ {RISK,CONFLICT,SEAL,ELEMENT}`。
2. `RuleRepository.upsert` 用主键冲突更新。
