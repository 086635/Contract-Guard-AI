## ⑤ 接口规格

```python
class _ClassifyOutput(BaseModel):
    contract_type: ContractType


class _ElementDraft(BaseModel):
    key: str
    label: str
    value: str | None
    confidence: float = Field(ge=0.0, le=1.0)
    is_custom: bool = True


class _ExtractBatch(BaseModel):
    elements: list[_ElementDraft] = Field(default_factory=list)
```

```python
def classify_node(state: AuditState, deps: GraphDeps) -> dict[str, Any]:
    """分类合同类型。

    读：clauses
    写：contract_type、llm_calls、warnings、stage_log
    """


def extract_node(state: AuditState, deps: GraphDeps) -> dict[str, Any]:
    """归一化外部 elements；无 elements 时才允许 LLM 补漏。

    读：elements、clauses
    写：elements、llm_calls、warnings、stage_log
    """
```

### 分类输入适配

模板 `classify.prompt` 的占位符为 `contract_title` / `clause_excerpt`：

```text
contract_title = state.get("contract_id", "")
clause_excerpt = "\n".join(f"{label}: {text}" for 前 20 条)
```

说明：

- `AuditState` 当前没有合同标题字段，本卡不得为了 Prompt 擅自新增 state 键。
- `contract_id` 只作为稳定标题占位，不冒充真实业务标题。

### 要素归一化键

每个 element 最终只保留 OpenAPI `ContractElement` 的 6 个字段：

```text
key
label
value
confidence
bbox
isCustom
```

缺省规则：

- `label` 缺失 -> `key`
- `value` 缺失 -> `None`
- `confidence` 缺失 -> `0.0`
- `bbox` 缺失 -> `None`
- `isCustom` 缺失 -> `False`

去重键：

```text
(key, label, value)
```

后出现的重复项丢弃，并在 detail 记录去重数量。

## ⑥ 实现规范

1. `classify_node` 无 clauses 时返回 `contract_type=None`、`SKIPPED`、warning `无条款，跳过合同分类`，不调模型。
2. `classify` 模板缺失时返回 `contract_type=None`、`SKIPPED`、warning `缺少 classify 模板`，`llm_calls=0`。
3. `classify` 调用成功返回 `OK`、`llm_calls=1`；失败返回 `DEGRADED`、`contract_type=None`。
4. `classify` 只把前 `deps.max_clauses` 条条款用于摘要；条款预算 warning 由 C4 helper 生成。
5. `extract` 若 `state.get("elements")` 非空：只做归一化和去重，`llm_calls=0`，不调模型。
6. `extract` 若 elements 为空且模板缺失：返回 `elements=[]`、`SKIPPED`、warning `缺少 extract 模板`。
7. `extract` LLM 补漏时，将 `isCustom=True`、`bbox=None`；不得接受模型返回的 bbox。
8. `extract` LLM 输出为 `_ExtractBatch`，代码再转换成纯 dict；不得把 Pydantic 对象直接写入 state。
9. 成功、降级、跳过都必须写且只写一条 `stage_log`。
10. `latency_ms` 使用 `time.perf_counter()` 计算，向下取整为非负 int。
11. 节点整体 `try/except Exception`；异常只进入 warnings / stage_log。
12. `llm_calls` 只统计真正执行过的 LLM 调用：分类成功/失败各 1；提取补漏成功/失败各 1；跳过为 0。

### 实测后回填

| 项 | 实测值 |
|---|---|
| 分类模板存在时的调用次数 | ✅ 成功路径 `llm_calls=1`；缺模板 / 无条款路径为 `0` |
