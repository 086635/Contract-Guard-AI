## ② 范围

### ✅ 做

- access token 只保存在内存，启动时调用 refresh 恢复会话。
- Axios 自动注入 Authorization，401 只尝试一次 refresh 后重试。
- 实现 Login 页、受保护路由守卫和登出。
- 按角色隐藏管理员入口，并对 403 显示明确提示。

### ❌ 不做

- 不把 access/refresh token 放 localStorage。
- 不在组件中直接 fetch 或创建 Axios 实例。
- 不把权限判断当后端授权的替代。

## ⑤ 接口规格

```text
authStore.login/refresh/logout/me
httpClient request interceptor: Authorization
authStore.hasRole(role)->bool
```

## ⑥ 实现规范

1. 401 刷新必须去重，避免并发风暴。
2. logout 清理内存 token 并调用后端撤销。
3. 导航守卫不得在 render 中产生请求。
4. 错误展示不包含 token。
