## ⑤ 接口规格

```text
Depends(get_current_user)
Depends(require_roles(Role.ADMIN))
POST /api/v1/auth/login
POST /api/v1/auth/refresh
POST /api/v1/auth/logout
GET /api/v1/auth/me
GET/POST/PATCH /api/v1/admin/users
```

## ⑥ 实现规范

1. access token 从 Authorization Bearer 读取。
2. refresh cookie 名 `cg_refresh`，HttpOnly/Secure/SameSite=Lax。
3. 写操作校验 Origin 或 CSRF token。
4. 错误统一交给 C51 全局处理器。
