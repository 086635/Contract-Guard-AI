## ② 范围

### ✅ 做

- 新增 POST `/tasks/{taskId}/stream-token`。
- 签发 60 秒、绑定 userId/taskId 的短期 token。
- SSE 接受 streamToken 并校验任务访问权。
- GET task 与 SSE 共用同一权限策略。

### ❌ 不做

- 不把 access token 放 query。
- 不放宽匿名 SSE。
- 不让 token 可用于其他任务。

## ⑤ 接口规格

```text
StreamTokenData{streamToken,expiresIn}
POST /tasks/{taskId}/stream-token
GET /tasks/{taskId}/stream?streamToken=...
```

## ⑥ 实现规范

1. token exp 60 秒，scope=stream，含 taskId/userId。
2. 校验任务合同访问权。
3. 过期 token 返回 401/403，不泄露任务是否存在。
4. SSE 响应保持 text/event-stream。
