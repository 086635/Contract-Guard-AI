## ② 范围

### ✅ 做

- 新增 POST `/tasks/{taskId}/stream-token`。
- 签发 60 秒、绑定 userId/taskId 的短期 token。
- SSE 接受 streamToken 并校验任务访问权。
- GET task 与 SSE 共用同一权限策略。

### ❌ 不做

- 不把 access token 放 query。
- 不放宽匿名 SSE。
- 不让 token 可用于其他任务。

## ⑤ 接口规格

```text
StreamTokenData{streamToken,expiresIn}
POST /tasks/{taskId}/stream-token
GET /tasks/{taskId}/stream?streamToken=...
```

## ⑥ 实现规范

1. token exp 60 秒，scope=stream，含 taskId/userId。
2. 校验任务合同访问权。
3. 过期 token 返回 401/403，不泄露任务是否存在。
4. SSE 响应保持 text/event-stream。

### 实测后回填·断言逐条

| # | 断言 | 实测结果 |
|---|---|---|
| 1 | 合法 token 建立 SSE | 通过：`test_stream_token_scoped`（`expiresIn=60`、claims 绑定 `sub`/`taskId`/`typ=stream`/`scope=stream`、`exp-iat=60s`）+ PG 门禁用例（`GET /stream?streamToken=` → 200 且 `content-type: text/event-stream`，正文含 `event: progress`） |
| 2 | 过期/篡改 token 拒绝 | 通过：`test_stream_token_expired`（61s 拒、59s 仍有效）、`test_stream_token_tampered_rejected`（改签名 → 拒）；HTTP 层映射 401 |
| 3 | 其他用户任务拒绝 | 通过（**可强制执行的边界**）：`test_cross_user_stream_forbidden`（为任务 A 签发的令牌订阅任务 B → `StreamTokenScopeError`，HTTP 403）。⚠️ 同租户内他人合同的判定需要 `contracts` 归属字段（母文档 `4-7 §⑤.11` 要求、**当前未落库**），见交付报告 §7 |
| 4 | access token 不能代替 stream token | 通过：`test_access_token_not_accepted_as_stream`（access token 缺 `taskId`/`scope` 且 `typ=access` → `TokenValidationError`；HTTP 层把 access token 放查询串 → 401） |
