## ⑤ 接口规格

```python
class ElementRepository:
    async def bulk_upsert(self, contract_id, elements: list[ContractChunk]) -> None: ...
    async def list_by_contract(self, contract_id) -> list[ContractChunk]: ...

class RiskRepository:
    async def bulk_upsert(self, contract_id, risks: Sequence[EnhancedRiskItem | CrossClauseConflict]) -> None: ...
    async def list_by_contract(self, contract_id, level=None) -> list[EnhancedRiskItem]: ...
    async def list_conflicts_by_contract(self, contract_id) -> list[CrossClauseConflict]: ...

class SealRepository:
    async def bulk_upsert(self, contract_id, seals: Sequence[SealSignatureDetection]) -> None: ...
    async def list_by_contract(self, contract_id) -> list[SealSignatureDetection]: ...

class ReportRepository:
    async def create(self, contract_id, format, storage_path) -> ReportRecord: ...
    async def get(self, contract_id) -> ReportRecord | None: ...
```

## ⑥ 实现规范

1. 批量 upsert 用主键冲突更新，不逐条 `select+insert`。
2. `list_by_contract` 支持 `level` 过滤（`RiskLevel` 三值）。
