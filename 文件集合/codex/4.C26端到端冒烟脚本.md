## ⑤ 接口规格

```text
用法：
  python scripts/e2e_smoke.py [--api-base-url http://localhost:8000]
                              [--api-prefix /api/v1]
                              [--minio-endpoint localhost:9000]
                              [--minio-access-key minioadmin]
                              [--minio-secret-key minioadmin]
                              [--file 本地合同路径]   # 缺省生成内存 DOCX 夹具
                              [--require-risks]      # 真实语义档：要求风险≥1 且 citations 非空
                              [--timeout 120]
退出码：0=通过；1=链路失败；2=参数/环境错误
```

- 默认离线档：`--file` 缺省时用 `python-docx` 生成含 3~5 条「第 X 条」条款的内存 DOCX（走 DOCX 合成坐标支路，秒级、无真实 OCR）。
- 核心链端点：`POST /contracts/presign` → `PUT {presignedUrl}` → `POST /contracts/upload` → `GET /tasks/{taskId}` 轮询至 DONE → `GET /contracts/{id}/elements|seals|parse-status` →（触发审核）→ 轮询 `run_audit` 任务 DONE → `GET .../risks|conflicts` → `POST /report/{id}/generate` → 轮询 → `GET /report/{id}` → 下载 DOCX 回读。
- 覆盖其余端点：`GET /contracts`、`GET /contracts/{id}`、`GET/PUT /settings/rules`、`POST /feedback`、`POST /agent/rewrite` 各至少一次合法调用（断言 HTTP 状态，不误伤核心链）。

## ⑥ 实现规范

1. 所有 HTTP 调用经 `httpx`（或等价），SSE 经 `GET /tasks/{taskId}/stream` 读 `text/event-stream`。
2. 轮询用固定间隔 + 总超时；解析/审核/报告每个阶段都要断言状态推进到 DONE，失败则退出 1。
3. 下载的 DOCX 用 `python-docx` 回读，断言含「风险」「溯源」「矛盾」章节（离线档允许条目为 0、显式 DEGRADED）。
4. 真实语义档（`--require-risks`）额外断言风险数 ≥1 且每条风险 `citations` 非空。
5. 阶段推进与失败原因打印到 stdout，失败信息必须含失败端点与响应摘要。

## ⑦ 验收标准

### 双层验收（已拍板）

| 档 | 断言 |
|---|---|
| 离线档（默认） | exit 0；状态机推进到 DONE；SSE 收 `RUNNING`+`DONE`；报告 DOCX 回读含「风险/溯源/矛盾」章节（条目可为 0、显式 DEGRADED）；`phase1_smoke.py` / `eval_recall.py` 退出 0 不退化 |
| 真实语义档（`--require-risks`） | 报告风险数 ≥1 且 `citations` 非空 |
