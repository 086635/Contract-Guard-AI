## ⑤ 接口规格

```text
PreviewStatus=PENDING|RUNNING|DONE|FAILED
PreviewData{contractId,status,previewUrl,expiresIn,pageCount,converterVersion,createdAt}
GET /contracts/{id}/preview
POST /contracts/{id}/preview/retry
```

## ⑥ 实现规范

1. previewUrl 运行时签发，不落库。
2. PDF 上传时可直接建立 DONE 记录。
3. DOCX 初始为 PENDING。
4. 权限失败与合同不存在都不能泄露存在性。

### 实测后回填·断言逐条

| # | 断言 | 实测结果 |
|---|---|---|
| 1 | PDF 立即 DONE | 通过：`test_preview_pdf_ready`（初始 `DONE`，`previewUrl` 由 `presign_get` **运行时**签发，`expiresIn=900`）+ `test_preview_pdf_get_is_idempotent` |
| 2 | DOCX 初始 PENDING | 通过：`test_preview_docx_pending`（`PENDING` / `previewUrl=null` / `expiresIn=0` / **不触碰对象存储**） |
| 3 | retry 幂等 | 通过：`test_preview_retry_idempotent`（连续两次 retry → **只派发一次** `convert_doc`，返回同一 `taskId`）；`test_preview_retry_skips_when_done` |
| 4 | 无权限 403 | 通过：`test_preview_permission`（结构断言：retry 的角色门槛闭包 = `{ADMIN, REVIEWER}`；GET/retry 均在 `get_current_user` 依赖图内）；真实 VIEWER→403 在 HTTP 集成用例内（DSN 门禁） |
| 5 | URL 不暴露内部 key | 通过：`test_preview_dto_has_no_internal_key_field`（DTO 字段固定为 7 个，无 `*Key*`/`*path*`；库内 key 只用于 `presign_get`） |
