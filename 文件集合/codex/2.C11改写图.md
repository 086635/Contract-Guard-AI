### 状态流

| 阶段 | 读 | 写 |
|---|---|---|
| `prepare` | before / rag_context / clause_id | rag_context（可选）、stage_log |
| `rewrite` | instruction / before / recent_dialog / rag_context | after / reasoning_steps / citations / stage_log |
| `finalize` | before / after | diff / stage_log；成功后更新 memory 快照 |

`thread_id = f"{contract_id}:{clause_id}"`。

### Diff

使用 `difflib.SequenceMatcher` 对 `splitlines()` 做比较，保留 before / after 全文：

```text
DiffMessage(type="DIFF", before=全文, after=全文, clauseId=clause_id)
```

## ⑥ 实现规范

1. RagTool 失败只降级：`rag_context=None`、`citations=[]`，仍继续改写。
2. 缺 `rewrite.prompt` 或 LLM 最终失败：抛 `RewriteUnavailableError`。
3. idempotency 使用 `OrderedDict`，上限 256，命中不重复调 LLM。
4. 只在成功 finalize 后更新 `deps.memory` 快照。
5. `updatedAt` 使用 `datetime.now(UTC).isoformat()`。
6. 阶段名只取 `REWRITE_STAGES`。
7. `reasoning_steps` / `citations` 保持 `RewriteResponse` 字段名。
8. 不在 GraphDeps 中放模型实例或连接对象。
9. 不改变 `RewriteResponse` / `DiffMessage` 字段。
10. 当前 `AgentRewriteRequest` 无独立 `before` 字段：按 `ragContext["before"]` → `scopedMemory.draftAfter` 顺序取原文，不回改契约。
