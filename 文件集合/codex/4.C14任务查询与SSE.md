## ⑤ 接口规格

```python
class TaskService:
    async def get(self, task_id: UUID) -> TaskProgress: ...
    async def stream(self, task_id: UUID) -> AsyncIterator[str]: ...
```

SSE 输出：

```text
event: progress
data: {"taskId":"...","stage":"...","percent":0.5,"status":"RUNNING","result":null}

```

## ⑥ 实现规范

1. 响应 `GET` 继续走 `TaskProgressResponse` 包络。
2. SSE 事件豁免包络，事件载荷使用 `TaskProgress.model_dump(by_alias=True)`。
3. `text/event-stream` 必须关闭代理缓存并保持心跳。
4. Redis 无消息时按 heartbeat 间隔发注释行，避免连接空闲断开。
5. 客户端断开必须终止生成器并 unsubscribe。

## ⑦ 验收标准

| # | 断言 |
|---|---|
| 1 | `GET /tasks/{id}` 读取真实任务行 |
| 2 | 未知 task 返回 404 |
| 3 | SSE 能收到至少一条 progress 事件 |
| 4 | Redis 断开时流结束且不无限忙等 |
