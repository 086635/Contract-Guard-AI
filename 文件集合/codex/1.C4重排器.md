## ② 范围

### ✅ 做

- `factory.build_reranker()` 用 `RERANK_PRESETS` 补全 `http_url` / `path` / 模型（**不新增配置项**）
- 联调用例：真实 rerank 服务（**未配置时 skip**）+ 分数**单调性**断言（更相关的条款分更高）
- **阈值口径自证**：`rerank_threshold` 作用于 rerank 分、`score_threshold` 作用于 final 分，
  且 **noop 路径不叠加**（`factory._rerank_threshold_for()` 已实现 —— 本卡补一条"不许回退"的用例）
- 失败路径：超时 / 5xx / 返回长度不符 → 回退 `base_scores` 并置 `RERANK_FAILED`（**已实现，本卡加测**）

- ❌ 不改 `_rank()` 的过滤顺序与 `ChunkScores` 字段

## ⑤ 接口规格

不变更任何签名；只新增以下**行为契约**：

```text
build_reranker(settings):
  rerank_enabled=False                  → None
  rerank_mode="noop"                    → NoopReranker()
  rerank_mode="http" 且 url 为空        → warning + NoopReranker()（既有行为，保留）
  rerank_mode="http" 且 url 非空        → HttpReranker(url=预设补全后的值, path=…, model=…, api_key=…)
     其中 base_url/path/model 只在**配置留空**时取 RERANK_PRESETS[provider]
```
**分数口径（不改，只加测）**：`rerank_threshold` 仅当精排真正生效时叠加到阈值上；`noop` / 缺 URL 一律不叠加。

## ⑥ 实现规范

1. 🔴 **不改分数口径**：`final = rerank_scores if rerank_scores is not None else base_scores`；`clamp_score(dense)` 仍是 base。
2. 🔴 **失败即回退**：超时 / 非 2xx / 长度不符 → 回退 `base_scores` + `RERANK_FAILED`（**绝不抛给上层**）。
3. ⚠️ **`noop` 不叠加阈值**：`_rerank_threshold_for()` 是唯一判定处；本卡只加"不许回退"的用例。
4. ⚠️ **打点**：`retrieve.rerank`（既有）保留 `model` / `pairs` / `score_max` / `dropped_count` / `latency_ms`。
5. ⚠️ 真实服务用例：`CG_RAG_TEST_RERANK_URL` 未设置 → skip。
