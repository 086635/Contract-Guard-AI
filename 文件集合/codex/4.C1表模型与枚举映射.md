## ⑤ 接口规格

```python
class Contract(Base):  # contracts
    id: Mapped[UUID]（pk）
    filename: Mapped[str]
    file_size: Mapped[int]
    file_hash: Mapped[str]（unique）
    storage_path: Mapped[str]
    status: Mapped[ContractStatus]
    contract_type: Mapped[ContractType]
    created_at / updated_at: Mapped[datetime]

class ContractCommit(Base): # contract_commits：请求 ID / item_id / accepted / version
class ContractElement(Base):  # contract_elements：ContractChunk 28 字段投影 + contract_id(FK) + vector_id
class AuditTask(Base):       # audit_tasks：task_type/stage/progress(0..1)/status/celery_task_id/error_message
class AuditRisk(Base):       # audit_risks：EnhancedRiskItem/CrossClauseConflict 投影（level 用 RiskLevel）
class SealDetection(Base):   # seal_detections：SealSignatureDetection 投影
class SettingsRule(Base):    # settings_rules：rule_name/category/prompt_template/threshold/is_enabled
class AuditReport(Base):     # audit_reports：format/storage_path/download_count/generated_at/status
class UserFeedback(Base):    # user_feedbacks：target_type/target_id/verdict/user_comment/created_at
```

## ⑥ 实现规范

1. 枚举列一律用 openapi/`rag_contracts` 枚举类型，禁止魔法字符串。
2. `audit_tasks.progress` 用 `0..1`、`status` 用 `RUNNING/DONE/FAILED`。
3. `UserFeedback` 用 `target_type + target_id` 多态关联。
4. 表名、列名与 `4-1 §⑤` 对齐，UUID 主键用 `uuid4` 默认。
