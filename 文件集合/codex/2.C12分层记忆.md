## ⑤ 接口规格

```python
class ScopedMemoryManager:
    def append(self, clause_id: str, turn: DialogTurn) -> None: ...

    def record_turn(
        self,
        clause_id: str,
        role: str,
        content: str,
        *,
        created_at: str,
    ) -> None: ...

    def set_draft(self, clause_id: str, draft_after: str) -> None: ...

    def snapshot(self, clause_id: str) -> ScopedClauseMemory: ...

    def get(self, clause_id: str) -> ScopedClauseMemory: ...
```

窗口上限：

```text
_MAX_TURNS = 5
```

## ⑥ 实现规范

1. 每个 clause_id 维护独立 deque。
2. `record_turn` 构造 `DialogTurn`，窗口满自动淘汰最旧。
3. `set_draft` 不创建新 clause 窗口，仅保存草稿。
4. `snapshot` 返回当前窗口副本与 draftAfter。
5. `get` 与 `snapshot` 行为一致，保留兼容。
6. rewriter 与 memory 的 `ScopedClauseMemory` 必须是同一对象。
7. rewriter 中不得再有 `class ScopedClauseMemory`。
8. `GlobalStateManager` 继续使用进程内 dict，本卡不持久化。
