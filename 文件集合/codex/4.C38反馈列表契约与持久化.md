## ⑤ 接口规格

```text
GET /api/v1/feedback
  contractId?: UUID
  targetType?: RISK|CONFLICT|SEAL|ELEMENT
  verdict?: CORRECT|FALSE_POSITIVE|MISSING
  page?: int >= 1 (default 1)
  pageSize?: int 1..100 (default 20)

data:
  items: FeedbackItem[]
  total: int
  page: int
  pageSize: int
  hasMore: bool
```

```python
class FeedbackService:
    async def list(
        self,
        *,
        contract_id: UUID | None,
        target_type: TargetType | None,
        verdict: FeedbackVerdict | None,
        page: int,
        page_size: int,
    ) -> tuple[list[FeedbackItem], int]: ...

class FeedbackRepository:
    async def create(
        self, target_type, target_id, verdict, user_comment,
        *, contract_id: UUID, reviewer: str | None = None,
    ) -> FeedbackRecord: ...
    async def list(
        self, target_type=None, *, contract_id=None, verdict=None,
        page: int = 1, page_size: int = 20,
    ) -> tuple[list[FeedbackRecord], int]: ...
```

## ⑥ 实现规范

1. OpenAPI 先落盘并执行代码生成；不得手改 `types.ts` / `zod.ts` / `schemas.py`。
2. 迁移采用“nullable 列 → 回填 → 非空约束”的安全顺序：
   - `RISK` 反馈可按 `audit_risks.id → contract_id` 回填；
   - 无法映射的旧行必须显式失败或由单独清理任务处理，禁止填占位 UUID。
3. 新建反馈时从 `FeedbackCreateBody.contractId` 写入 `contract_id`、从 `reviewer` 写入 reviewer；列表过滤只按真实列查询。
4. Repository 使用 `SELECT COUNT(*)` + `LIMIT/OFFSET` 或等价分页实现，禁止全表加载后在 Python 分页。
5. `pageSize` 超过 100、`page < 1` 必须由 FastAPI 参数校验返回 422。
6. `FeedbackItem` 投影必须从记录还原 `contractId`、`targetType`、`targetId`、`verdict`、`reviewer`、`createdAt`；空值按契约返回。
7. 错误使用统一 envelope；不吞掉数据库异常，不让 Route 直接操作 Repository。
