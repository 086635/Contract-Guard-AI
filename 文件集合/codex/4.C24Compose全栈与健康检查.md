## ⑥ 实现规范

1. qdrant healthcheck 打 REST 端口 `6333` 的 `/healthz`；minio healthcheck 打 `9000` 的 `/minio/health/live`；探针用镜像内可用的 HTTP 客户端（curl / wget / mc），并实测通过。
2. postgres / redis 沿用现有 `service_healthy` 探针。
3. `migrate` 用 `alembic.ini` 的 `%(here)s` 相对路径（`-c apps/api-gateway/alembic.ini`），`sqlalchemy.url` 留空、由 `env.py` 回退 `CG_POSTGRES_DSN`。
4. worker 的 `CG_RAG_QDRANT_MODE=server` 与 `CG_RAG_QDRANT_URL=http://qdrant:6333` 成对设置；`CG_LLM_PROVIDER=offline` 保证离线可跑。
5. 项目名保持 `contract-guard`（防与其它 docker 目录的 compose 同命名空间）。
