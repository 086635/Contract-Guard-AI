## ⑤ 接口规格

```python
class _RiskDraft(BaseModel):
    """LLM 只能产出风险语义字段。"""

    category: RiskCategory
    level: RiskLevel
    title: str
    suggestion: str
    reasoning_steps: list[ReasoningStep] = Field(default_factory=list)


def risk_node(state: AuditState, deps: GraphDeps) -> dict[str, Any]:
    """逐条款执行 RAG + 风险识别。

    读：clauses、contract_type、tolerance
    写：risks、rag_calls、llm_calls、warnings、stage_log
    """
```

### LLM 输入

模板 `risk.prompt` 占位符：

```text
clause_label
clause_text
contract_type
tolerance
rag_context
```

`rag_context` 只允许：

```text
rag_result.context_block
```

若 Tool 返回 `status="EMPTY"`，必须是：

```text
EMPTY_CONTEXT_HINT
```

### 代码回填规则

| 字段 | 来源 |
|---|---|
| `id` | `f"{contract_id}:{clause_id}:risk:{ordinal}"`，`ordinal` 从 1 递增 |
| `clauseId` | `ClauseInput.clause_id` |
| `originalText` | `ClauseInput.text` |
| `bbox` | `ClauseInput.bbox or {}` |
| `citations` | `AgentRAGToolResult.citations` 转 `PreciseCitation` |
| `legalBasis` | 固定 `None`，不把来源标题冒充法条正文 |

说明：

- `EnhancedRiskItem.bbox` 类型是 `dict`，因此缺坐标时传 `{}`，并记 warning。
- `{}` 表示“无坐标”，不得填 `(0, 0, 0, 0)` 或伪造页码/坐标。
- 同一条款若 LLM 产出一个 `_RiskDraft`，对应一个 `EnhancedRiskItem`。

## ⑥ 实现规范

1. 无条款时返回 `risks=[]`、`SKIPPED`、warning `无条款，跳过风险识别`；`rag_calls=0`、`llm_calls=0`。
2. 缺 `risk.prompt` 时整节点 `SKIPPED`，不调用 RAG 与 LLM。
3. 有条款且模板存在时，对每个受预算限制的 clause 执行一次 RAG 调用。
4. `deps.rag_tool is None` 时：不增加 `rag_calls`，使用 `EMPTY_CONTEXT_HINT`，增加一次 warning，继续 LLM。
5. RAG Tool 抛异常时：`rag_calls += 1`，使用 `EMPTY_CONTEXT_HINT` 继续，记 warning，最终 stage 为 `DEGRADED`。
6. RAG 返回 `EMPTY` 或 `DEGRADED` 时按原 `context_block` 注入，不重建提示语。
7. 每个 clause 成功后 `llm_calls += 1`；LLM 异常或结构化失败时也计入已尝试调用，跳过该 clause。
8. 单条失败不得使整节点抛异常；至少产出的风险继续保留。
9. 只要存在 RAG/LLM 单条失败，stage 状态为 `DEGRADED`；全部成功为 `OK`。
10. citations 必须用 `PreciseCitation.model_validate(citation.model_dump())` 或等价字段映射，保持 1:1。
11. `reasoningSteps` 原样使用模型输出；若为空仍返回风险，但记 warning。
12. 节点不得调用 `_resolve_llm` 之外的模型构造方式；`deps.llm` 存在时必须优先使用注入实例。
