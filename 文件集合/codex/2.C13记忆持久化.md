## ⑤ 接口规格

```python
class MemoryStorePort(Protocol):
    def get(self, namespace: str, key: str) -> str | None: ...
    def set(self, namespace: str, key: str, value: str, ttl_s: int | None = None) -> None: ...
    def delete(self, namespace: str, key: str) -> None: ...
    def keys(self, namespace: str) -> list[str]: ...


class MemorySettings(BaseSettings):
    backend: Literal["inmemory", "redis", "postgres"] = "inmemory"
    redis_url: str = "redis://localhost:6379/3"
    postgres_dsn: str = ""
    ttl_s: int = 86400
    key_prefix: str = "cg:mem"


def build_memory_store(settings: MemorySettings | None = None) -> MemoryStorePort: ...
def build_checkpointer(settings: MemorySettings | None = None): ...
```

key 规则：

```text
{prefix}:global:{contract_id}
{prefix}:scoped:{contract_id}:{clause_id}
```

版本壳：

```json
{"v": 1, "data": {}}
```

## ⑥ 实现规范

1. `inmemory` 默认且无外部依赖。
2. TTL 只由 store 处理；`ttl_s=None` 永不过期。
3. InMemory TTL 使用注入 `clock`，禁止硬编码 `time.time()`。
4. Redis / psycopg / checkpoint-postgres 延迟导入。
5. 构建失败降级 InMemory，记 `memory.degrade` warning。
6. 未知版本壳当 miss，不抛异常。
7. 记忆模型先过 Pydantic，再序列化。
8. manager 不传 store 时仍默认 InMemory，旧签名兼容。
9. ScopedMemory 窗口仍为 5，持久化不放大窗口。
10. checkpointer 与 memory store 分属两个接口。

### 实测后回填

| 项 | 实测值 |
|---|---|
| InMemory 读写 P95 | ✅ 200 次 set+get：P50 **0.0008 ms**、P95 **0.0027 ms**、max 0.0127 ms |
| Redis 是否可测 | ✅ `.venv` 已装 redis 6.4.0；无真实 Redis 用例（`CG_MEMORY_TEST_REDIS_URL` 未设）。坏地址构造实测约 0.26s 后降级 InMemory |
| 20×5 记忆体大小 | ✅ 20 条款 × 5 轮：版本壳 JSON 合计 **13690 bytes** |
| checkpoint-postgres 是否安装 | ❌ `.venv` 未安装；仅系统 Python 可见。`backend=postgres` 且无依赖/DSN 时降级 `InMemorySaver` |
