## ⑤ 接口规格

### ⑤.1 OpenAPI 加法

`GET /api/v1/feedback`：

| 参数 | 类型 | 必填 | 规则 |
|---|---|---:|---|
| `contractId` | string | 否 | 按合同过滤 |
| `targetType` | enum | 否 | RISK / CONFLICT / SEAL / ELEMENT |
| `verdict` | enum | 否 | CORRECT / FALSE_POSITIVE / MISSING |
| `page` | int | 否 | 默认 1，最小 1 |
| `pageSize` | int | 否 | 默认 20，1~100 |

响应 `data` 复用统一分页形状：

```json
{
  "items": [],
  "total": 0,
  "page": 1,
  "pageSize": 20,
  "hasMore": false
}
```

设置增量：

```json
{
  "enabled": true,
  "reviewThresholds": {
    "high": 0.85,
    "medium": 0.65,
    "low": 0.40
  }
}
```

- `ReviewThresholds` 的 high/medium/low 均为 0~1；
- 前端 0~100 展示值由前端转换，后端只保存 0~1；
- `enabled` 复用 `settings_rules.is_enabled`；
- 既有 `enabledRules`、`threshold` 保留，避免破坏现有客户端。

### ⑤.2 Python 接口

```python
class FeedbackService:
    async def list(
        self,
        *,
        contract_id: UUID | None,
        target_type: TargetType | None,
        verdict: FeedbackVerdict | None,
        page: int,
        page_size: int,
    ) -> tuple[list[FeedbackItem], int]: ...

@celery_app.task(name="rewrite", bind=True)
def rewrite_task(self, payload: dict) -> dict: ...
```

要素映射契约：

```text
ContractElement.key          -> ContractChunk.section_id
ContractElement.label        -> ContractChunk.title
ContractElement.value        -> ContractChunk.extra["value"]
ContractElement.confidence   -> ContractChunk.extra["confidence"]
ContractElement.isCustom     -> ContractChunk.extra["isCustom"]
ContractElement.bbox         -> ContractChunk.bbox
category                     -> CONTRACT_ELEMENT
```

`ContractProjector.elements()` 必须优先读取 `extra`；`text` 只作为检索/展示兼容字段，不能用占位文本冒充真实 value。

### ⑤.3 配置增量

```text
CG_MINIO_PUBLIC_ENDPOINT=localhost:9000
```

- 未配置时回退到 `CG_MINIO_ENDPOINT`；
- 内部 client 负责 `stat_object`、报告上传；
- 公网 client 只负责浏览器 presign PUT/GET；
- 禁止先生成内部 URL 再替换 host。

## ⑥ 实现规范

1. **先契约后代码**：先改 `openapi.yaml`，执行一次代码生成；后端和测试只消费生成 DTO，禁止手改 `types.ts` / `zod.ts` / `schemas.py`。
2. **反馈迁移**：先加 nullable `contract_id`，按 `target_type=RISK` 关联 `audit_risks.contract_id` 回填；无法回填的旧行必须显式失败或由任务单独决定清理，不得伪造合同 ID。
3. **反馈分页**：Repository 使用 `WHERE` 过滤 + `COUNT(*)` + `ORDER BY created_at DESC, id ASC` + `LIMIT/OFFSET`；Service 计算 `hasMore = page * pageSize < total`。
4. **设置迁移**：`review_thresholds` 使用 JSON/JSONB 非空，迁移默认 `{"high":0.85,"medium":0.65,"low":0.40}`；`enabled` 不新增列，映射现有 `is_enabled`。
5. **设置校验**：PUT 必须校验 high/medium/low 在 0~1，且满足 high ≥ medium ≥ low；非法值返回 422，不写库。
6. **要素映射**：只接受解析结果顶层 `elements` 的 dict；空 value 保留在 `extra.value`，不得改写为 label；每条失败隔离为 warning。
7. **rewrite 任务**：解析 `AgentRewriteRequest`，调用 `rewrite_clause()`，成功返回 `model_dump(mode="json", by_alias=True)`；失败保留结构化错误和 trace_id，禁止返回 Mock Diff。
8. **MinIO**：`minio-init` 必须幂等创建 `contracts` bucket，设置 5173/8080 来源的 CORS；API/worker 保留内部 endpoint，API 额外注入 public endpoint。
9. **不改已闭合链路**：C22/C23/C25~C27/C18~C21 只允许因新增测试或接口兼容做最小调整，不得重写。
10. **C28-R 交接**：T-D6 合入当前工作树后，另立 Goal 执行 C28-R，核对生成物差异只含本任务预期字段。
