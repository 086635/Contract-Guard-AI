## ⑤ 接口规格

```python
# worker/tasks/gen_report.py
@celery_app.task(name="gen_report", bind=True)
def gen_report_task(
    self,
    contract_id: str,
    payload: dict[str, Any] | None = None,
) -> dict[str, Any]:
    """渲染 DOCX、上传 MinIO，并返回供网关落库的结构化结果。"""
```

成功结果：

```python
{
    "contractId": "<uuid>",
    "status": "DONE",
    "format": "DOCX",
    "storagePath": "reports/<uuid>/<timestamp>_<uuid8>.docx",
    "warnings": [],
}
```

失败结果：

```python
{
    "contractId": "<uuid>",
    "status": "FAILED",
    "format": "DOCX",
    "storagePath": "",
    "warnings": ["<reason>"],
}
```

## ⑥ 实现规范

1. 使用 `bind=True`，通过 `self.update_state()` 上报进度，沿用 `ReportProgressReporter` 的单调保护。
2. 阶段表只含 `render` / `upload`；不得复用 `PARSE_STAGES` 或 `AUDIT_STAGES`。
3. `payload` 为 `None` 时返回 `FAILED`，`warnings` 写入“缺少报告输入”。
4. 使用 `ReportRenderInput.model_validate(payload)`，失败时返回 `FAILED`。
5. 上传成功后才返回 `DONE`；上传异常必须捕获并转为 `FAILED`。
6. 结果必须是纯 JSON 可序列化对象，不能含 Pydantic 模型、Path、异常对象。
7. 不直接写数据库，不 presign，不 import `app.*`。

## ⑦ 验收标准

| # | 断言 |
|---|---|
| 1 | 固定 `payload` 下任务返回 `status=DONE` 且 `storagePath` 以 `reports/` 开头 |
| 2 | 假 `upload_report` 收到的 DOCX 字节非空，且任务结果包含该上传 key |
| 3 | 空 `payload` 返回 `status=FAILED`，不抛异常 |
| 4 | 上传异常返回 `status=FAILED`，不向 broker 抛出 |
| 5 | 返回结果 `json.dumps(result)` 可序列化 |
| 6 | `gen_report.py` 源码不含 `from app.` / `import app.` |
