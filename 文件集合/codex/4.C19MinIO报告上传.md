## ⑤ 接口规格

```python
# worker/storage/minio_client.py
def upload_report(
    contract_id: str,
    data: bytes,
    content_type: str = "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
) -> str:
    """上传报告对象并返回 object key。"""
```

## ⑥ 实现规范

1. `data` 为空时抛 `ValueError`。
2. `contract_id` 为空或包含 `/`、`\`、`..` 时抛 `ValueError`，避免路径穿越。
3. bucket 读取 `CG_MINIO_BUCKET`，默认 `contracts`；key 必须形如 `reports/{contract_id}/{YYYYMMDDHHMMSS}_{uuid8}.docx`。
4. 使用 `put_object(bucket, key, BytesIO(data), length=len(data), content_type=content_type)`。
5. 返回 key；任何异常向上抛，由 C20 捕获并转成任务失败结果。
6. 不要在本函数内 presign、不要写 DB、不要打印下载地址。
7. 改完 `apps/async-worker/pyproject.toml` 后执行 `uv sync --all-packages`，避免剪掉其它 workspace 依赖。
