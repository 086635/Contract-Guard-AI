## ② 范围

### ✅ 做

- 实现 Redis 幂等键、请求体哈希、响应快照和 24 小时 TTL。
- 同 key 同 body 重放原响应；同 key 不同 body 返回 409；Redis 不可用返回 503。
- 仅对声明 X-Request-ID 的写操作启用，并在响应头回传 requestId。
- 前端优先读取 ApiError.message/detail，禁用裸 detail 的第二套分支。

### ❌ 不做

- 不在业务 Service 里复制 Redis 幂等逻辑。
- 不缓存读请求。
- 不把 Redis 失败静默放过。

## ⑤ 接口规格

```text
key = cg:idempotency:{operationId}:{userId}:{requestId}
TTL=24h
replay: same body -> original response
conflict: different body -> 409
redis down -> 503
```

## ⑥ 实现规范

1. 使用 SHA-256 哈希完整规范化 body。
2. 缓存内容不得包含 Authorization/refresh cookie。
3. 中间件不吞非幂等路径。
4. 错误由 C51 handler 统一包装。
