## ⑤ 接口规格

```python
class RuleService:
    async def list(self, contract_type: str | None) -> list[SystemAuditConfiguration]: ...
    async def get(self, rule_id: UUID) -> SystemAuditConfiguration: ...
    async def update(self, rule_id: UUID, body: dict) -> SystemAuditConfiguration: ...

class FeedbackService:
    async def create(self, body: FeedbackCreateBody) -> FeedbackItem: ...
```

路由签名保持不变，只把 `MockDataFactory` 替换成 Service。

## ⑥ 实现规范

1. 路由只处理 HTTP 语义和状态码，DTO 组装全部在 Service。
2. 反馈创建使用 `TargetType` / `FeedbackVerdict`，不手写字符串。
3. 409/404 的映射必须由 Service 抛专用异常并在路由统一转换。
4. 响应继续由生成 wrapper 构造，禁止在路由手拼 dict 包络。
5. `X-Request-ID` 幂等继续由中间件负责，Service 不重复实现幂等。

## ⑦ 验收标准

| # | 断言 |
