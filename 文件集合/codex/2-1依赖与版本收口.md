## ⑥ 实现规范

1. 🔴 **区间上下限都要写**：`>=1.2,<2.0`，禁止 `>=0.2` 这类敞口。理由：`StateGraph` / `add_messages` / checkpointer 在 0.2 → 1.2 之间**接口变过**，敞口会制造「我这儿能跑、别人那儿不能跑」的幽灵问题。
2. 🔴 **`langchain-core` 必须显式声明**：即便它会被 `langgraph` 传递安装，**直接 import 的包就必须直接声明**（本模块会 `from langchain_core.messages import ...`）。
3. 🔴 **`[tool.uv.sources]` 三行一个不能少**：uv workspace 靠它把兄弟包解析为本地 editable。
4. 🔴 **`dev` 组只加 `pytest`**：`ruff` / `mypy` / `datamodel-code-generator` 在**根** `pyproject.toml` 的 `[dependency-groups] dev`（见 1-1 §⑧），**不要重复声明**。
5. ⚠️ **`ai-engine` 不得声明 `doc-processor`**：`AuditState.clauses` 用本地最小输入 DTO 承接（见 `2-3`），由 `async-worker` 做一次适配；否则会把 `pdfplumber` / `paddleocr` 拖进 Agent 包。
6. ⚠️ 写入文件时遵守标准 §0.2 的文件结构与中文注释规范；TOML 里的注释同样用中文。
