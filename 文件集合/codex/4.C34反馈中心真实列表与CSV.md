## ⑤ 接口规格

```ts
export const feedbackApi = {
  list(params?: FeedbackListParams): Promise<FeedbackListData>;
  create(body: FeedbackCreateBody): Promise<FeedbackItem>;
};
```

约定：

- `FeedbackListParams`、`FeedbackListData` 由 T-D6 生成的类型提供。
- `Feedback.tsx` 不得自行声明与生成类型不同的字段。
- CSV 仅导出当前列表字段，字段顺序固定并在表头写中文标签。

## ⑥ 实现规范

1. 首次进入和提交成功后都调用 `feedbackApi.list()`；刷新按钮同样重新拉取真实数据。
2. 统计值从 `items` 计算：总数、按 verdict 计数、最近记录时间；无数据时显示 0 或空态。
3. 搜索在当前已加载列表上筛选，不伪造服务端搜索能力；若 T-D6 提供过滤参数，应传入接口。
4. CSV 必须对逗号、双引号、换行做转义，并生成可被 Excel 打开的 UTF-8 文件。
5. 提交创建成功后使列表失效重拉，不把本地数组作为持久化事实。
6. 错误显示真实 message/traceId（开发环境），不静默 `console.warn` 后继续展示旧数据。
