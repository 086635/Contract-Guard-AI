# 官方初始知识库（2026-10-05）

本目录保存官方网页/PDF的提取文本，不是原始版式 PDF。`sources.json` 记录官方来源、发布日期、原文 SHA-256 和适用范围。民法典 1260 条；官方范本 2 份。条款按原切片器和合同类型展开为 70 个可检索记录，不代表 70 个独立范本条款。

委托合同适用于委托事务；农副产品合同的专用条款不适用于机器人等工业产品，仅可参考通用合同表述。两份范本均未经企业审批，标准比对会明确提示缺少企业基线。法条的具体适用须人工复核。

原下载站点在本机出现 TLS EOF/WAF，文本通过工具读取的官方网页和官方 PDF 提取结果保存；没有关闭证书验证。来源和提取内容可据链接复核，原文哈希仅校验本目录提取文本。

运行配置启用本机 BGE-M3 / Qdrant server 后，可执行：

```powershell
python scripts/import_official_knowledge.py --manifest "文件集合/知识库/官方初始库20261005/sources.json"
```

先加 `--dry-run` 可仅校验文本与切片数量；正式导入复用现有 PG 条款管理和 Qdrant 索引。相同来源重复导入沿用条款 ID，不覆盖已有人工编辑；法条沿用稳定切片 ID。
