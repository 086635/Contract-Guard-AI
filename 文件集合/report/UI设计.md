## 视觉风格与全局布局架构

- **视觉基调**：深色/浅色专业法务工作台风格（Slate / Zinc 色系）。
- **语义化色彩规范**：
  - **高风险 (HIGH)**：`bg-red-50 text-red-700 border-red-200`（高亮颜色 `#FEE2E2`，BBox 边框 `#EF4444`）
  - **中风险 (MEDIUM)**：`bg-amber-50 text-amber-700 border-amber-200`（高亮颜色 `#FEF3C7`，BBox 边框 `#F59E0B`）
  - **低风险 (LOW)**：`bg-blue-50 text-blue-700 border-blue-200`（高亮颜色 `#DBEAFE`，BBox 边框 `#3B82F6`）
  - **关键要素 (ELEMENT)**：`bg-emerald-50 text-emerald-700 border-emerald-200`（高亮颜色 `#D1FAE5`，BBox 边框 `#10B981`）
  - **印章/签名 (SEAL)**：`bg-purple-50 text-purple-700 border-purple-200`（高亮颜色 `#EDE9FE`，BBox 边框 `#8B5CF6`）
- **全局框架 (Shell Layout)**：
  - **Header (顶部栏)**：系统 Logo、全局搜索、任务通知中心、租户/用户切片。
  - **Sidebar (左侧导航)**：收缩式侧边栏（合同工作台、规则引擎配置、系统日志/标注统计）。
  - **Main Container (主视图)**：支持双栏/三栏响应式伸缩布局，针对合同审核场景优化了两侧独立滚动同步。

## 页面规划与 API 映射明细

系统共规划 4 个核心页面视图，精准覆盖全部 19 个 API 端点。

### 1. 合同管理与导入中心 (`/contracts`)

**页面布局**：

- **顶栏操作区**：合同类型筛选下拉框、状态过滤器（解析中/已审核/存在高危）、搜索框及「上传合同」主按钮。
- **核心内容区**：表格/卡片双视图切换，卡片展示合同基本信息、风险统计 Badge（高/中/低）、最新解析状态与操作列（查看、重新解析、生成报告）。
- **上传 Modal 弹窗**：支持 Drag-and-Drop 拖拽拖入 PDF/Word 文件，显示上传进度与异步解析 Task 进度条。

```
┌──────────────────────────────────────────────────────────────────────────────┐
│  [🔍 搜索合同名称/编号...]  [合同类型: 全部 ▾]  [审核状态: 全部 ▾]  [ + 上传新合同 ] │
├──────────────────────────────────────────────────────────────────────────────┤
│ 📄 2026采购框架协议.pdf   [采购合同]  高风险(2) 中风险(5)  [已完成]  [ 查看审核 ]  │
│ 📄 智能设备服务条款.docx   [服务合同]  高风险(0) 中风险(1)  [解析中]  [ 查看进度 ]  │
└──────────────────────────────────────────────────────────────────────────────┘

```

- **关联 API 映射**：
  - `GET /contracts`：分页获取合同列表与风险汇总统计。
  - `POST /contracts/presign`：拖拽文件后预获取 MinIO 直传 URL。
  - `POST /contracts/upload`：直传完成后提交上传任务，获取 `task_id`。
  - `GET /tasks/{task_id}`：轮询上传与初步预处理状态。
  - `GET /tasks/{task_id}/stream`：建立 SSE 长连接，实时推送后端解析/OCR 分页进度条。

### 2. 双栏智能审核工作台 (`/contracts/:contract_id/audit`) —— 核心主页

**页面布局**：采用 **三栏伸缩架构（三栏比例 25% : 45% : 30%）**。

```
┌─────────────────┬──────────────────────────────────┬─────────────────────────┐
│ 左侧：要素/导航  │ 中间：PDF.js 双栏图层渲染区        │ 右侧：智能审核 & AI 助手 │
├─────────────────┼──────────────────────────────────┼─────────────────────────┤
│ 📑 导航索引     │  [📄 原始 PDF 渲染层 (Canvas)]    │ 🔴 风险列表中(12)        │
│ ├─ 抽取要素 (8) │   ┌──────────────────────────┐   │  ┌────────────────────┐ │
│ ├─ 风险列表 (12)│   │ 条款 3.1: 违约金按每日5% │   │  │ [高危] 违约金过高  │ │
│ ├─ 交叉矛盾 (2) │   │  [红色 BBox 高亮框]       │   │  │ 建议修改为每日0.05% │ │
│ └─ 印章签名 (1) │   └──────────────────────────┘   │  └────────────────────┘ │
│                 │                                  │ 🤖 Agent 条款改写对话框  │
│ 📌 关键要素清单 │  [📝 抽取文本与坐标同步 Overlay] │  │ ┌────────────────────┐ │
│ 甲方: 杭州xxx   │                                  │  │ AI 一键改写与替换   │ │
│ 乙方: 科技xxx   │                                  │  └────────────────────┘ │
└─────────────────┴──────────────────────────────────┴─────────────────────────┘

```

- **左侧 Panel（抽屉导航与要素大纲）**：
  - 要素提取 Tabs（主体、金额、履约期限、争议解决管辖地）。
  - 风险等级 Anchor 锚点树（点击跳转至中间对应页码与坐标）。
- **中间 Panel（PDF.js 双栏高亮渲染）**：
  - 底层：PDF.js Canvas 图像渲染。
  - 顶层：SVG/HTML Overlay 高亮图层，渲染绝对 BBox（Bounding Box）坐标，自动跟随缩放/旋转。
  - 悬浮 Tooltip：点击高亮框浮出快速打标弹窗（正确/错误反馈）。
- **右侧 Panel（智能审核、冲突分析与 Agent 重写）**：
  - **风险卡片区**：卡片式展示风险描述、CoT 推理过程、PreciseCitation 原文溯源引用。
  - **跨条款矛盾区**：展示多条款互斥矛盾关联（如“付款条款 3.1” 与 “违约责任 8.2” 冲突）。
  - **Agent 协商改写面板**：以对话形式调用 Agent 重写条款，提供 Diff 差异对比（红删绿增），支持“一键采纳替换”。
  - **底部操作栏**：包含「提交批注确认」与「生成审核报告」主按钮。
- **关联 API 映射**：
  - `GET /contracts/{contract_id}`：获取当前合同详情与全局元数据。
  - `GET /contracts/{contract_id}/parse-status`：校验合同结构化 AST 是否就绪。
  - `GET /contracts/{contract_id}/elements`：渲染左侧关键要素提取列表。
  - `GET /contracts/{contract_id}/risks`：渲染右侧风险列表并绘制中间 PDF BBox 高亮。
  - `GET /contracts/{contract_id}/conflicts`：渲染跨条款交叉矛盾提示卡片。
  - `GET /contracts/{contract_id}/seals`：渲染印章/签名检测框 Overlay。
  - `POST /agent/rewrite`：触发 Agent 重写条款，获得替换文本与修改依据。
  - `POST /feedback`：对风险项或要素项进行人工纠错/打标反馈（HITL 机制）。
  - `POST /contracts/{contract_id}/commit`：提交人工审核最终修改（批量持久化）。

### 3. 审核报告与导出中心 (`/contracts/:contract_id/report`)

**页面布局**：

- **顶部导览**：包含报告版本历史、导出 PDF/Word 按钮、打印适配样式。
- **报告主体（A4 预览画幅）**：
  - **封面与概览**：合同基本信息、综合风险评分 Dashboard（仪表盘）、风险分布雷达图。
  - **高风险清单**：表格化列出高危条款、法条依据、修改前后对比。
  - **缺失条款提醒**：提示标准模板中存在但当前合同缺失的关键保护条款。
  - **合规签署校验**：印章完整度与签名合规性评估报告。
- **关联 API 映射**：
  - `POST /report/{contract_id}/generate`：发起异步报告生成任务（状态 202）。
  - `GET /tasks/{task_id}`：轮询报告渲染生成进度。
  - `GET /report/{contract_id}`：拉取完整的结构化报告数据展示在 A4 预览区。

### 4. 规则引擎与 3 维配置中心 (`/settings/rules`)

**页面布局**：

- **左侧规则树**：按合同类型分类（采购合同、销售合同、劳动合同、保密协议等）。
- **主配置面板**：
  - **基础属性**：规则名称、适用合同类型、启用状态开关。
  - Prompt/角色配置：PromptRoleConfig 调整（系统角色设定、温度系数、CoT 链条深度）。
  - **风险阈值设置**：高/中/低风险判定置信度滑块。
  - **标准条款库关联**：绑定 Qdrant 中该类合同的标准范本条款向量库。

```
┌──────────────────────┬──────────────────────────────────────────────────────┐
│ 规则列表             │ 规则配置: [采购合同审查标准 v2.1]                    │
├──────────────────────┼──────────────────────────────────────────────────────┤
│ 📁 采购类合同 (3)    │  [基本信息]  [Prompt与Agent角色]  [标准条款匹配库]    │
│  ├─ 🔹 框架采购规则  │ ─────────────────────────────────────────────────── │
│  └─ 🔹 设备采购规则  │  高风险阈值:  [===========|====] 0.85                │
│ 📁 销售类合同 (2)    │  必须包含条款: [☑ 违约责任] [☑ 争议解决] [☑ 验收标准]│
│ 📁 劳动类合同 (1)    │  [ 💾 保存配置修改 ]                                 │
└──────────────────────┴──────────────────────────────────────────────────────┘

```

- **关联 API 映射**：
  - `GET /settings/rules`：获取所有合同审查规则配置列表。
  - `GET /settings/rules/{config_id}`：加载选中规则的具体详情。
  - `PUT /settings/rules/{config_id}`：修改并保存规则参数、Prompt 配置与阈值。
