## 3. 真实语义联调实测（**本次最有价值的证据**）

环境：本机 **ollama 0.34.0 + `bge-m3:latest`（1024 维，CPU）**；向量库 `qdrant`（`local_memory`，无需容器）。

| 项 | 改前（默认 `hash` + `noop`） | 改后（`http` bge-m3） |
|---|---|---|
| 冒烟 3 条查询 `returned` | 2 / **0（EMPTY_RECALL）** / 2 | **3 / 3 / 3** |
| `top_score`（阈值 0.35） | 0.5017 / **0.3398** / 0.4896 | **0.8025 / 0.7365 / 0.7743** |
| `EMPTY_RECALL` 次数 | 1 | **0** |
| 日志里的向量化模型 | `hash-trick-v1` | **`bge-m3`** |
| 语义区分度（余弦） | 无区分力 | 近义 **0.8513** vs 无关 **0.5396** |

**延迟（CPU 实测）**：冷启动 / 空闲后再加载 **≈ 34 ~ 41 s**；热态单条 **≈ 0.42 ~ 0.48 s**；批量 32 条 **≈ 43 s**。

> ⚠️ **由此得出一条对 `.env.example` 的修正**：`1-6 §⑥.1` 建议的 `CG_RAG_EMBED_TIMEOUT_MS=10000`
> 在 ollama + CPU 上**不够**（每次模型被卸载后必然超时降级，现象是"服务明明好的，检索却突然变差"）。
> 走 ollama 时建议 **≥ 60000**；生产建议换 TEI / 云端 API（届时 10000 够用）。

## 5. 两处**卡内纠偏**（原文保留，已写明理由）

| # | 卡片原文 | 实测/落地 | 理由 |
|---|---|---|---|
| 1 | 维度不符时"**该批返回 `None`**" | 改为：记 `embed.degrade` 后抛 **`EmbedFailedError`** | `EmbedderPort` 是**冻结**协议（`list[list[float]]`），返回 `None` 会让上层聚合 `TypeError`，而改 `service.py` 不在本卡授权内 |
| 2 | 超长文本"按 `CG_RAG_MAX_QUERY_CHARS` 截断" | 改为：**本层不截断**，原样送服务；超长由服务端拒绝 → 上层降级 | 该配置项的消费方在 **C9 字段描述 + `1-3 §⑧`** 中已明确归属 Agent 工具层（T-B4），`rag-core` 不实现切分（分层红线）；且卡内 §⑩-4 本身要求"口径各自声明" |

另新增一个公开符号 `detect_provider()`：本卡不许新增 `embed_provider` 配置项，provider 只能从**既有配置值**反查
（裸 provider 名 `ollama`，或 URL `host:port` 命中预设表）。

## 8. 影响面与风险（回归判断）

- **默认离线路径零变化**：`embed_mode` 默认仍是 `hash`，`HashEmbedder` 行为逐字未改
  （守卫用例 `test_default_hash_embedder_matches_blank_policy`）。
- **显式配置者零影响**：`.env.example` 第 27~33 行本就显式写了 `EMBED_BASE_URL` / `EMBED_PATH`，
  预设**不会**覆盖显式值（`test_explicit_config_wins_over_preset`）。
- **唯一行为变化**：只设 `CG_RAG_EMBED_MODE=http` 而**不写** `base_url` / `path` 时，`path` 会从字段默认
  `/v1/embeddings` 变为预设的 `/embed`（默认 `base_url=http://localhost:8080` 命中 TEI 预设）。
  这与 `1-6 §⑤`「TEI 自部署首选」一致，已在卡片 §⑤ 标注。
- **风险与缓解**：ollama + CPU 冷启动 **34~41 s**，若按 `1-6 §⑥.1` 的 10000 ms 配，会在模型被卸载后
  **稳定降级** → 已在 `1-6 §⑪.3` 建议 ≥ 60000；失败只走既有降级（`degraded=True`），不崩。
- **不引入新依赖**：只用 stdlib（`urllib.parse`）+ 既有 `httpx` / `cg_observability`；
  `rag-core` 仍**不含** `torch` / `sentence-transformers`。
