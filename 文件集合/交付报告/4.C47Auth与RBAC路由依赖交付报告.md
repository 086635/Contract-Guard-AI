## 3. 实现说明

### 3.1 OpenAPI logout 契约

落点：`packages/schema/openapi.yaml`

新增：

```text
LogoutData { revoked: boolean }
LogoutResponse = ApiEnvelopeBase + { data: LogoutData }
POST /auth/logout
```

`/auth/login` 与 `/auth/refresh` 保持 `security: []`；其余 auth/admin 路由继承全局 Bearer 安全声明。

### 3.2 Bearer 当前用户依赖

落点：`apps/api-gateway/app/api/deps.py`

```text
get_current_user():
  HTTPBearer(auto_error=False)
  -> JwtService.verify_access
  -> UserRepository.get(sub)
  -> 检查用户是否存在且启用
```

无 token、错误 token、无效用户统一返回 401。

### 3.3 角色门槛

```text
require_roles(Role.ADMIN)
```

- 复用 `get_current_user`；
- 非允许角色统一返回 403；
- 不在业务路由重复写角色判断。

### 3.4 Cookie 与 Origin 边界

- login/refresh 设置 `cg_refresh`；
- logout 删除 `cg_refresh`；
- refresh/logout/admin POST/PATCH 依赖 `verify_origin`；
- Origin 必须匹配 `settings.cors_origins`，否则返回 403。

### 3.5 路由事务

- login、refresh、logout、create_user、update_user 成功后在路由层提交 `AsyncSession`；
- `AuthService` 只 flush，不在正常路径自行提交；
- refresh 重放触发的安全补偿由 `AuthService.refresh` 在抛错前提交，避免被失败响应回滚；
- 登录失败时提交已持久化的失败次数/锁定状态，避免 HTTP 错误路径回滚锁定策略；
- 其他未持久化错误的路径保持事务回滚/关闭语义。

### 3.6 业务路由保护

`main.py` 对以下路由统一挂 `dependencies=[Depends(get_current_user)]`：

- contracts
- agent
- config
- report
- feedback
- tasks

公开入口只剩：

```text
GET /health
POST /api/v1/auth/login
POST /api/v1/auth/refresh
```
