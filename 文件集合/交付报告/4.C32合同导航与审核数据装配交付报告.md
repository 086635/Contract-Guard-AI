## 1. 任务目标

C32 解决合同中心到审核工作台的真实导航和数据装配：

```text
合同中心
  -> /contracts/{真实 contractId}/audit
  -> Audit 读取路由 contractId
  -> 并行加载六路数据
  -> 成功：显示审核工作区
  -> 部分失败：保留已成功数据 + 可重试错误
  -> 无/非法 ID：返回合同中心或显示空/错状态
```

## 3. 实现说明

### 3.1 路由

落点：`apps/web-ui/src/router/index.tsx`

- 保留：
  - `/contracts`
  - `/contracts/:contractId/audit`
  - `/contracts/:contractId/report`
  - `/settings/rules`
  - `/feedback`
- `/audit`、`/report` 无 ID：重定向 `/contracts`；
- legacy `/audit/:contractId`、`/report/:contractId` 使用 `useParams()` 转发到动态路由。

### 3.2 侧边栏导航

落点：`apps/web-ui/src/components/layout/AppShell.tsx`

从当前 pathname 解析：

```text
/contracts/{contractId}/audit
/contracts/{contractId}/report
```

有合同时生成真实合同路径；无当前合同时审核/报告入口回到 `/contracts`。固定 `12` 任务计数已移除。

### 3.3 Audit 六路装配

落点：`apps/web-ui/src/views/Audit.tsx`

- 只接受路由 `contractId`；
- UUID 非法时不发请求，直接显示错误；
- 六路并行请求：

```text
contractApi.detail
contractApi.elements
contractApi.risks
contractApi.conflicts
contractApi.seals
contractApi.parseStatus
```

- 使用 `Promise.allSettled` 汇总；
- 成功的接口更新对应状态；
- 失败的接口只影响错误提示，不清空其它成功数据；
- 无审核数据时不渲染工作区，只显示可重试空/错状态。
