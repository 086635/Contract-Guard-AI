## 1. 任务目标

C52 建立横切写操作幂等：

```text
HTTP middleware
  -> Redis idempotency store
  -> 首次执行 / 同 body 重放 / 不同 body 409 / Redis down 503
```

并统一前端读取 C51 `ApiError` 的方式。

---

## 2. 实现说明

### 2.1 幂等存储适配器

落点：`apps/api-gateway/app/services/idempotency.py`

- `canonical_body_hash`：
  - JSON 规范化排序后 SHA-256；
  - 非 JSON 使用原始 bytes；
- `idempotency_key`：
  - `cg:idempotency:{operationId}:{userId}:{requestId}`；
- `IdempotencyStore.begin`：
  - 先读已有快照；
  - 无快照时使用 `SET NX EX=86400` 抢首次执行锁；
- `IdempotencyStore.complete`：
  - 写入响应快照；
- `IdempotencyStore.release`：
  - 5xx 或未完成时释放锁；
- 快照不保存 Authorization/Cookie。

### 2.2 中间件

落点：`apps/api-gateway/app/api/middlewares/idempotency.py`

- 仅对声明的幂等写路由启用；
- 缺失或非法 `X-Request-ID` → 422 `ERR_VALIDATION`；
- `login/refresh` 要求 header，但绕过响应缓存，避免重放时丢失 refresh `Set-Cookie`；
- 同 key 同 body → 直接返回缓存响应；
- 同 key 不同 body → 409 `ERR_DUPLICATE_REQUEST`；
- Redis/存储异常 → 503，`detail=idempotency store unavailable`；
- 响应继续带 `X-Request-ID` / `X-Trace-Id`；
- 非幂等路由完全绕过 Redis。

### 2.3 前端错误适配

落点：`apps/web-ui/src/api/client.ts`

- 解析 ApiError：
  - `message`
  - `detail`
  - `traceId`
  - `code`
  - `issues[]`
- 用户可见消息优先 `message`；
- `detail` 仅作为兼容回退；
- 业务组件不再维护第二套裸 `detail` 分支。

### 2.4 OpenAPI

- 新增 `ServiceUnavailable` response；
- 对 `/auth/logout`、`/contracts/presign` 补充必填 `X-Request-ID`；
- 对 Redis fail-closed 503 提供统一错误说明。
