## 1. 任务目标

把「`client.ts` 里 Zod 校验还是 TODO」推进为可用的运行时防线：

1. 建立 operationId → 生成 Zod Schema 的注册表；
2. 开发/测试校验失败立即抛错，脏数据不得进入页面核心状态；
3. 生产记录 operationId/traceId 并**拒绝**脏数据（不静默接受）；
4. 错误体按 `ApiError` 校验；覆盖合同详情、风险、上传、rewrite、报告与权限响应。

---

## 2. 实现说明

### 2.1 注册表与校验（`src/api/client.ts`）

- 新增 `endpointSchemas`（Map）+ `registerOperationSchema` / `registerApiErrorSchema` / `registeredOperationIds`；
- `validateOperationResponse(operationId, payload)` → 合法返回 `null`，非法返回 `ApiClientValidationError`（携带 `operationId` / `traceId` / issue 路径，**不含响应内容**）；
- `parseOperationResponse(...)` → 先上报再抛错：`DEV/TEST` 用 `console.error` fail fast；`PROD` 用 `console.warn` 上报后**同样抛错**；
- 成功拦截器：从 `response.config._operationId` 取操作名 → 校验 `response.data`（生成物 `*Response` 包络 schema，已包含业务 `data`）；
- 错误拦截器：`validateApiErrorBody(error.response.data)` 校验 `ApiError`，**兼容期只上报形状漂移**，继续保留 `detail` 回退一个发布周期；
- `declare module "axios"` 增加 `_operationId?: string`（类型安全，不加自定义 HTTP 头）。

### 2.2 operationId 登记（`src/api/services.ts`）

- `OPERATION_SCHEMAS`：30 个端点的 operationId → 生成 schema（`schemas.ContractDetailResponse` 等）；
- 每个 `httpClient` 调用显式带 `_operationId`（登录/刷新/登出/当前用户、合同列表/详情/要素/风险/矛盾/印章/解析状态/提交、presign/上传、预览/重试、任务/stream-token、报告查询/生成、规则读写、标准条款 CRUD/重建、反馈、改写）；
- 对外直传 `httpClient.put(presignedUrl, ...)`（MinIO 预签名 PUT）**不登记**，由 `isExternalRequest` 自动跳过；
- `P0_OPERATION_IDS` 常量供验收测试断言（合同详情/风险/上传/改写/报告/权限）。

### 2.3 未生成/未消费端点

- SSE `streamTask` 走 `EventSource`（非 axios），不在拦截器内，消息解析由 C65 `parseTaskProgress` 负责；
- `/admin/users`、`/audit/events` 当前 web-ui 未消费 → 未登记 schema（登记表可随时追加，不改生成物）。

## 7. 边界与后续

### 边界声明

- **不手写第二套业务 Schema**：全部复用 `generated/zod.ts`（`schemas.*`）；生成物零改动；
- **不做全局 any 容错**：校验失败一律拒绝；错误体仅保留既有 `detail` 回退（一个发布周期）；
- **不在组件里校验**：注册表在 `services.ts`、策略在 `client.ts`，组件只消费 services；
- **不打印响应内容**：上报只含 operationId / traceId / issue 路径（§⑥.2）。

### 残余与归属

- **SSE 通道**（`streamTask`）不在 axios 拦截器覆盖内 → 由 C65 解析层容错，真实回归归 **C75**；
- **管理端点**（users/audit）web-ui 暂未消费 → 需要时在 `OPERATION_SCHEMAS` 追加即可；
- **bundle 体积**：Zod + 30 个生成 schema 进入生产包（+90 kB raw / +20 kB gzip），属本卡要求的运行时防线代价；如需缩减，可在 C74 评估按需注册策略。
