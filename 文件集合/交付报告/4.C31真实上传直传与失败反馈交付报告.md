## 3. 实现说明

### 3.1 `uploadApi.directUpload()`

落点：`apps/web-ui/src/api/services.ts`

```ts
await httpClient.put(presignedUrl, file, {
  baseURL: "",
  headers: { "Content-Type": file.type || "application/octet-stream" },
  timeout: 120_000,
});
```

行为：

- 不解析/替换 host；
- `.local` 不再返回成功；
- 非 2xx、CORS、连接失败、超时都会 reject；
- 错误由 C29 统一 Client 和 `UploadPanel` 处理。

### 3.2 `UploadPanel.tsx`

状态：

```text
idle
  -> uploading
  -> parsing
  -> done

uploading/parsing
  -> failed
  -> uploading（重试重新 presign）
```

关键规则：

- 文件扩展名只允许 PDF/DOCX；
- 文件大小不超过 50 MB；
- 每次重试都重新调用 presign，不复用失效 URL；
- `DONE` 才能进入审核；
- 进入审核前校验真实 UUID `contractId`；
- `close()` 与卸载统一调用 `unsubscribe`；
- `busyRef` 防止重复提交；
- 临时状态在组件关闭时清理。
