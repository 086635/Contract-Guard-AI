| `tests/test_llm_factory.py` | 17 条离线单元测试 |

### 3.2 关键行为

#### 默认离线

- `LlmSettings.provider` 默认 `offline`。
- `build_chat_model()` 默认返回 `OfflineChatModel`。
- 离线桩能按 Pydantic JSON Schema 生成合法最小对象，覆盖：
  `str`、`int`、`float`、`bool`、`list`、`Optional`、`enum`、`$ref`、`allOf`。

#### 配置错误快速失败

- `openai` 或 `deepseek` 缺少 API Key 时，构建期抛 `LlmConfigError`。
- 缺 Key 时不会构造 `ChatOpenAI`，不会静默联网。
- API Key 以 `SecretStr` 传入底层模型，不写日志、不入库。

#### 模型缓存

- 缓存键为原始标量元组，覆盖 provider、model、temperature、max tokens、
  timeout、retries、API Key、base URL、json mode。
- `clear_llm_cache()` 用于测试隔离和配置热更新。

#### 三级结构化降级链

1. `with_structured_output(schema, method="function_calling")`
2. `response_format={"type":"json_object"}` + 手工 Pydantic 校验
3. 纯提示词 + 后置 JSON 提取与校验

任何一级失败都会记录 warning，最终仍失败时返回 `(fallback, warnings)`，不向节点抛异常。

#### reasoning 截断守卫

- 识别“content 为空 + reasoning tokens 触碰 max_tokens”或 `finish_reason=length`。
- 判定截断后记录 warning，并允许最多一次放大 `max_tokens` 重试。
- 该路径由离线可编程假模型覆盖。

- content 非空。

- 当前服务未复现旧的空 content 现象。
- 代码中的守卫仍保留，并由离线假模型测试覆盖。
- 该差异属于外部模型行为演进，不应删除守卫。
