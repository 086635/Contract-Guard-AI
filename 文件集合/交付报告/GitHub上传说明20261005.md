## 在另一台机器启用相同检索配置

先安装 Ollama、官方 Qdrant server，按 `测试记录20261005/本地向量与三库检索/模型与运行包来源.json` 的固定版本下载 BGE-M3 GGUF 并核对 SHA-256。将 GGUF 导入 Ollama 为 `bge-m3-local:q8`。这些大文件无需放入 Git 仓库。

沿用原启动流程，在本机运行环境显式设置以下配置；密钥仅在本机配置，不能写入源代码：

```text
CG_LLM_PROVIDER=deepseek
CG_LLM_MODEL=deepseek-flash
CG_LLM_BASE_URL=https://api.deepseek.com/v1
CG_LLM_ALLOW_EXTERNAL_DATA=true
CG_LLM_JSON_MODE=json_mode
CG_RAG_VECTOR_STORE=qdrant
CG_RAG_QDRANT_MODE=server
CG_RAG_QDRANT_URL=http://127.0.0.1:6333
CG_RAG_COLLECTION=contract_knowledge_bge_m3_20261005
CG_RAG_EMBED_MODE=http
CG_RAG_EMBED_BASE_URL=http://127.0.0.1:11434
CG_RAG_EMBED_PATH=/v1/embeddings
CG_RAG_EMBED_MODEL=bge-m3-local:q8
CG_RAG_EMBED_BATCH_SIZE=4
CG_RAG_EMBED_TIMEOUT_MS=120000
CG_RAG_BM25_ENABLED=false
CG_RAG_STRATEGY=DENSE_ONLY
```

`CG_LLM_API_KEY` 使用自己的私有密钥。`CG_KNOWLEDGE_MANIFEST` 指向本机绝对路径的 `文件集合/知识库/官方初始库20261005/sources.json`。API 与 worker 使用同一运行配置。准备原数据库与服务后导入：

```powershell
python scripts/import_official_knowledge.py --manifest "文件集合/知识库/官方初始库20261005/sources.json"
```

初始库是 2 份官方范本、按类型展开的 70 个条款记录和民法典 1260 条。范本没有企业审批效力；工业产品采购只能参考其通用表述。需要完整标准比对时，由管理员补充已审批的企业标准条款。
