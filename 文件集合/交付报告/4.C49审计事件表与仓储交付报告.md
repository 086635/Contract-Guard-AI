## 3. 实现说明

### 3.1 审计动作与结果

落点：`apps/api-gateway/app/db/models.py`

`AuditAction`：

```text
LOGIN / REFRESH / LOGOUT / UPLOAD / VIEW / REWRITE / COMMIT / REPORT / EXPORT
SETTINGS_UPDATE / USER_CREATE / USER_UPDATE / AUTH_DENIED
TASK_RECOVERED / FILE_REJECTED
```

`AuditOutcome`：

```text
SUCCESS / FAILURE / DENIED
```

### 3.2 AuditEvent 模型

落点：`apps/api-gateway/app/db/models.py`

字段：

- `id`
- `actor_id`（可空）
- `actor_role`（可空，复用 `Role`）
- `action`
- `resource_type`
- `resource_id`
- `outcome`
- `ip_address`
- `user_agent`
- `trace_id`
- `metadata`（ORM 属性名为 `event_metadata`，DB 列名为 `metadata`）
- `created_at`

索引：

- `ix_audit_events_created_at`
- `ix_audit_events_actor_created`
- `ix_audit_events_action_created`
- `ix_audit_events_trace_id`
- `ix_audit_events_resource`

### 3.3 迁移

落点：

`apps/api-gateway/alembic/versions/20260930_0010_add_audit_events.py`

- `upgrade` 创建表与全部索引；
- `downgrade` 删除索引和表；
- 支持 upgrade/downgrade/upgrade 真实 PostgreSQL 往返。

### 3.4 仓储

落点：`apps/api-gateway/app/db/repository/audit.py`

```text
AuditRepository.append(AuditEventCreate) -> AuditEventRecord
AuditRepository.list(filters, page, page_size) -> (records, total)
```

- `append` 只 `flush`，调用方管理事务；
- `list` 使用 `created_at DESC, id ASC` 稳定排序；
- 支持 `actor_id`、`action`、`resource_type`、`resource_id`、`outcome`、`trace_id`、时间区间过滤；
- `metadata` 必须是 JSON object；
- 仓储不提供 `update` / `delete`。
