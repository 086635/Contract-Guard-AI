## 2. 终裁：Qdrant 主力 + Milvus 备选

### 2.1 裁决表

| 项 | 结论 |
|---|---|
| **主向量库** | **`QdrantVectorStore`** —— 保持现行配置，**不改默认路径**，主库侧**零工作量** |
| **离线 / 单测** | **`InMemoryVectorStore`** —— 零依赖，"默认路径离线可跑"红线不变 |
| **Milvus 定位** | **备选适配器（P2）** —— 用途是**展示 Ports & Adapters 的可扩展性**，不阻塞达标 |
| **默认值红线** | `CG_RAG_VECTOR_STORE` 的**代码默认仍是 `inmemory`**；生产/演示在 `.env` 显式设 `qdrant`。**Milvus 不得成为任何默认值** |
| **数据迁移** | **不做**（生产库不切换）→ **T-A10 取消** |

### 2.2 为什么不是"以 Milvus 为核心"——四条硬理由

| # | 理由 | 依据 |
|---|---|---|
| 1 | **决定分数的是语义与度量，不是向量库。** 硬指标是"风险条款识别召回率 ≥75%"，瓶颈在 `HashEmbedder`（伪向量）＋ `NoopReranker`（无精排）；换库对召回率的边际收益 **≈ 0** | 实测：冒烟 3 条查询 1 条 `EMPTY_RECALL`，原因为默认非语义向量 |
| 2 | **开发机是 Windows，而 Milvus Lite 官方支持矩阵不含 Windows** → 只能走 Docker 三件套（etcd + MinIO + Milvus），冷启动 30~60s；Qdrant 是**单容器、秒级** | `1-4` §⑦ |
| 3 | **演示可靠性**：单容器 vs 三件套，活动部件越少越好；答辩是"当场跑一遍"的场景 | `1-4` §⑥ |
| 4 | **规模用不上**：本项目切片量级 10⁴~10⁵，Qdrant 单容器可覆盖到百万级；Milvus 的十亿级/分布式优势在此**无收益** | `vector_dim=1024`、`collection=contract_clauses` |

### 2.3 红线（已写入文档，可直接被 code review 引用）

1. **默认路径永远是 `inmemory`（离线）或 `qdrant`（生产）**。
2. **Milvus 不得成为任何默认值**，也**不得成为关键路径上的依赖**。
3. **不做数据迁移**（T-A10 取消）—— 生产库不切换，迁移无意义。
4. **本次不替换自研 BM25** —— 原 D1.5 的"用 Milvus 原生稀疏向量替掉自研 BM25"明确**不做**。

### 3.2 本次最重要的新增：§0.11 文档权威层级

**问题背景**：`文件集合/report/` 下曾有 **3 份文档各自宣称自己是"唯一依据"**，且方向不一致，读者无法判断该信哪一份 —— 这是本项目**最大的二义性来源**。

**处理**：把它们拆到**三个正交的轴**上，"唯一"各自成立、不再竞争：

| 层 | 文档 | 只在这些问题上**有权威** | 不得用于 |
|---|---|---|---|
| **L0 · 施工** | `文件集合/codex/*` | **任务拆分、执行顺序、验收断言、落点** | 定义契约字段 |
| **L1 · 契约** | `RAG_MODULE_DESIGN.md` | **契约字段、接口签名、枚举取值** | 定实现细节、定命名 |
| **L2 · 实现** | `RAG搭建框架.md` | **标识符命名总表、算法实现细节** | 定义契约字段 |
| **L3 · 事实** | `项目代码深度阅读与分析报告.md` | **"仓库现在是什么样"（实测）** | 设计决策 |
| **L4 · 计划** | `codex项目推进.md` | **任务编号、决策登记（D1–D4）** | 定义契约字段 |
| **L5 · 阅读** | `RAG白皮书.md` / `RAG对照解析.md` | 仅供**理解概念** | **任何实现依据** |
| **L6 · 历史** | `RAG_IMPLEMENTATION_GUIDE.md` / `AI核心开发文档.md` / `核心构建PRD.md` | 仅作**决策演进档案** | **任何实现依据** |

**三条裁决规则**（已写入 §0.11.2）：

1. **L0~L2 之间不重叠**：L0 管"做什么 / 怎么算做完"，L1 管"字段长什么样"，L2 管"代码怎么写、叫什么名"。三者不构成竞争 —— 所以"唯一依据"应各自限定在这三个**正交**的轴上。
2. **L5 / L6 不得被引用为实现依据**。若 L0~L2 出现空缺，**应补 L0~L2，而不是去 L6 找答案**。
3. **同一事实在多层出现且不一致时，以层级高者为准，并必须回头修正低层** —— 修正方式一律为**追加"⚠️ 文档纠偏声明"**，**不删原文**（保留决策演进痕迹）。
