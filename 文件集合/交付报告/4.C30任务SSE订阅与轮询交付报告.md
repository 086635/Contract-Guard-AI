## 1. 任务目标

C30 解决前端任务进度的真实订阅与断线兜底：

```text
GET /tasks/{taskId}/stream
  -> event: progress
  -> TaskProgress 裸载荷
  -> RUNNING 持续回调
  -> DONE / FAILED 关闭连接并清理

SSE error
  -> 关闭 EventSource
  -> 每 2 秒调用 GET /tasks/{taskId}
  -> 任务终态后停止
  -> unsubscribe 后彻底停止
```

本卡只负责 API 层生命周期，不实现页面按钮、路由跳转或上传逻辑。

## 3. 实现说明

### 3.1 命名事件

```ts
source.addEventListener("progress", handleProgress as EventListener);
```

不再使用 `source.onmessage` 作为主通道。`event.data` 只接受裸 `TaskProgress`，同时保留对 envelope 的兼容读取。

### 3.2 事件校验

`parseProgress()` 对以下字段做类型守卫：

- `taskId: string`
- `stage: string`
- `percent: number`
- `status: RUNNING | DONE | FAILED`

解析失败只告警，不让页面收到脏进度。

### 3.3 终态清理

统一 `finish()`：

```text
stopped = true
clearInterval(pollTimer)
source.close()
```

`DONE` 或 `FAILED` 均通过 `emit()` 进入该清理路径，且重复调用 `unsubscribe()` 幂等。

### 3.4 断线轮询

SSE `onerror` 后：

1. 调用调用方 `onError`；
2. 关闭 EventSource；
3. 启动 `setInterval(..., 2000)`；
4. 每轮调用 `taskApi.get(taskId)`；
5. 请求异常只告警，不伪造终态；
6. 收到 `DONE/FAILED` 后停止 timer。
