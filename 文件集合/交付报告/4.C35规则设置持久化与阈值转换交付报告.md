## 3. 实现说明

### 3.1 草稿来源

`selectRule(next)`：

- 复制 `promptConfig`；
- 复制 `enabledRules`；
- 复制 `reviewThresholds`；
- 复制 `customEntities`；
- 作为当前可编辑草稿。

切换规则时新建草稿，不复用上一规则阈值。

### 3.2 转换

```ts
percentToRatio = value => Math.max(0, Math.min(1, value / 100))
ratioToPercent = value => Math.round(value * 100)
```

UI：

- 滑块 `min=0 max=100`
- 标签显示 `%`
- API DTO 始终保存 0~1

### 3.3 保存与冲突

```text
settingsApi.update(rule.id, rule)
  -> 200：setRule(updated) + setRules(updated)
  -> 409：显示“配置版本冲突，请重新加载后再保存。”
```

失败不会自动重试覆盖。
