## 2. 实现内容

### 2.1 私有结构化输出模型

落点：[nodes.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:30)

```python
class _ClassifyOutput(BaseModel):
    contract_type: ContractType


class _ElementDraft(BaseModel):
    key: str
    label: str = ""
    value: str | None = None
    confidence: float = Field(default=0.0, ge=0.0, le=1.0)
    is_custom: bool = True


class _ExtractBatch(BaseModel):
    elements: list[_ElementDraft] = Field(default_factory=list)
```

这些模型只用于 LLM structured output，不进入 `AuditState`。

### 2.2 `classify_node`

落点：[classify_node](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:239)

执行流程：

1. 使用 C4 `_bounded_clauses()` 获取受预算约束的 clauses。
2. 无 clauses：返回 `contract_type=None`、`SKIPPED`、warning。
3. 缺 `classify.prompt`：返回 `contract_type=None`、`SKIPPED`、`llm_calls=0`。
4. 使用 `contract_id` 作为稳定的 `contract_title` 占位；不得新增 state 键。
5. 渲染 `clause_excerpt`，调用 `invoke_structured(_ClassifyOutput)`。
6. 成功写入 `ContractType` 和 `llm_calls=1`；失败返回 `DEGRADED`。

成功路径：

```text
state.contract_type = ContractType
state.llm_calls += 1
stage_log.stage = "classify"
stage_log.status = "OK" | "DEGRADED"
```

### 2.3 `extract_node`

落点：[extract_node](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:317)

#### 已有 elements 路径

- 只归一化，不调用 LLM。
- 统一为 OpenAPI `ContractElement` 的 6 字段：

```text
key
label
value
confidence
bbox
isCustom
```

- 去重键固定为 `(key, label, value)`。
- 缺少 `label` -> `key`。
- 缺少 `value` -> `None`。
- 缺少 `confidence` -> `0.0`。
- 缺少 `bbox` -> `None`。
- 缺少 `isCustom` -> `False`。
- 无效条目不进入 state，并以 warning 记数。

#### elements 为空的补漏路径

- 只有存在 clauses 且存在 `extract.prompt` 时才调用 LLM。
- 模板缺失返回 `elements=[]`、`SKIPPED`、`llm_calls=0`。
- 模型成功时将 `_ElementDraft` 转为纯 dict。
- 补漏要素强制 `bbox=None`、`isCustom=True`。
- 模型失败返回 `elements=[]`、`DEGRADED`。

### 2.4 阶段日志

两个节点都通过 C4 共享 helper 输出：


日志字段包括：

```text

```

不把 Prompt 全文写入日志。
