## 1. 实现内容

### 1.1 C7/C8 扩展

- `TaskDispatcherPort.get_status()` 返回 `TaskStatusSnapshot`。
- `CeleryTaskDispatcher` 读取 AsyncResult 状态与 meta。

### 1.2 TaskService

落点：[task_service.py](E:/important_project/Serve_bage/apps/api-gateway/app/services/task_service.py:1)

- `get()`：DB task 提供身份，Celery 快照覆盖实时 stage/percent/status。
- `stream()`：先发当前快照，再订阅 Redis。
- DONE/FAILED 后主动结束。
- 非法 Redis 事件只记录 warning 并忽略。

### 1.3 SSE 与路由

- [sse.py](E:/important_project/Serve_bage/apps/api-gateway/app/services/sse.py:1) 负责 SSE 序列化。
- [tasks.py](E:/important_project/Serve_bage/apps/api-gateway/app/api/v1/tasks.py:1)
  `GET /tasks/{taskId}` 与 `/stream` 已去 Mock。
- SSE 返回 `text/event-stream`，并设置 no-cache / nginx buffering 关闭。
