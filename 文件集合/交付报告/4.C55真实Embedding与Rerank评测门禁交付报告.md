## 1. 任务目标

C55 把 RAG 语义链路从“配置可切换”推进到“生产可门禁”：

1. production 必须使用 HTTP/TEI/OpenAI-compatible embedding 与 HTTP rerank。
2. 提供 dense / sparse / rerank 健康检查与失败分类。
3. 评测复用既有 `scripts/eval_recall.py` 和 `1-7 §8.3` 阈值。
4. 校验 Qdrant collection 维度，防止“换 embedding 模型但不重建索引”。

## 2. 实现说明

### 2.1 RAG 生产配置门禁

落点：`packages/rag-core/rag_core/config.py`

`RagSettings.validate_production()` 现在拒绝：

```text
CG_RAG_EMBED_MODE=hash
CG_RAG_RERANK_MODE=noop
CG_RAG_RERANK_ENABLED=false
HTTP embedding 缺少 base_url
HTTP rerank 缺少 http_url
空 embedding/rerank 模型名
```

development/test 默认离线行为不变。

### 2.2 健康检查

落点：`packages/rag-core/rag_core/factory.py`

新增：

```text
health_check(settings=None) -> {dense, sparse, rerank}
```

状态语义：

- `ok`：探针通过；
- `disabled`：功能显式关闭；
- `empty`：BM25 索引为空；
- `failed:<ExceptionType>`：底层探针失败，保留异常类型用于定位。

探针内容：

- dense：实际执行 embedding，校验向量维度，再校验向量库 collection 维度；
- sparse：装配 BM25 并执行一次检索，空索引返回 `empty`；
- rerank：HTTP rerank 执行一次最小 `rerank()` 调用，结构异常归类 `RerankFailedError`。

### 2.3 Qdrant collection 维度守卫

落点：`packages/rag-core/rag_core/adapters/qdrant_store.py`

`ensure_collection(dim)` 对已有 collection 读取真实维度：

```text
actual_dim != expected_dim
  -> StoreUnavailableError
```

错误 detail 记录 `collection`、`expected_dim`、`actual_dim`，不静默重建、不静默写入。

### 2.4 评测生产门禁

落点：`scripts/eval_recall.py`

新增 CLI：

```text
--require-production-threshold
```

该开关要求：

- `embed_mode=http`
- `rerank_mode=http`
- `vector_store=qdrant`
- 人工标注 `Recall@5 >= 0.80`

阈值常量：

```text
PRODUCTION_RECALL5_THRESHOLD = 0.80
```

来源：`1-7 §8.3`。脚本没有新增第二套阈值或基线。

输出新增：

```text
production_gate:
  status: PASS|FAILED
  recall@5
  mrr
  recall@5_threshold
  embed_mode
  rerank_mode
  vector_store
```
