## 1. 任务目标

C54 解决三类问题：

1. 真实模型 provider 必须继续由唯一 factory 构造，支持 OpenAI / DeepSeek / Ollama 切换，禁止第二套客户端。
2. 审核图模型失败必须区分：
   - 单条款失败 → 整体 `DEGRADED`；
   - 全部模型调用失败或核心节点不可用 → 整体 `FAILED`；
   - 不得用空 risks 伪装“无风险”。
3. rewrite 必须返回完整 `RewriteData`，失败必须有明确错误映射，不能被 offline 空结果伪装成成功。

## 2. 实现说明

### 2.1 LLM provider 与外部数据开关

落点：

- `packages/ai-engine/ai_engine/llm/factory.py`
- `packages/ai-engine/ai_engine/llm/settings.py`

变更：

- `LlmSettings` 新增：

```text
allow_external_data: bool = False
```

- 生产校验新增：

```text
CG_LLM_ALLOW_EXTERNAL_DATA=true
```

非 offline provider 在 production 下未显式打开该开关时，启动配置校验失败。

- `ChatOpenAI.metadata` 增加：

```text
cg_llm_provider
cg_llm_model
cg_llm_json_mode
cg_llm_allow_external_data
```

- factory 日志增加 `allow_external_data`，不记录合同原文、Prompt 或 API Key。
- 模型缓存键纳入 `allow_external_data`，避免配置切换后复用错误模型实例。

### 2.2 核心节点失败语义

落点：`packages/ai-engine/ai_engine/graphs/nodes.py`

新增稳定错误码：

```text
ERR_LLM_UNAVAILABLE
ERR_LLM_ALL_CLAUSES_FAILED
ERR_LLM_INVALID_RISK
ERR_LLM_INVALID_CONFLICT
ERR_LLM_ALL_CONFLICTS_FAILED
```

risk 节点：

- 模型构造失败 → `FAILED`。
- 单条款模型失败/空风险 → 隔离，最终 `DEGRADED`。
- 所有条款均失败 → `FAILED`。
- 空 title 或空 suggestion 不生成风险对象。

conflict 节点：

- 模型构造失败 → `FAILED`。
- 部分批次失败 → `DEGRADED`。
- 所有批次失败 → `FAILED`。

### 2.3 run_audit 外部状态

落点：

- `apps/async-worker/worker/tasks/run_audit.py`
- `apps/api-gateway/app/services/task_service.py`
- `apps/api-gateway/app/services/ingestion.py`

变更：

- worker 结果中出现 stage `FAILED` 时，顶层结果状态映射为 `FAILED`。
- Celery 状态为 `DONE`、但内部 `result.status=FAILED` 时，任务查询返回 `FAILED`。
- `finalize_audit` 对 `result.status=FAILED` 直接拒绝空入库，避免“模型失败但前端看到 0 风险”。
- FAILED 审核结果清空 `risks/conflicts/missingClauses`，`healthScore={}`，不输出伪健康分。
- FAILED 审核任务使用 `reporter.fail()` 上报失败终态，不伪装成 DONE。

### 2.4 rewrite 成功链

落点：

- `packages/ai-engine/ai_engine/graphs/rewrite_graph.py`
- `apps/async-worker/worker/tasks/rewrite.py`

变更：

- rewrite citations 合并模型输出和 RAG 上下文引用，保证 `RewriteData.citations` 成功链完整。
- rewrite 失败统一补充：

```text
detail.errorCode = ERR_LLM_UNAVAILABLE
```

- offline 空 after 仍会抛出 `RewriteUnavailableError`，不会返回假 `RewriteData`。
