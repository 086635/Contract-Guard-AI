### C43 发现的 C42 接线缺陷

e2e 首轮发现 `POST /contracts/presign` 返回 500：

```text
api 容器 public client endpoint = localhost:9000
presigned URL 生成触发 MinIO SDK GetBucketLocation
localhost 在 api 容器内不是 MinIO -> Connection refused
```

修复方式：

- `app/config.py` 增加 `minio_region: str = "us-east-1"`；
- internal/public 两个 Minio client 都显式传入 `region`；
- Compose API/Worker 注入 `CG_MINIO_REGION=us-east-1`。

修复后 public client 只签名，不发生 `GetBucketLocation` 网络探测，presign 返回 200。
