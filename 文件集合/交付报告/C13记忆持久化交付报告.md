## 2. 实现内容

### 2.1 KV 端口与默认实现

[store.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/memory/store.py:1)

```python
class MemoryStorePort(Protocol):
    get(namespace, key) -> str | None
    set(namespace, key, value, ttl_s=None) -> None
    delete(namespace, key) -> None
    keys(namespace) -> list[str]
```

`InMemoryMemoryStore`：

- 默认 store。
- `clock` 可注入，TTL 测试完全确定。
- `ttl_s=None` 永不过期。
- 读取时惰性清理过期项。

### 2.2 序列化版本壳

```json
{"v": 1, "data": { ...Pydantic model_dump(mode="json")... }}
```

规则：

- 写入前先过 Pydantic。
- 读取使用 `model_validate`。
- 未知版本 / 坏 JSON / 校验失败均按 miss 处理并 warning。

### 2.3 Redis 实现

[redis_store.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/memory/redis_store.py:1)

- `redis` 在构造函数内延迟导入。
- 快速 connect timeout / socket timeout。
- `set(..., ttl_s)` 映射 Redis EX。
- `scan_iter` 实现 namespace keys。

### 2.4 Postgres 实现

[postgres_store.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/memory/postgres_store.py:1)

- `psycopg` 延迟导入。
- 自动创建 `cg_memory_kv`。
- Upsert + `expires_at` TTL + namespace keys。

### 2.5 工厂与降级

[factory.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/memory/factory.py:1)

```python
backend: inmemory | redis | postgres
redis_url
postgres_dsn
ttl_s
key_prefix
```

降级规则：

- 未安装依赖。
- DSN / URL 缺失。
- Redis / Postgres 连接失败。
- 非法后端。

以上情况均返回 `InMemoryMemoryStore` 并记录 `memory.degrade`。

### 2.6 checkpointer 独立工厂

[checkpointer.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/memory/checkpointer.py:1)

- 默认返回 `InMemorySaver`。
- `backend=postgres` 且 DSN 非空时尝试 PostgresSaver。
- 缺包 / 建连失败时回落 `InMemorySaver` + warning。
- 不与业务 MemoryStore 混用。

### 2.7 Manager 注入

`GlobalStateManager` / `ScopedMemoryManager` 均支持注入同一 store：

```python
store = build_memory_store()
global_manager = GlobalStateManager(store=store)
scoped_a = ScopedMemoryManager(store=store, contract_id="C1")
scoped_b = ScopedMemoryManager(store=store, contract_id="C1")
```

不同 manager 实例可读取相同业务记忆。
