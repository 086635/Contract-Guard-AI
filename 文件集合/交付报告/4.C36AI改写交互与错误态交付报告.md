## 1. 任务目标

C36 解决前端 AI 改写真实交互：

```text
当前真实风险
  -> contractId / clauseId / originalText
  -> POST /agent/rewrite
  -> 加载中
  -> 成功：展示真实 before/after/updatedAt/citations
  -> 用户点击“采用”才回调审核页
  -> 失败：显示真实错误，保留输入，重试
  -> 关闭/卸载：忽略晚到响应
```

---

## 2. 范围与边界

### 2.1 本次完成

- `AgentChat` 使用 `agentApi.rewrite()`；
- 将当前 `contractId`、`clauseId` 与 `originalText` 写入请求上下文；
- 加载中禁用重复请求和文本编辑；
- 失败时展示真实 `Error.message`，保留 instruction；
- 只有 `RewriteData` 非空时才渲染真实 before/after；
- `onApplied(data)` 只在用户点击“采用这版修改”后调用；
- 空 citations 显示“暂无引用来源”，不显示伪来源；
- close/unmount 后通过 `activeRef` 忽略晚到响应；
- 不修改 `agentApi` 契约和后端 rewrite 逻辑。

### 2.2 明确不做

- 不在前端实现 LangGraph、RAG、Prompt；
- 不手工构造 RewriteData、Diff、citation、updatedAt；
- 不把 AI 改写视为合同定稿；
- 不改变请求/响应 DTO；
- 不在组件内直接 `fetch` 或新建 Axios。

## 3. 实现说明

### 3.1 请求

```ts
await agentApi.rewrite({
  clauseId,
  contractId,
  instruction: instruction.trim(),
  xRequestId: crypto.randomUUID(),
  scopedMemory: {
    targetClauseId: clauseId,
    draftAfter: originalText,
    recentDialog: [],
  },
});
```

`originalText` 只作为改写上下文，不伪造后端返回结果。

### 3.2 状态

| 状态 | 行为 |
|---|---|
| 加载中 | 禁用生成按钮，显示“生成中…” |
| 成功 | 显示真实 before/after/updatedAt/citations |
| 失败 | 显示真实 message，按钮切换“重试生成” |
| 采纳 | 只在点击“采用这版修改”时调用 `onApplied(result)` |
| 关闭 | `activeRef=false`，晚到 response/reject 不再 setState |
