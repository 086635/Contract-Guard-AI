## 2. 实现说明

### 2.1 `docker/nginx.prod.conf`（新建）

```text
client_max_body_size 50m;                        # == 后端 MAX_UPLOAD_BYTES（C56）
limit_req_zone … zone=cg_api    rate=30r/s       # 常规 API
limit_req_zone … zone=cg_login  rate=5r/m        # 登录（防口令爆破）
limit_req_zone … zone=cg_upload rate=20r/m       # presign / upload

server { listen 80;  return 301 https://$host$request_uri; }
server {
    listen 443 ssl; http2 on;
    ssl_certificate /etc/nginx/certs/server.crt;   # 由部署方挂载，仓库无证书
    ssl_protocols TLSv1.2 TLSv1.3; server_tokens off;
    add_header Strict-Transport-Security … always;
    add_header Content-Security-Policy "default-src 'self'; … frame-ancestors 'none'" always;
    add_header X-Content-Type-Options / Referrer-Policy / X-Frame-Options / Permissions-Policy …;

    location ~ ^/api/v1/tasks/[^/]+/stream$ {       # SSE：绝不缓冲
        proxy_buffering off; proxy_cache off; gzip off;
        proxy_read_timeout 3600s; proxy_set_header Connection "";
    }
    location ~ ^/api/v1/contracts/(presign|upload)$ { limit_req zone=cg_upload …; }
    location = /api/v1/auth/login { limit_req zone=cg_login …; }
    location /api/ { limit_req zone=cg_api …; proxy_pass http://api:8000; }
    location / { proxy_pass http://web:80; }        # SPA（history 回退在 web 服务内）
}
```

- **正则 location 优先于前缀 location**：SSE 与上传/登录的专用配置不会被 `/api/` 覆盖。
- **代理头**：`Host` / `X-Real-IP` / `X-Forwarded-For` / `X-Forwarded-Proto` 全链路补齐（后端审计与限流依赖真实客户端信息）。
- **`nginx -t` 真实验证**：沙箱外用 `nginx:alpine` 挂载本文件 + 自签证书、并 `--add-host api/web` 解析上游 → **syntax ok**。

### 2.2 `docker/docker-compose.prod.yml`（修改）

```yaml
nginx:
  ports: !override ["80:80", "443:443"]
  volumes: !override
    - ./nginx.prod.conf:/etc/nginx/conf.d/default.conf:ro
    - ${CG_TLS_DIR:-./tls}:/etc/nginx/certs:ro
```

`volumes` 必须用 `!override`（compose 对 volumes 默认合并，叠加会出现「同一 target 两个挂载」）。

## 7. 边界与后续

### 边界声明

- **不在 nginx 写业务权限**：只做 TLS/限流/反代，鉴权仍由 API（JWT/streamToken）负责；
- **不关闭 TLS 校验**：不出现 `ssl_verify_client off`，不启用 TLSv1/1.1；
- **不让 SSE 被缓冲**：`proxy_buffering off` + `proxy_cache off` + `gzip off`（§⑨-2）；
- **不新增第二套反向代理**：仍是同一个 nginx 服务，生产用 overlay 换配置文件。

### 两处需知晓的决策

1. **`http2 on;` 而非 `listen 443 ssl http2`**：后者在 nginx ≥1.25 已废弃（会打 warning）；
   卡片 §⑤ 写的是旧语法，本实现采用现行写法，语义一致（本机 `nginx -t` 已通过）。
2. **安全头只加在 443 server 块**：80 块只做 301 跳转，因此不需要（也无法保证）HSTS——
   避免在明文响应上发安全头造成误导。
