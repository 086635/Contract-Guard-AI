### 2.1 ScopedMemoryManager

[scoped_memory.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/memory/scoped_memory.py:30)

新增方法：

```python
record_turn(clause_id, role, content, *, created_at)
set_draft(clause_id, draft_after)
snapshot(clause_id) -> ScopedClauseMemory
```

保留兼容方法：

```python

```

内部结构：

```text
_mem: dict[clause_id, deque[DialogTurn](maxlen=5)]
_drafts: dict[clause_id, str]
```

### 2.2 窗口行为

- 每个 clause_id 独立 deque。
- 窗口满时自动淘汰最旧 DialogTurn。
- `snapshot()` 返回 list 副本，不暴露内部 deque。
- `set_draft()` 不创建空对话窗口。
