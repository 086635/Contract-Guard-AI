## 1. 实现内容

### 1.1 Schema

- `contracts.version`：默认 1。
- `contract_commits`：保存 `request_id/item_id/accepted/version/created_at`。
- 增量迁移：[20260927_0003_add_contract_commits.py](E:/important_project/Serve_bage/apps/api-gateway/alembic/versions/20260927_0003_add_contract_commits.py:1)。

### 1.2 Repository

- `ContractRepository.increment_version()`。
- `CommitRepository.list_by_request()`。
- `CommitRepository.create_items()` 使用 `ON CONFLICT DO NOTHING` 保证同请求同 item 幂等。

### 1.3 Service 与路由

- `CommitService.commit()` 实现：
  - 请求 ID 命中已有明细时直接返回原结果。
  - 合同不存在抛 404。
  - 旧版本抛 409。
  - 空 items 抛 422。
  - 成功项递增合同版本。
  - 写明细并提交事务。
- `POST /contracts/{contractId}/commit` 已去 Mock。
