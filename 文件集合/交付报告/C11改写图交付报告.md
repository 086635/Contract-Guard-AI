## 2. 实现内容

### 2.1 三阶段图

[rewrite_graph.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/rewrite_graph.py:26)

```text
START -> prepare -> rewrite -> finalize -> END
```

| 阶段 | 行为 |
|---|---|
| `prepare` | 复用调用方 context，或用 RagTool 检索 top 3；失败降级继续 |
| `rewrite` | 渲染 `rewrite.prompt`，结构化输出 after / reasoning_steps / citations |
| `finalize` | 生成 Diff，成功后写最近 5 轮记忆快照 |

### 2.2 结构化输出

```python
class _RewriteDraft(BaseModel):
    after: str
    reasoning_steps: list[ReasoningStep]
    citations: list[PreciseCitation]
```

RAG 不可用时，即使模型返回 citations 也会被代码清空，确保没有虚构依据。

### 2.3 Diff

使用 `difflib.unified_diff()` 对 `splitlines()` 生成差异文本，同时保留：

```text
type = "DIFF"
before = 原文全文
after = 改写全文
clauseId
updatedAt
```

`RewriteResponse.diff` 收敛为冻结的 `DiffMessage`。

### 2.4 rewrite_clause

[rewrite_clause()](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/agents/rewriter.py:76)

- `thread_id = f"{contractId}:{clauseId}"`。
- `trace_id` 使用请求 ID。
- 构造 memory 快照并传入 `GraphDeps.memory`。
- 成功后构造 `RewriteResponse`。
- 同 `xRequestId` 命中缓存时直接返回同一对象。

### 2.5 失败与降级

| 情况 | 行为 |
|---|---|
| RAG 缺少 / 异常 / EMPTY | 降级继续，citations=[] |
| 缺 rewrite 模板 | `RewriteUnavailableError` |
| 模型最终失败 / after 为空 | `RewriteUnavailableError` |
| Diff 缺失 | `RewriteUnavailableError` |
| 失败前 | 不写入 memory 快照 |
| 幂等缓存满 | 淘汰最旧 key |
