## 1. 目标与边界

### 1.1 本卡目标

1. 使用 `asyncpg` 建立异步 SQLAlchemy engine。
2. 建立 `async_sessionmaker`，并关闭提交后过期，方便异步读取 ORM 字段。
3. 提供 `get_session()`，每个请求使用独立会话并在退出时关闭。
4. 无 DSN 时允许集成测试自动 skip，保持离线基线。

### 1.2 明确不做

- 不实现任何 Repository 或 DAL 查询。
- 不实现 API 路由接线。
- 不实现连接池调优、读写分离或事务重试策略。
- 不在其它文件创建第二份 engine/sessionmaker。

### 1.3 依赖方向

```text
app.config.settings
        |
        v
app.db.session -> SQLAlchemy asyncpg
```

模块只依赖 `app.config` 与 SQLAlchemy，不依赖 worker、DAL 或契约实现。

## 2. 实现内容

落点：[session.py](E:/important_project/Serve_bage/apps/api-gateway/app/db/session.py:1)

```python
engine = create_async_engine(settings.postgres_dsn, pool_pre_ping=True)
SessionLocal = async_sessionmaker(engine, expire_on_commit=False)


async def get_session() -> AsyncIterator[AsyncSession]:
    async with SessionLocal() as session:
        yield session
```

关键约束：

- DSN 复用 `app.config.settings.postgres_dsn`，不在 session 模块散落读取环境变量。
- 驱动固定为 `postgresql+asyncpg`。
- `expire_on_commit=False`，避免异步提交后读取字段再次触发 IO。
- `get_session()` 使用异步上下文管理，依赖退出时自动关闭会话。
