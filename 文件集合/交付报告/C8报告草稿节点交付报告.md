### 1.2 父文档公式纠偏

`2-4 §⑦` 原示例与 `2-4 §5.5` 公式存在数值矛盾：

```text
原示例：risks=[HIGH, MEDIUM] + missing=1
      -> compliance=95 / performanceRisk=100 / overall=97
```

HIGH 风险本身有 10 分或 8 分扣分，不可能得到对应维度 100。
C8 以 §5.5 公式为唯一口径，并使用如下可核算示例：

```text
performance HIGH + compliance MEDIUM + 1 missing
-> compliance 95 / performanceRisk 90 / clauseCompleteness 97
-> overall round(38 + 36 + 19.4) = 93
```

该纠偏已登记在 C8 卡，并由 `test_formula_performance_high_compliance_medium` 锁死。

### 1.3 明确不做

- 不调用 LLM、RAG Tool、数据库或外部 IO。

## 2. 实现内容

### 2.1 健康分公式

落点：[compute_health_score](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:462)

风险扣分：

```text
HIGH   = 10
MEDIUM = 5
LOW    = 2
```

矛盾扣分：

```text
HIGH   = 8
MEDIUM = 4
LOW    = 1
```

缺失标准对照：

```text
每条 3 分
```

维度计算：

```text
compliance          = clamp(100 - compliance_deduction, 0, 100)
performanceRisk    = clamp(100 - performance_deduction, 0, 100)
clauseCompleteness = clamp(100 - 3 * missing_count, 0, 100)

overall = round(
    0.4 * compliance
    + 0.4 * performanceRisk
    + 0.2 * clauseCompleteness
)
```

输出：

```python
{
    "overall": int,
    "dimensions": {
        "compliance": int,
        "performanceRisk": int,
        "clauseCompleteness": int,
    },
}
```

### 2.2 维度映射

`performanceRisk` 风险类别：

```text
UNLIMITED_LIABILITY
LIABILITY_IMBALANCE
PENALTY_TOO_HIGH
PAYMENT_TERM_RISK
UNILATERAL_TERMINATION
```

`performanceRisk` 矛盾类别：

```text
PAYMENT_CONTRADICTION
LIABILITY_CONTRADICTION
```

其余风险和矛盾进入 `compliance`：

```text
UNFAVORABLE_JURISDICTION
MISSING_DISPUTE_CLAUSE
FORCE_MAJEURE_ABSENT
IP_OWNERSHIP_RISK
VAGUE_CONFIDENTIALITY
OTHER

TERM_CONTRADICTION
OTHER
```

测试锁定了 11 类风险和 4 类矛盾的映射完整性以及互斥性。

### 2.3 报告草稿

落点：[build_report_draft](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:501)

结构：

```python
{
    "summary": str,
    "risk_counts": {
        "HIGH": int,
        "MEDIUM": int,
        "LOW": int,
    },
    "top_risks": list[dict],
    "health_score": {
        "overall": int,
        "dimensions": {
            "compliance": int,
            "performanceRisk": int,
            "clauseCompleteness": int,
        },
    },
}
```

固定摘要：

```text
共识别 {risk_count} 条风险、{conflict_count} 条矛盾、{missing_count} 条缺失标准对照。
```

Top Risks 规则：

- 排序：HIGH -> MEDIUM -> LOW。
- 同级按 `id` 字典序。
- 最多保留 5 条。
- 输出前通过 `model_dump(mode="json", by_alias=True)` 转纯 dict。

### 2.4 报告节点

落点：[report_draft_node](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:539)

执行流程：

1. `state.get("risks", [])`
2. `state.get("conflicts", [])`
3. `state.get("missing_clauses", [])`
4. 调用 `compute_health_score()`
5. 调用 `build_report_draft()`
6. 写回 `report_draft` 与整数 `health_score`
7. 记录 `audit.report_draft` 阶段日志

不返回 `llm_calls` / `rag_calls`，reducer 计数保持不变。
