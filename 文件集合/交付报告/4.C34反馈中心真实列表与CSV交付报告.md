## 3. 实现说明

### 3.1 API

`apps/web-ui/src/api/services.ts` 的 `feedbackApi`：

```ts
list(params?: {
  contractId?: string;
  targetType?: TargetType;
  verdict?: FeedbackVerdict;
  page?: number;
  pageSize?: number;
}): Promise<FeedbackListData>;
```

页面首次加载：

```ts
feedbackApi.list({ page: 1, pageSize: 100 })
```

### 3.2 统计

统计全部由真实 `items` 派生：

- `weekCount`：最近 7 天 `createdAt`；
- `incorporatedRate`：`isIncorporated=true / items.length`；
- `pendingCount`：`isIncorporated=false`。

无固定 `38 / 94.2% / 6`。

### 3.3 CSV

列顺序：

```text
反馈ID, 合同ID, 目标类型, 目标ID, 判定,
用户修正, 审核人, 是否采纳, 创建时间
```

每个字段：

```ts
`"${String(value ?? "").replace(/"/g, '""')}"`
```

并输出 UTF-8 BOM，兼容 Excel。
