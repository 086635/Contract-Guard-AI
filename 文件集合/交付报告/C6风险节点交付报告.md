## 2. 实现内容

### 2.1 私有结构化输出

[_RiskDraft](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:61)

```python
class _RiskDraft(BaseModel):
    category: RiskCategory
    level: RiskLevel
    title: str
    suggestion: str
    reasoning_steps: list[ReasoningStep] = Field(default_factory=list)
```

LLM 只负责风险语义，不获得任何需要稳定标识或坐标的字段。

### 2.2 风险节点执行链

[risk_node](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/graphs/nodes.py:459)

```text
clauses
  -> 条款预算
  -> 取 risk.prompt
  -> 逐条款：
       RagTool(query=条款正文, top_k=5, source_types=[STANDARD_CLAUSE, LAW_ARTICLE])
       -> risk.prompt.render(...)
       -> invoke_structured(_RiskDraft)
       -> 代码回填 EnhancedRiskItem
```

### 2.3 确定性回填

| 字段 | 来源 |
|---|---|
| `id` | `f"{contract_id}:{clause_id}:risk:{ordinal}"` |
| `clauseId` | `ClauseInput.clause_id` |
| `originalText` | `ClauseInput.text` |
| `bbox` | `ClauseInput.bbox or {}` |
| `citations` | `AgentRAGToolResult.citations` 转 `PreciseCitation` |
| `legalBasis` | 固定 `None` |
| `reasoningSteps` | `_RiskDraft.reasoning_steps` |

### 2.4 降级与失败隔离

| 情况 | 行为 | stage |
|---|---|---|
| 无条款 | 不调 RAG / LLM | `SKIPPED` |
| 缺 `risk.prompt` | 不调 RAG / LLM | `SKIPPED` |
| `rag_tool=None` | 使用 `EMPTY_CONTEXT_HINT` 继续 LLM | `DEGRADED` |
| RAG 抛异常 | 当前条款用空召回提示，继续 LLM | `DEGRADED` |
| RAG 返回 EMPTY | 使用原 `context_block`，不视为故障 | 可 `OK` |
| LLM 返回 None | 跳过当前条款，继续后续条款 | `DEGRADED` |
| bbox 缺失 | 写 `{}`，不伪造坐标 | warning |
| reasoning_steps 为空 | 保留风险，记 warning | warning |
