```text

  -> AuthService

```

## 3. 实现说明

### 3.1 持久化锁定字段

落点：

- `apps/api-gateway/app/db/models.py`
- `apps/api-gateway/alembic/versions/20260930_0009_add_auth_lockout_fields.py`

新增字段：

- `failed_login_attempts`：整数，默认 0，非空；
- `locked_until`：带时区时间，可空。

迁移支持旧库升级与回滚，真实 PostgreSQL upgrade/downgrade/upgrade 通过。

### 3.2 AuthService 登录

落点：`apps/api-gateway/app/services/auth_service.py`

```text
login(username, password) -> TokenBundle
```

策略：

1. 用户名不存在时仍执行固定假哈希校验，统一返回 `InvalidCredentialsError`；
2. 已停用账号不区分用户名/密码错误；
3. 有效锁定期内即拒绝，不因密码正确而放行；
4. 密码错误则递增 `failed_login_attempts`；
5. 达到 5 次时写入 `locked_until = now + 15m`；
6. 达到阈值当次抛 `AccountLockedError(retry_after_seconds=900)`；
7. 锁定窗口过期后重新从 0 次开始；
8. 登录成功清空失败次数和锁定时间，更新 `last_login_at`。

### 3.3 refresh / logout / me

```text
refresh(refresh_token) -> TokenBundle
logout(user_id, session_id) -> None
me(user_id) -> UserRecord
```

- refresh 只调用 C45 `SessionRepository` 完成哈希查询和原子轮换；
- refresh 重放检测命中后，`AuthService` 先提交安全补偿事务，再抛 `InvalidRefreshTokenError`，避免路由失败响应把“撤销全部活动会话”回滚掉；
- logout 校验 `session.user_id == user_id`，禁止跨用户撤销；
- me 只返回有效用户安全投影。

### 3.4 用户创建与管理员保护

```text
create_user(username, password, role, display_name, is_active) -> UserRecord
update_user(user_id, role, is_active, display_name) -> UserRecord
```

- `create_user` 先在 Service 做 Argon2id，再把哈希交给 `UserRepository`；
- `update_user` 在停用或降级 ADMIN 前，调用 `UserRepository.list_active_admins_for_update()` 锁定有效管理员集合；
- 如果本次变更会让最后一个有效 ADMIN 消失，抛 `LastAdminProtectedError`；
- 停用用户或改变角色后，撤销该用户全部活动 refresh 会话。
