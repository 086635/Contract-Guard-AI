## 1. 任务目标

C48 把 C47 的认证 API 接入前端：

```text
页面/路由
  -> authStore
  -> authApi
  -> httpClient
  -> /api/v1/auth/*
```

核心约束：

- access token 只在内存，不进入 localStorage；
- 刷新页面时通过 HttpOnly refresh cookie 恢复会话；
- 401 只刷新一次并重试，且并发请求只触发一次 refresh；
- VIEWER 不显示管理员入口，后端 403 仍是最终授权边界；
- 组件不得直接 `fetch` 或自建 Axios 实例。

## 2. 实现说明

### 2.1 HTTP Client

落点：`apps/web-ui/src/api/client.ts`

新增：

- `setAccessToken`
- `getAccessToken`
- `setRefreshHandler`
- `refreshAccessToken`
- 请求拦截器自动注入 `Authorization: Bearer <token>`
- 401 响应拦截器：
  1. 排除 `/auth/login` 与 `/auth/refresh`；
  2. 对普通业务请求只重试一次；
  3. 调用单飞 `refreshAccessToken()`；
  4. 成功则更新 Authorization 并重试原请求；
  5. 失败则清空内存 token 并抛出原错误。

并发 refresh 使用模块级 `refreshPromise` 去重。

### 2.2 Auth Store

落点：`apps/web-ui/src/stores/authStore.ts`

状态：

- `accessToken`
- `user`
- `status: idle | loading | authenticated | unauthenticated`
- `error`

动作：

- `login`
- `refresh`
- `bootstrap`
- `logout`
- `me`
- `hasRole`
- `reset`（测试隔离）

`setRefreshHandler(() => authStore.refresh())` 把 client 的 401 单飞刷新接回唯一 auth store。

### 2.3 登录页

落点：`apps/web-ui/src/views/Login.tsx`

- 用户名/密码表单；
- 登录中禁用提交；
- 错误信息不包含 token；
- 登录成功回到原始深链接或 `/contracts`；
- 已认证用户访问 `/login` 自动回到业务页。

### 2.4 路由守卫

落点：`apps/web-ui/src/router/index.tsx`

- `AuthGuard`：
  - `idle` 时在 `useEffect` 触发一次 bootstrap；
  - `loading` 显示恢复状态；
  - `unauthenticated` 跳转 `/login`；
  - `authenticated` 渲染业务路由。
- `AdminGuard`：
  - 非 ADMIN 访问 `/settings/rules` 时跳回 `/contracts`；
  - 不把前端隐藏当后端授权替代。

### 2.5 AppShell

落点：`apps/web-ui/src/components/layout/AppShell.tsx`

- 导航项由 `buildNavItems(contractId, isAdmin)` 生成；
- `规则配置` 标记为 `adminOnly`，VIEWER 不显示；
- 侧边栏/顶栏使用当前用户显示名；
- 新增退出登录按钮；
- 退出后清理内存 token 并跳转 `/login`。
