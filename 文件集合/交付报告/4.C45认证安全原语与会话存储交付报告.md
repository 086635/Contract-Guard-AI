## 1. 任务目标

C45 是 T-D7-1 的安全底座，目标是在 C44 用户模型之上提供以下唯一实现：

```text
密码 -> Argon2id
access -> JWT
refresh -> 高熵随机 token + 哈希落库
会话 -> auth_sessions + 单次轮换 + 重放撤销
```

本卡不实现登录、刷新、登出、用户管理 HTTP 路由；这些由 C46/C47 消费本卡原语和会话仓储。

## 3. 实现说明

### 3.1 密码服务

落点：`apps/api-gateway/app/services/security.py`

- `PasswordService` 默认使用 Argon2id；
- 参数为 `time_cost=3`、`memory_cost=65536`、`parallelism=4`、`hash_len=32`、`salt_len=16`；
- `hash_password` / `verify_password` 提供全局默认入口；
- 哈希损坏、格式错误或密码不匹配统一返回 `False`，不泄露内部原因；
- 不保存明文密码。

### 3.2 JWT access token

落点：`apps/api-gateway/app/services/security.py`

```text
JwtService.issue_access(user) -> str
JwtService.verify_access(token) -> TokenClaims
```

Claims：

- `sub`：用户 UUID；
- `role`：ADMIN / REVIEWER / VIEWER；
- `typ`：必须为 `access`；
- `iss`：来自 `settings.jwt_issuer`；
- `aud`：来自 `settings.jwt_audience`；
- `iat` / `exp`：使用注入时钟计算。

校验：

- 签名算法由配置提供；
- audience / issuer 由 PyJWT 校验；
- `sub`、`role`、`typ`、`iss`、`aud`、`iat`、`exp` 必须存在；
- `iat` 不得晚于当前注入时钟；
- `exp` 必须晚于当前注入时钟；
- 篡改、过期、错误 audience 和非法 claims 统一抛 `TokenValidationError`。

### 3.3 refresh token 与轮换

落点：

- `apps/api-gateway/app/services/security.py`
- `apps/api-gateway/app/db/repository/auth.py`

refresh token 设计：

```text
generate_refresh_token() -> 高熵明文
hash_refresh_token(raw) -> SHA-256 hex
```

`SessionRepository`：

- `create(user_id, hash, expires_at)`：创建会话，调用方负责 commit；
- `get_by_hash(hash)`：读取会话，包括已撤销记录；
- `rotate(old_hash, new_hash, new_expires_at, now)`：
  1. 对旧会话行 `FOR UPDATE`；
  2. 不存在 -> `SessionNotFoundError`；
  3. 已撤销/已轮换 -> 撤销该用户全部活动会话 -> `RefreshTokenReusedError`；
  4. 已过期 -> 标记撤销 -> `SessionExpiredError`；
  5. 有效 -> 建新会话，旧会话写入 `revoked_at`、`replaced_by_id`、`last_used_at`；
- `revoke(session_id, now)`：撤销指定会话，幂等；
- `revoke_by_hash(hash, now)`：按 refresh 哈希撤销。

持久化只保存 `refresh_token_hash`，不保存 refresh token 明文。

### 3.4 数据模型与迁移

落点：

- `apps/api-gateway/app/db/models.py`
- `apps/api-gateway/alembic/versions/20260929_0008_add_auth_sessions.py`

`auth_sessions` 字段：

- `id`：UUID 主键；
- `user_id`：用户外键，删除用户时 CASCADE；
- `refresh_token_hash`：唯一，长度 64；
- `expires_at`：带时区；
- `revoked_at`：可空；
- `replaced_by_id`：自关联轮换链，删除时 SET NULL；
- `created_at`：UTC；
- `last_used_at`：可空。

迁移支持 `upgrade -> downgrade -> upgrade`，真实 PostgreSQL 测试通过。
