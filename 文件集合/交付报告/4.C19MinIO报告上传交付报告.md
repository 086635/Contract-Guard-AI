## 2. 实现内容

### 2.1 上传函数

落点：`apps/async-worker/worker/storage/minio_client.py`

```python
def upload_report(
    contract_id: str,
    data: bytes,
    content_type: str = DOCX_MIME,
) -> str:
    ...
```

实现行为：

1. 校验 `contract_id` 非空，且不包含 `/`、`\`、`..`。
2. 校验 `data` 非空。
3. 从 `CG_MINIO_BUCKET` 读取桶名，默认 `contracts`。
4. 用 UTC 时间戳和 `uuid4().hex[:8]` 生成唯一 key。
5. 调用 `get_minio_client().put_object()` 写入 `BytesIO`。
6. 返回 key，不签发 URL。

### 2.2 依赖与导出

- `apps/async-worker/pyproject.toml` 声明 `minio>=7.2`。
- `uv.lock` 同步 `async-worker` 的 `minio` 依赖元数据。
- `worker/storage/__init__.py` 导出 `upload_report`。

## 5. 边界与已知事项

1. 本卡没有触碰 `rag_contracts`、网关路由、数据库模型、预签名下载逻辑。
2. `upload_report()` 只负责 MinIO 写入，不负责创建 bucket。
3. 真实 MinIO 集成测试只有在设置 `CG_MINIO_TEST_ENDPOINT` 且目标 bucket 存在时才执行。
4. `uv sync --all-packages` 被工作区既有 `apps/web-ui__demo` 目录阻断，该目录没有 `pyproject.toml`。
   本轮没有删除或移动该目录；`uv.lock` 已手工同步 `minio>=7.2`，且 `.venv` 中该包已存在、测试通过。
