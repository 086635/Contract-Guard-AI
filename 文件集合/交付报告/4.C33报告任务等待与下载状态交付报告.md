## 3. 实现说明

### 3.1 Audit 报告动作

落点：`apps/web-ui/src/views/Audit.tsx` 的报告区块。

- `reportApi.generate(selectedId)` 后保存 `taskId`；
- 调用 `taskApi.subscribe(taskId, ...)`；
- RUNNING 只更新生成中提示；
- DONE 后清理订阅并跳转 `/contracts/{selectedId}/report`；
- FAILED 后清理订阅、保留合同上下文并允许重试；
- `reportUnsubscribeRef` 在重新生成和卸载时统一清理。

### 3.2 Report 五态

落点：`apps/web-ui/src/views/Report.tsx`。

| 状态 | 判定 | 页面行为 |
|---|---|---|
| 未生成 | `reportApi.get` 404 且无 report | 显示“尚未生成报告”与生成按钮 |
| 生成中 | `task.status === RUNNING` 或 report RUNNING | 显示进度条和 stage |
| 失败 | task/report FAILED | 显示失败与重新生成 |
| 可下载 | report DONE + downloadUrl 非空 | 启用下载按钮 |
| 重新生成 | 点击重新生成 | 清理旧订阅，重新派发任务 |

### 3.3 下载

`openDownload()` 只在：

- `downloadUrl` 非空；
- `new URL(...)` 可解析；

时打开真实报告 URL。无 URL 时不会打印、不会拼接、不会造假成功。
