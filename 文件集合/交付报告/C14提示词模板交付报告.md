## 2. 实现内容

### 2.1 模板清单

| 模板 | 字符数 | 估算 Token | 当前 / 下游消费方 |
|---|---:|---:|---|
| `classify.prompt` | 274 | 183 | C5 classify |

Token 估算使用：

```python
TokenCounter(force_estimate=True)
```

### 2.2 占位符契约

| 模板 | 占位符 |
|---|---|
| classify | `contract_title` / `clause_excerpt` |
| extract | `clause_block` |
| risk | `clause_label` / `clause_text` / `contract_type` / `tolerance` / `rag_context` |
| conflict | `pair_block` / `contract_type` |
| rewrite | `instruction` / `before` / `recent_dialog` / `rag_context` |

每个模板的占位符集合均由测试逐项精确比对，重复占位符也会被拒绝。

### 2.3 加载入口

落点：[prompts/__init__.py](E:/important_project/Serve_bage/packages/ai-engine/ai_engine/prompts/__init__.py:13)

新增：

```python
PROMPT_NAMES
OPTIONAL_PROMPT_NAMES
templates_dir()
load_default_library()
```

行为：

- `templates_dir()` 返回包内模板目录绝对路径。
- `load_default_library()` 加载全部模板。
- 目录缺失时返回空库，不抛异常。
- 模板缺键时仍由既有 `render()` 抛 `KeyError`。

### 2.4 模板正文结构

每个模板均按四段组织：

```text
1. 角色
2. 任务
3. 输出字段清单
4. 约束
```

输出段要求“严格输出 JSON”，但不复制 JSON Schema 全文。
