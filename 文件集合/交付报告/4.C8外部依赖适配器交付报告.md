## 1. 实现内容

### 1.1 `storage.py`

- `MinioObjectStorage` 实现 C7 `ObjectStoragePort`。
- 预签名 URL 运行时生成，不落库。
- 测试可注入 Fake MinIO client。

### 1.2 `dispatch.py`

- `TaskKind` 固定允许的任务名：
  `parse_doc` / `run_audit` / `gen_report` / `rewrite`。
- `CeleryTaskDispatcher.send()` 只发送任务名和 args，返回 task id。
- 不 import worker 任务模块，不在网关执行任务。

### 1.3 `progress.py`

- `RedisProgressBroker` 订阅 `task_progress:{task_id}`。
- JSON 消息逐条产出；收到 `DONE` / `FAILED` 后结束。
- Redis/JSON 异常记录 warning 并退出，不忙循环。

### 1.4 依赖与配置

- `apps/api-gateway/pyproject.toml` 增加 Celery 运行期依赖。
- `app/config.py` 增加并被消费：
  - `CG_CELERY_BROKER`
  - `CG_CELERY_BACKEND`
  - `CG_MINIO_SECURE`
- 执行 `uv lock` + `uv sync --all-packages`，锁文件校验通过。
