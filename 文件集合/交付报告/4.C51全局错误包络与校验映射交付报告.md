## 1. 任务目标

C51 把散落在路由中的 `HTTPException` 和 FastAPI validation 响应统一为：

```text
ApiError {
  code,
  message,
  detail,
  traceId,
  issues?
}
```

目标：

- 保持 HTTP 状态语义；
- 用户提示和开发 detail 分离；
- 422 带字段级 issues；
- 500 不泄露堆栈或内部敏感信息；
- traceId 与响应头一致；
- 不改变成功响应包络。

---

## 2. 实现说明

### 2.1 OpenAPI 契约

落点：`packages/schema/openapi.yaml`

新增：

```text
ValidationIssue { path, code, message }
ApiError.issues? = ValidationIssue[]
```

保留 `ApiError.code/message/detail/traceId`。

### 2.2 全局异常处理器

落点：`apps/api-gateway/app/api/errors.py`

注册：

- `HTTPException`
- `RequestValidationError`
- unhandled `Exception`

映射规则：

| HTTP | ErrorCode | 说明 |
|---|---|---|
| 400/422 | `ERR_VALIDATION` | 参数或请求校验失败 |
| 401 | `ERR_UNAUTHORIZED` | 未认证 |
| 403 | `ERR_FORBIDDEN` | 无权限 |
| 404 | `ERR_CONTRACT_NOT_FOUND` | 资源不存在 |
| 409 | `ERR_DATA_CONFLICT` / `ERR_DUPLICATE_REQUEST` | 冲突或重复请求 |
| 413 | `ERR_FILE_TOO_LARGE` | 文件超限 |
| 415 | `ERR_UNSUPPORTED_FILE_TYPE` | 文件类型不支持 |
| 504 | `ERR_LLM_TIMEOUT` | 模型/上游超时 |
| 其他 | `ERR_INTERNAL` | 安全内部错误 |

### 2.3 422 issues

`RequestValidationError` 转为：

```text
ERR_VALIDATION
message = 参数校验失败
detail  = request validation failed
issues[] = {path, code, message}
```

`path` 去除 `body/query/path/header/cookie` 框架前缀，保留字段路径。

### 2.4 unhandled exception

- 记录服务器日志；
- 返回 `ERR_INTERNAL`；
- `message = 服务器内部错误`；
- `detail = internal server error`；
- 不回显异常消息、堆栈、数据库 DSN 或密码。

### 2.5 traceId

- `IdempotencyMiddleware` 绑定请求 trace_id；
- handler 优先读取上下文 trace_id；
- 响应体 `traceId` 与 `X-Trace-Id` 保持一致；
- 无中间件测试上下文时生成安全 `tr-*` 值。
