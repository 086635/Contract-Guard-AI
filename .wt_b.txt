+## 1.1 模块目标
+
+在**不破坏现有契约与编排**的前提下，把 RAG 从「机制正确但语义贫弱」推进到「**语义可用、可换 Milvus、指标可量测**」。
+
+### 1.1.1 对应赛题硬指标
+
+| 赛题指标 | 阈值 | RAG 模块的支撑方式 |
+|---|---|---|
+| 风险条款识别召回率 / 精准度 | ≥ 75% / 75% | 混合检索召回 + 精排质量（**本模块直接负责**） |
+| 标准条款比对 + 缺失条款提醒 | 必须 | 用 `EMPTY_RECALL` / 低分命中作为「缺失标准对照」信号（机制已存在） |
+| 报告含原文位置 | 必须 | `ContractChunk.bbox` → `RetrievedDoc.bbox` 的溯源链路（契约已通，坐标由 OCR 模块供给） |
+| 报告含法律依据 | 必须 | `CitationOut` → `EnhancedRiskItem.citations`（契约已通） |
+
+### 1.1.2 本模块的三个关键词
+
+```
+补语义  —— 接入真实 embedding 与 reranker（当前是哈希伪向量 + noop，故召回不达标）
+换引擎  —— 新增 Milvus 适配器（Ports & Adapters 已就位，业务层零改动）
+可量测  —— 建评测集与 Recall@K 脚本（没有度量就没有调参，这是达标的先决条件）
+```

+## 1.4 端到端数据流
+
+### 1.4.1 离线建库（写入）
+
+```
+语料(JSONL / 解析层输出)
+   → SimpleChunker.chunk()            产出 ContractChunk[]        [已有的]
+   → EmbedderPort.embed_batch()       产出 vector[][]（1024 维）   [T-A5 换成真模型]
+   → VectorStorePort.upsert()         写入向量库                  [T-A1 支持 Milvus]
+   → SparseStorePort.upsert()         写入 BM25 倒排/正排表        [已有]
+```
+
+> ⚠️ **两路索引必须用同一套 `chunk_id`**。
+> `ContractChunk.chunk_id` 由 `make_chunk_id(doc_id, section_id, slice_idx)` 用 **uuid5 确定性生成**，
+> 这是两路可对齐的前提（源码已保证，勿改）。
+
+### 1.4.2 在线检索（读取）
+
+```
+RAGService.retrieve(request)
+  ├─ 策略判定：strategy != DENSE_ONLY 且 sparse_store 为 None → 降级 DENSE_ONLY + warning
+  ├─ embed     : embedder.embed_one(query)                → 查询向量 + token 计量
+  ├─ dense     : vector_store.search(vec, dense_top, filters)   → VectorHit[]
+  ├─ sparse    : sparse_store.search(query, sparse_top)    → SparseHit[]     [T-A0-2 修复]
+  ├─ fusion    : rrf_fuse([dense_ranked, sparse_ranked], k=rrf_k)
+  ├─ rerank    : reranker.rerank(query, texts, base_scores) [T-A6 换成 HTTP 精排]
+  ├─ 阈值过滤  : final >= score_threshold  否则 → EMPTY_RECALL 降级
+  ├─ build     : ContextBuilder.build(docs, max_context_tokens)
+  └─ 返回 RAGQueryResponse（含 degraded / fallback_reason / citations / token_usage）
+```
+
+**红线**：`retrieve()` **永不抛异常**。任何失败路径 → `_degraded()` 响应。
+
+### 1.4.3 分数口径（**改动阈值前必须理解**）
+
+| 字段 | 含义 | 范围 |
+|---|---|---|
+| `scores.dense` | 稠密路**原始余弦相似度**（保留供调试） | `[-1, 1]` |
+| `scores.sparse` | BM25 原始分（未归一，量纲与余弦不可比） | `[0, +∞)` |
+| `scores.fused` | RRF 融合分 `Σ 1/(k+rank)`，**非归一** | `(0,1)` 小数 |
+| `scores.rerank` | 精排分 | `[0,1]` |
+| `scores.final` | **用于与 `score_threshold` 比较** | `[0,1]` |
+
+🔴 **`final` 用 clamp 而非 `(x+1)/2` 线性映射**（源码注释已说明）：
+后者会把"无关文本"（余弦≈0）抬到 0.5，**直接击穿 0.35 阈值，使"缺失标准对照"信号失效**。
+**改这里等于废掉缺失检测功能。**
