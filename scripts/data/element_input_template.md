# 合同要素标准输入模板（C80 / T-D8-5）

> **用途**：① 法务按此规范书写合同要素；② `scripts/build_quality_gold.py` 以此为**唯一源**
> 生成 30 份评测集（`quality_gold.jsonl`）与可填写的空白模板。
> **标准输入要求**（可核对的最小写法）见 `文件集合/codex/4.C80要素key契约与标准输入.md` §⑤。
> ⚠️ 缺项**不阻断**任何线上流程（上传/解析/审核照常），只降低「关键要素抽取 F1」。

## 一、核心要素写法（必须可逐字核对）

| key | 标签 | 规范写法 | 反例 |
|---|---|---|---|
| `party_a` | 甲方 | `甲方：杭州启明科技有限公司` | `甲方向乙方采购…`（无全称） |
| `party_b` | 乙方 | `乙方：宁波远洋设备有限公司` | 同上 |
| `amount` | 合同金额 | `合同总价为人民币 1200000.00 元` | 只写大写「壹佰贰拾万元整」 |
| `sign_date` | 签订日期 | `签订日期：2026-03-01` | 无落款日期 |
| `term` | 合同期限 | `本合同期限自 2026-03-01 起至 2027-02-28 止` | 只写「有效期三年」 |
| `jurisdiction` | 管辖地 | `争议由乙方所在地人民法院管辖` | 只写「依法解决」 |

## 二、合同正文模板（占位符由生成器替换）

{{subject_matter}}

{{breach_liability}}
